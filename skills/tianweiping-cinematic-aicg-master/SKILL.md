## 1. 硬约束（不可越）

1. **本地优先**：图像/视频/语音/配乐/合成/编码全部本机已核验工具；禁云端回退、代理、自动拉取模型（除非用户明确要求）。
2. **不写受保护内容**：prompt里禁止出现在世艺术家姓名、作品名、受保护IP名（如"鬼灭之刃"）、在世大师姓名——必须转译成通用视觉语言（用"ufotable style anime cinematic"这类通用风格词）。
3. **关键帧先过QA再进i2v**：不锁角色不批量生成。
4. **光效词忌讳**：H3 i2v 写 glow/reflection/flicker/全息UI 会触发多余特效杂讯，避免。
5. **不测试不宣称更好**：skill文件、提示词、自评分不能替代作品验证。
6. **时长诚实**：慢放撑时长是艺术片手法（塔可夫斯基），不是偷懒；但要"剧情片"必须补足镜头数。
7. **用户是主创**：已认可的剧情/人设/构图/画风是锁定项；必要变化先给候选、保留原版。

## 2. 工作流 A · 真人导演风格路由

用户给一句场景描述（如"雨夜东京街头，穿风衣的男人点烟"）：

1. **判断风格归属**：读 `references/directors.md` 末尾"场景→导演速查表"，给1个首选+最多2个备选，各写一句为什么
2. **用户已点名导演**：跳过推荐
3. **拆视觉签名**：从 directors.md 取该导演的构图/色彩/光影/运镜/空间/符号参数
4. **拼提示词**（通用顺序）：
   `景别+机位 → 主体动作 → 导演签名（构图/色彩/光影/运镜）→ 空间符号 → 氛围词 → 镜头规格（35mm/anamorphic/IMAX/film grain）`
5. **同时给中英文版**（视频模型英文更稳）

**13位导演库**：韦斯·安德森 / 王家卫 / 诺兰 / 黑泽明 / 库布里克 / 维伦纽瓦 / 塔可夫斯基 / 奉俊昊 / 是枝裕和 / 迪金斯 / 芬奇 / 雷德利·斯科特 / 让·雷诺阿

**反模式**：不在用户没说导演时硬塞风格；不把导演生平影评堆进提示词；不凭印象写风格，一切以 directors.md 参数为准。

## 3. 工作流 B · 导演审片

按 `references/review-prompts.md` 选模板：
- **单片段诊断**：模板1（逐帧找致命伤 + 重写prompt）
- **多片抽卡选优**：模板2（6维打分 + 明确选哪条）
- **完整TVC/广告片**：模板3（五维质检 + 可投放判断）

**执行要点**：
- 审片前先读 `doubao-video-extract` skill，抽帧+逐字稿，不凭空评
- 必须把"当初想拍什么"一起喂给模型，否则只能评技术、评不到"是否贴需求"
- 结论必须带**时间码（mm:ss）**和**可执行改法**（机位/焦段/光位/动作颗粒度）
- 拒收"更有电影感"这类废话

### 审片先写证据范围（不凭印象下结论）

| 实际获得并检查的材料 | 可下结论 | 待检查 |
|---|---|---|
| 文字剧本/分镜 | 因果、计划空间、时长加和 | 实际画面/运动/光色/声音 |
| 图像分镜/关键帧 | 姿态、身份、构图、光色 | 帧间连续性、节奏、声画 |
| 稀疏抽帧 | 采样位置的结构与漂移线索 | 未采样瞬间、全段运动 |
| 无声视频原速播放 | 动作、连接、视觉节奏 | 音乐、对白、同步 |
| 有声成片连续看/听 | 本次范围综合判断 | 未提供工程等 |

**返修单格式**：`ISSUE_ID / SHOT_ID / 版本 / 时间码 → 证据 → 影响 → 改动 → 保留项 → 方法 → 检查 → 状态`
**分级**：阻断（违反锁定项/因果/身份/接触/台词不可懂）> 需要修改 > 建议优化
**两轮同方法无改善** → 查意图/素材/控制条件/工具，换关键姿态或局部补绘，不无限重试。

## 4. 工作流 C · AIGC动画电影全流程

> 完整实战手册见 `references/aicg-film-playbook.md`（含21节：两条视觉路线/大师prompt公式/色彩脚本/情感节拍/角色一致性/本地H3管线/长片组装/超分）

### 制作流程
```
导演阐述 → 色彩脚本 → 角色美术设定 → 分镜剧本 → 关键帧 → 图生视频 → 剪辑合成 → 声音设计
```

| 阶段 | 输出 | 质量门 |
|---|---|---|
| 导演阐述 | 对标大师、情绪弧、色彩脚本 | 先定风格再出图 |
| 角色设定 | 角色标准图+磨损道具 | 不是完美脸，是被职业刻过的脸 |
| 分镜剧本 | 镜头表+情绪+台词+时长 | 每镜必须有情感功能 |
| 关键帧 | 每镜首帧图 | 逐张生成逐张交付 |
| 图生视频 | 5秒/段动态片段 | 用首帧锁角色一致性 |
| 剪辑 | 拼接+转场+BGM | 黑场过渡比花哨转场高级 |
| 声音设计 | 人声+音效+BGM | 关键时刻抽掉所有声音 |

### 两条视觉路线（同一剧本出两版）
| | 写实电影版 | 艺术厚涂版 |
|---|---|---|
| 目标 | 短视频传播、情绪冲击 | 影展、高级感、朋友圈 |
| 参考 | 《烈火英雄》《勇往直前》 | 安德鲁·怀斯、伦勃朗、马远留白 |
| 构图 | 满屏叙事、人物占满 | 大面积留白/暗部，人物占1/3 |
| 配色 | 丰富、细节多 | 严格两色（橙琥珀#ff8c3a + 深青蓝#1a2a3a） |
| 人物 | 真实脸、疤、胡茬、汗 | 剪影、半明半暗 |
| 光影 | 多点照明、环境光 | 单光源伦勃朗光、大面积死黑 |
| 平台 | 抖音/快手/B站 | 视频号/小红书/影展 |

**默认先出艺术版关键帧定调，再决定是否补写实版。**

### 角色设计反"AI脸"
AI默认出完美小鲜肉脸，英雄题材必须刻意打破：

| 部位 | AI默认 | 应该 |
|---|---|---|
| 脸 | 光滑无瑕疵 | 旧疤、胡茬、眼角纹、烟灰汗水 |
| 手 | 干净修长 | 老茧、指甲缝洗不净、粗糙 |
| 装备 | 崭新笔挺 | 肘部磨白、膝盖烧焦洞、水渍焦痕 |
| 眼神 | 明亮看镜头 | 平时疲惫下垂，入火场瞬间锐利 |
| 体型 | 精瘦上镜 | 肩膀宽厚、脖子粗、被工装撑满 |
| 道具 | 无 | 磨损全家福、红绳徽章、速效救心丸瓶 |

### 情感节拍（真正让人哭的镜头）
1. **摘面罩给孩子**——牺牲不用台词，动作本身
2. **偷偷哭被人看见**——脆弱比坚强更打动人
3. **道具呼应**——女孩的蜡笔画和主角头盔里的女儿画一模一样
4. **金句**——"怕就对了。怕还往里冲，才是消防员。"
5. **剪影比正脸强**——英雄时刻用逆光剪影

**反模式**：不说教旁白 / 不慢镜头煽情堆 / 不喊口号 / 不把英雄拍成超人

### 色彩脚本（60秒短片情绪弧）
```
开场  冷蓝#1a2332 + 暖黄窗灯     宁静/孤独
警报  警报红#ff2020骤入          撕裂
火海  烈焰橙#ff6b1a + 黑烟       压迫
牺牲  橙红逆光 + 剪影            悲壮
救赎  黎明金#ffd89b + 淡蓝       希望
```
**不要全片一个色调，每个情绪转折必须换色温。**

### 图生视频Prompt公式
```
[主体正在做什么动作，有物理重量]
+ [环境元素如何流动：火焰跃动/烟雾翻涌/水波反射]
+ [镜头运动：固定/缓慢跟随/缓慢推近]
+ [节奏：安静/紧张/呼吸感]
```
**关键**：不要让人物做大动作。5秒里人物只走几步、微微低头、肩膀轻颤就够了。动得越多越假。

### 角色一致性5招
1. 固定首帧：每张i2v用同一张关键帧
2. 锁定描述词：角色核心特征一字不差
3. 分段5秒：不要一次生成太长
4. 先定一张核心脸，后续基于它
5. 艺术版可以剪影，反而更高级

### 声音设计
- **关键时刻抽掉所有声音**：摘面罩瞬间BGM和环境音全停，只剩呼吸——比任何音效都强
- 环境声做床底；BGM克制（艺术版用单乐器不用弦乐堆）
- 掌声从一人到一片
- 混音：人声-6dB，BGM-18dB，音效-12dB

## 5. 工作流 D · 竖屏漫剧量产

> 质量评分见 `references/drama-quality-rubric.md`

**先定风格（一次问清，别迭代7次）**：要真人剧照质感 / 厚涂插画 / 3D动画 / 素描？用户给参考图最好。

| 路线 | 首帧prompt模板 |
|---|---|
| 真人剧照质感（历史默认） | `Screenshot from 1994 TV drama + real actor face + pores wrinkles + weathered armor + grainy film texture` |
| 厚涂插画（儿童/治愈） | `same thick oil-painting storybook illustration style` |
| 3D动画（Pixar系） | `3D animated movie still, Pixar style`（慎用，用户常否定） |
| 赛博朋克 | `neon-lit, cyberpunk` |

### 风格确认流程（每项目必走）
1. 出**一张**人设图 → 用户确认/否决 → 否决就问"哪里不行" → 定位改prompt
2. 三主角各一张 → 逐张确认
3. 场景全景 → 确认
4. 关键帧前4个 → 确认；后6个 → 确认
5. **每步等"可以/继续"，用户没确认不推进**

### 标准流水线（每集）
1. **剧本**：10个15s镜头，每镜=画面+动作+台词+音效
2. **人设图**：每主角一张（左大头特写+右三视图），9:16，出完停
3. **场景图**：每场景一张全景空镜，同画风，出完停
4. **关键帧**：每镜一张（人物+场景+动作），作为H3首帧
5. **H3跑视频**：每张关键帧跑5秒I2V，turbo 8步，9:16 0.4MP
6. **剪映拼接**：10个5s片段放慢/拼接成2-3分钟，加字幕配音BGM转场

### 已踩过的坑
| 坑 | 现象 | 解决 |
|---|---|---|
| 内存不够 | ComfyUI 403/拒连 | 跑前清到≥20GB空闲；关Chrome/Steam/抖音 |
| 中文文件名 | LoadImage报Invalid image file | 关键帧一律英文命名 `ep01_shot01.jpg` |
| 伪汉字 | AI生成的招牌/竹简是乱码 | 关键帧prompt写"no text"；后期剪映加字 |
| 5秒vs15秒 | H3只能跑5秒 | 剪映放慢1.5-2x或重复帧 |
| 分辨率低 | 0.4MP≈832×1472 | 后期Real-ESRGAN超分 |
| 角色漂移 | 每个镜头脸变 | prompt写死特征（大耳/红脸长髯/豹头环眼） |
| 进程驻留 | 跑完占15GB内存 | 任务完杀python PID |
| 队列积压 | 新任务排不上 | 批量前查queue_pending，>20先清 |

## 6. 工作流 E · 电影级大片感海报

> 设计语言见 `references/design-language.md`，配方见 `references/cinematic-recipes.md`，质检见 `references/quality-and-iteration.md`

**统一风格**：所有产出默认遵循「NEON SIGNAL 设计语言」保证个人风格统一。

### 大片感五支柱（每张必查）
1. **构图张力**：明确一个构图原型+一个灵动动作（偏轴主体、字图叠压、超大标题、破格出画、对角线动势、仰视透视）。拒绝居中呆板。
2. **高级配色**：默认"深夜色基底 + 电光强调色 + 暖色点睛"三色制。**禁止俗套的纯蓝紫霓虹全屏**；用暖琥珀/暖橙撞色点睛，脱离"科技模板感"。
3. **材质系统**：至少2类材质落点。高价值组合：湿润反光地面、体积光、磨砂玻璃、数据粒子、流体金属、霓虹边缘光、真实皮肤微纹理。
4. **杂志级排版**：主标题用创意字体，建立"主视觉→大标题→副标→落款"强阅读层；信息按语义成组，不堆半透明底板。
5. **主题母题**：把主题发展成组织画面的结构型母题（如信号光柱贯穿、数据流环形围合），同时承担视觉主体与版面骨架。

### 三种已验证配方
| 配方 | 适用 | 构图 |
|---|---|---|
| 01 主视觉KV | 品牌/IP主视觉、作品集封面 | 电影纵深+非对称 |
| 02 3D超现实概念 | 宏大史诗、游戏/影视感 | 向心爆发+低角度仰视 |
| 03 人物特写杂志 | 人物/IP角色海报 | 非对称+字图咬合 |

风格范例（可直接作视觉锚点）：`assets/ref-01-kv.png` / `ref-02-3d.png` / `ref-03-portrait.png`

### 六段式Prompt骨架
```
生成一张[产物与主题]的[画幅]海报。
[构图原型 + 结构型主视觉 + 主体位置 + 视觉动势 + 阅读层]。
核心文字为[主标题，用中文双引号""框定]。
```

### i2v运动Prompt（每段3秒）
只写动作和运镜，不写画面（首帧已锁）：
- 静镜头：`She stands still, rain falls, kimono sleeve sways gently, camera slowly pushes in.`
- 动作镜头：`Fast motion — she draws katana and slashes horizontally, blade leaves red light trail, hair flares.`
- **避免**：glow/reflection/flicker/全息UI（触发杂讯）

### QA检查清单
- [ ] 角色一致性（脸/发/服装/道具跨镜头）
- [ ] 构图符合导演配方
- [ ] 色彩在STYLE DNA范围内
- [ ] 材质可区分（缎面vs皮革vs金属vs钢）
- [ ] 无AI artifact（塑料皮肤/多手指/刀变形/文字水印）
- [ ] 叙事连续（动作→反应→结果）

### 禁止
- 一张图塞4个角色做i2v
- 一个prompt写两个不同场景
- 用glow/reflection/flicker类光效词
- 极特写手/眼做i2v（会崩）
- 不锁角色就批量生成

|---|---|---|
| 成长/日常/善意/性格 | 宫崎骏 JM01-03 | JM04、JS02 |
| 等待/距离/记忆/地点情绪 | 新海诚 JS01-04 | JM01、JM04 |

- **JM02 生活参考落实重量**：搬/推/拉/放检查支撑脚、接触点、重心移动
- **JM03 体验决定环境取舍**：先写角色此刻注意什么，再安排背景/环境声/停顿
- **JM04 Layout统一所有部门**：关键镜先定地标、比例、起止位、路径、遮挡、摄影机、光源
- **JS01 地点能被生活**：先固定出入口/路径/尺度，再选少量有使用原因的差异
- **JS02 每镜呈现色受环境光影响**：写"注意对象—主光—时间—天气—反射—人物明暗"

## 9. 长篇情感编剧（30分钟级）

> 详见 `references/emotional-longform.md`

- 主要人物分开写：外在目标 / 内在需要 / 错误判断 / 害怕失去 / 关系与资源
- 重要转折来自**有代价的选择**，后果进入后续行动
- 先建立共同经历，再试探→误解→带代价行动→新相处方式。多年伤害不能靠一句道歉消除
- 情绪优先落到动作/潜台词/停顿，不能只靠旁白解释
- **伏笔表**：首次出现—观众当时理解—后续变化—回收—对选择的作用
- 30分钟=1800秒，逐场记录地点/时间/目标/阻力/行动/状态/对白/伏笔/时长，再拆镜头
- **禁止**：用循环或极慢放填足缺失剧情后宣称完整角色动画
- 测时分开记录：纯对白 / 句间停顿 / 独立动作 / 反应预算

## 10. 本地渲染管线（RTX 5080 实战）

> 详见 `references/aicg-film-playbook.md` 第15-21节

### 两条管线
| | 本地 H3（ComfyUI） | 云端 Seedance |
|---|---|---|
| 费用 | 免费，只耗电 | 按次扣费，有额度上限 |
| 速度 | 5秒约60秒，10秒约180秒 | 5秒约30秒 |
| 质量 | 写实自然，风格化弱 | 风格化强，运动流畅 |
| 适用 | 批量补拍、蒙太奇、日常镜头 | 关键镜头精品 |

**策略：关键情感镜头用云端精品，过渡/蒙太奇/补拍用本地批量。**（本地优先时全走本地）

### H3关键参数（`D:\AI_WORKSPACE\h3_template.json`）
| 节点 | 参数 | 值 |
|---|---|---|
| `105:11` | vae_name | `minimax_h3_video_vae_int8_convrot.safetensors` |
| `114` | image | 上传后的英文文件名 |
| `115` | aspect_ratio | `"16:9 (Widescreen)"` |
| `105:104` | prompt | 英文描述 |
| `105:111` | value | 5.0 / 10.0 / 15.0 |
| `105:15` | noise_seed | 随机整数 |
| `92` | filename_prefix | `window_film/shotXX` |

### 图片上传必走API
关键帧即使扩展名是.png，实际可能是JPEG数据，直接复制会被LoadImage拒绝。必须：
```
POST http://127.0.0.1:8188/upload/image
Content-Type: multipart/form-data
字段名: image；文件名改成 .jpg
```

### 性能基准（int8 + turbo 8步）
| 时长 | 渲染时间 | 文件大小 |
|---|---|---|
| 5秒 | ~60秒 | 300-600KB |
| 10秒 | ~180秒 | 700-1400KB |
| 15秒 | ~300秒 | 1-2MB |

**内存是瓶颈（需≥15GB空闲），不是显存。**

### 超分路线
| 方案 | 适用 | 说明 |
|---|---|---|
| ffmpeg Lanczos | 1080p/4K快路径 | 软件超分，细节是"画出来"的 |
| Real-ESRGAN | 真4K精修 | `F:\upscale_work\realesrgan-ncnn-vulkan.exe`，动画用 `realesr-animevideov3-x4` |

**4K正确姿势**：本地渲染720p级 → ffmpeg Lanczos拉到1080p → Real-ESRGAN逐帧x4 → 3840×2160
```
# 拆帧
ffmpeg -i in.mp4 -vf scale=1920:1080 frames_in/frame_%05d.png
# 超分
realesrgan-ncnn-vulkan -i frames_in -o frames_out -n realesr-animevideov3-x4 -s 4 -f png
# 重组装（加 setsar=1 修SAR变形）
ffmpeg -framerate 24 -i frames_out/frame_%05d.png -vf "scale=3840:2160,setsar=1" -c:v h264_mf -b:v 20M out_4k.mp4
```
- 5080速度约57帧/分钟，27分钟视频=39000帧≈11小时（过夜跑）
- Real-ESRGAN跑时**不要开ComfyUI/Chrome硬件加速/Ollama**
- 进程可能静默崩溃，必须监控输出帧数持续增长

### 本机ffmpeg能力（`C:\Program Files\Live2D Cubism 5.3\tools\ffmpeg.exe`）
- ✅ 有 `libopenh264`（替代libx264）/ `h264_mf` / `hevc_mf` 硬件编码
- ✅ 有 `libmp3lame` / `libopus` 音频编码
- ❌ 无 `drawtext`（标题卡用Flux出图）
- concat.txt 必须 UTF8无BOM（用 `[System.IO.File]::WriteAllLines` 不要Out-File）
