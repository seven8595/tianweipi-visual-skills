# 一线动画电影验收标准（每集交付前过一遍）

## 一、角色一致性（最重要）

- [ ] 刘备大耳垂肩、小胡子、灰袍、工牌挂绳——每个镜头都在
- [ ] 关羽红脸、长髯到胸、绿袍、工牌——每个镜头都在
- [ ] 张飞豹头环眼、络腮胡、黑甲、红巾——每个镜头都在
- [ ] 三人比例关系：关羽最高最瘦，张飞最矮最壮，刘备中等
- [ ] 没有出现"刘备变关羽"或"张飞换衣服"

**怎么查**：10个镜头并排缩略图，看角色是不是同一个人。不是就重跑那个镜头。

## 二、美术统一

- [ ] 厚涂插画质感一致（不是某些镜头照片感、某些镜头卡通感）
- [ ] 色温统一：街头暖黄、桃园粉金，不要跳到冷蓝
- [ ] 笔触密度相近（不要一个镜头精细、一个镜头粗糙）
- [ ] 边缘处理一致（柔和 vs 硬边）

## 三、镜头语言

- [ ] 每个镜头有明确的运动（推/拉/摇/移/跟），不是静止
- [ ] 景别有变化（全景→中景→特写），不要10个都是中景
- [ ] 动作有起承转合，不是人物僵住
- [ ] 视觉焦点清楚（观众第一眼知道看哪）

## 四、叙事节奏

- [ ] 开头3秒有钩子（刘备叹气/张飞拍桌）
- [ ] 10个镜头有起承转合：冲突→解决→伏笔
- [ ] 结尾留钩子（第2集预告）
- [ ] 单镜头不超过15秒，不短于5秒

## 五、后期（剪映阶段）

- [ ] 字幕准确（没有错别字、伪汉字）
- [ ] 配音对嘴型（大致）
- [ ] BGM不压过人声
- [ ] 转场自然（不要每个镜头都闪白）
- [ ] 9:16满屏，无黑边
- [ ] 1080p导出（不是0.4MP原片直接发）

## 六、喜剧效果

- [ ] 每个镜头至少1个笑点（职场梗/身份反差/现代梗）
- [ ] 笑点不尴尬（不是硬挠痒）
- [ ] 人物动机合理（为什么这么做）

## 常见问题排查

| 问题 | 原因 | 修复 |
|---|---|---|
| 角色脸变了 | prompt没写死特征 | 重跑，prompt开头加"same character as before:..." |
| 动作僵 | prompt只写了场景没写动作 | 重写prompt，加"slowly lifts head"等具体动作 |
| 色调跳 | 前后镜头prompt色温不一致 | 统一加"warm amber light" |
| 伪汉字入镜 | 关键帧没写"no text" | 重出关键帧，prompt加"no text, no calligraphy" |
| 时长不够 | H3只跑5s | 剪映放慢0.5x或加静帧 |
| 分辨率低 | 0.4MP | Real-ESRGAN超分到1080p |
