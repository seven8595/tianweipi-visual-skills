# 导演审片、判断与定点返修

适用：文字稿、分镜、静帧、动态分镜、动画测试及成片。先确认手上实际有什么，再决定能评到哪个层级。

## 证据决定检查范围

| 输入/实际检查 | 能支持的判断 | 尚不能支持的判断 |
|---|---|---|
| 剧本/文字分镜 | 因果、角色目标、计划空间与时长核算 | 实际构图、画面美术、表演流畅和真实节奏 |
| 图像分镜/关键帧 | 姿态、构图、身份、光色和可见空间 | 帧间连续性、接触时机、完整节奏和混音 |
| 稀疏抽帧 | 采样位置的结构/漂移、部分连续性线索 | 未采样的闪帧、运动细节、全段动态合格 |
| 无声视频且已原速播放 | 画面动作、镜头连接、时序和视觉节奏 | 对白可懂度、混音、声画情绪配合 |
| 音频且已听取 | 对白、音色、杂音、音乐/声音本身的节奏 | 与画面同步、影像表演及美术 |
| 有声成片且已连续播放/听音 | 本次检查范围内的综合判断 | 未提供工程的可编辑性、未检查平台的播放表现 |

技术可解码与实际原速观察分开记录。只获得静帧时直接完成静帧审查，并列出动态待检项；不能把未执行的播放写成已经发生。

## 三次审查，各有目的

工具允许时按需采用：

1. **原速整体看。** 先记录看懂了什么、视线是否被引导、人物意图与情绪落点。动作片段原速难以理解，优先返调度/时间安排。
2. **定位问题。** 用重复播放、慢放、逐帧、音频单听与具体采样核查原因。分清有意夸张、保持、留白与缺陷。
3. **修后原速回看。** 复核该镜及相邻镜头、声音和全段作用，防止局部修好后破坏连续性。

只需局部改台词/光色时缩小检查范围。不会为了完整表格强行扩展到无关镜头。

## 优先顺序与故障回溯

| 检查重点 | 常见可见/可听问题 | 优先修复阶段 |
|---|---|---|
| 意图与因果 | 无法理解角色为何行动、结果无铺垫 | 剧本/节拍/分镜 |
| 空间与调度 | 方向突变、接触对象位置不明、视线错配 | 场景关系/Layout |
| 身份与造型 | 五官/体积/服装/道具漂移 | 设定、原画、局部素材 |
| 表演与动作 | 滑步、重量不成立、动作无反应、击打无后果 | 关键姿态与时间表 |
| 美术与光色 | 人物被吞没、主光无解释、邻镜地点断裂 | 美术/色彩/合成 |
| 特效与整合 | 亮度掩盖接触、二维三维比例或节奏分离 | Layout/渲染/合成 |
| 声音与剪辑 | 关键台词被盖、落点失效、反应来不及理解 | 剪辑/声音/字幕 |
| 输出与工程 | 黑帧、截断、不同步、缺依赖、规格错误 | 工程/导出 |

找最早产生问题的阶段。空间没建立就先补关系镜/重排构图，不靠增加粒子修复；对白听不清则检查声源与混音，不自动重做画面。简报与实际锁定项优先于通用建议。

## 问题分级

- **阻断：**违反锁定项、关键因果无法读出、身份/接触严重错误、台词不可懂、文件缺失/损坏/规格不符。保持未通过，先修。
- **需要修改：**目标基本成立，但表演、连接、光色或声音明显削弱效果。明确位置与影响。
- **建议优化：**较好的节奏、造型或美术选择；注明为偏好/候选，不把个人喜好写成硬缺陷。

这是项目定位工具，不做名家排名，不把自评分相加称为大师认证。最终状态按实际阶段写：方案完成、预览待审、需返修、检查范围内通过、主创认可；工程检查、内容检查和主创审美决定分别记录。

## 每轮返修单

通常先列一至三个影响最大的项，需要更多阻断项时全部列清。每项记录：

| 字段 | 写法 |
|---|---|
| 编号/位置 | ISSUE_ID、SHOT_ID、实际版本、时间码或帧区间 |
| 证据 | 具体看到/听到的现象；没有真实素材时标“计划风险” |
| 影响 | 对动作理解、情绪、身份或规格造成何种影响 |
| 修改 | 哪个姿态、镜头长度、道具位置、明暗关系或声音落点怎样改 |
| 保留 | 已认可人物、构图区域、剧情、色彩或相邻镜头 |
| 方法/负责人 | 可用工具或需要的作画、美术、摄影、声音环节 |
| 验收 | 改后以何种观察/播放检查；检查相邻镜头及新副作用 |
| 状态 | 待修、已修改待检、检查范围内通过、仍有问题 |

**格式示例，非本次素材的真实发现：**`S03 / 1.20–1.45s`，角色手到杯柄前杯已开始移动，接触因果不成立。锁定杯子位置与人物身份；把杯子移动起点改到抓握姿态建立之后，补腕部受力，再原速看拿杯与下一镜。只有静帧时，这项只能写计划风险，不能伪填发现时间码。

## 停止与换方法

保留修改前版本，做最小可逆修改。两轮同方法无改善时查：意图误解、素材不适合、控制条件不足、工具限制、制作执行错误或标准不匹配。选择缩小范围、改关键姿态、局部补绘、改 Layout 或换可控工具；不靠降低评分标准获得“通过”。

没有参考图、真实视频或声音时，先做已有材料可支持的审查并给出下一阶段任务。确需缺失材料才能判断的结论保持待检，不补造结果。
