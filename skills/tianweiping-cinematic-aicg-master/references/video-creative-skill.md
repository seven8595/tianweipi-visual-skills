# 视频创意工作室

## 1. 创意工作流
```
创意构思 → 剧本 → 分镜脚本 → 镜头设计 → 拍摄/生成 → 剪辑 → 成片
```

## 2. 创意构思方法
- **痛点切入**：观众什么情绪？我们给什么解决方案？
- **反差制造**：预期A，给B，制造记忆点
- **情绪锚点**：开头3秒必须有钩子
- **故事弧**：起承转合，结尾留余味

## 3. 剧本结构
| 时长 | 结构 |
|---|---|
| 15秒短视频 | 钩子(3s) → 冲突(7s) → 解决/反转(5s) |
| 60秒短视频 | 钩子(5s) → 铺垫(15s) → 发展(20s) → 高潮(15s) → 结尾(5s) |
| 3分钟短片 | 开场(15s) → 建置(45s) → 对抗(90s) → 解决(30s) |

## 4. 分镜脚本格式
| 镜号 | 景别 | 镜头运动 | 画面内容 | 台词/旁白 | 时长 | 音效/BGM |
|---|---|---|---|---|---|---|

## 5. 镜头语言速查
### 景别
- 远景：交代环境
- 全景：人物全身
- 中景：膝盖以上，叙事
- 近景：胸部以上，对话
- 特写：面部/细节，情绪

### 运镜
- 推：强调、进入
- 拉：离开、揭示
- 摇：展示空间
- 移：跟随
- 跟：代入感
- 手持：真实感

## 6. 转场技巧
- J-cut：声音先入，画面后入
- L-cut：画面先出，声音后出
- 遮挡转场：物体过镜头
- 匹配转场：形状/颜色相似转场
- 动作转场：动作连贯切

## 7. AIGC视频prompt公式
```
[主体] + [动作/表情] + [镜头运动] + [环境] + [光影] + [风格] + [时长]
```
