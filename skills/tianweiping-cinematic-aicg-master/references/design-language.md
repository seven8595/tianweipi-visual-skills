# NEON SIGNAL — 个人设计语言系统（统一风格锚点）

本文档是 `cinematic-poster-lab` 的**统一风格定义**。所有用本 skill 产出的海报，必须遵循这套参数，确保个人作品风格统一、可辨识。源自已真机验证的 NEON SIGNAL 三张海报 + 设计语言系统页。

## 色彩系统（三色制，硬约束）

| 名称 | 色值 | 占比 | 职责 |
|---|---|---|---|
| 深空墨 | `#0A0E1A` | 60–70% | 基底 · 空间纵深 |
| 午夜蓝 | `#0D1326` | — | 卡片 · 层次表面 |
| 电光青 | `#22E0D8` | 15–20% | 强调 · 主视觉/路径/焦点 |
| 暖琥珀 | `#FFB454` | 5–10% | 点睛 · 标题/关键信息 |
| 冷霜白 | `#E8F1FF` | — | 文字 · 高光 |
| 雾紫 | `#6B7AA8` | — | 辅助 · 次级信息 |

- 三色制规则：深空墨承空间、电光青承主视觉与路径、暖琥珀承标题与关键信息。
- **暖色点睛破冷**：用暖琥珀撞破冷色垄断，脱离"科技模板感"，形成个人辨识度。
- 派生色沿 oklch 同 hue 调 lightness/chroma，不凭空发明新 hex。
- 同一语义同一颜色，不用装饰色堆砌。

## 字体系统

- **展示/标题**：`Orbitron`（几何未来主义），英文/数字/主题词主标；可描边、立体化、字图咬合。
- **中文字标/正文**：`Noto Sans SC`；正文 max-width ≈ 40 全角字；层级靠字重/字号/间距建立，不堆字体数量。
- 字号层级：Hero（clamp 2.9rem→7.6rem）→ H2（1.6→2.7rem）→ H3（1.05rem）→ 正文（0.95rem）→ 标签（11–12px，仅辅助文字）。

## 版式与构图

- **三层阅读顺序（硬约束）**：
  - LAYER 01 第一焦点：母题与主体交融处（信号光柱/面部光纹/巨型数据体）。
  - LAYER 02 纵深铺陈：楼宇纵深/数据海/粒子星尘。
  - LAYER 03 底部收束：信息区克制收束，主视觉→大标题→副标→落款。
- **构图原型**（偏好）：电影纵深 · 非对称主视觉 · 向心爆发 · 字图咬合 · 压角留白。
- **灵动动作**（每张必选其一）：偏轴主体 · 字图叠压 · 破格出画 · 仰视透视 · 超大标题。拒绝居中呆板。

## 材质系统（每张至少落 2 类）

湿润反光地面 / 体积光（丁达尔）/ 磨砂玻璃 / 数据粒子·光尘 / 流体金属 / 霓虹边缘光 / 真实皮肤微纹理 / 全息镭射。

## 主题母题库

信号光柱贯穿 · 数据流·粒子 · 楼宇纵深 · 巨型数据体 · 面部数据光纹 · 数据海翻涌。

## 红线与反刻板（硬约束）

1. 禁纯蓝紫霓虹全屏；用暖琥珀撞色打破。
2. 禁刻板映射（科技必用深蓝、春天必用绿）；用三色制 + 材质替代。
3. 禁机械重复装饰（满屏同款气泡/便签/光斑）。
4. 禁占位符与编造（日期/价格/人名/品牌全称只取用户事实，不写 XX）。
5. 禁在世艺术家名/作品名/受保护 IP 作风格锚点，一律转译为通用视觉参数。

## 主标题文案锚点（可选）

`NEON SIGNAL` 为默认可复用主题词；换主题时按"信号/觉醒/数据"语汇扩展，保持神秘、高级、前瞻语气。
