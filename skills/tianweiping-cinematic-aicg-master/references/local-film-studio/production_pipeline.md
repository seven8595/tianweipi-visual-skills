# 批量生成管线

## 项目目录结构

```
film_project/
├── 01_script/          # 剧本
├── 02_storyboard/      # 分镜表（shot_list.md）
├── 03_characters/      # 角色设定和参考图
├── 04_scenes/          # 场景参考图
├── 05_shots/           # 生成的镜头片段
│   ├── scene01_shot001.mp4
│   ├── scene01_shot002.mp4
│   └── ...
├── 06_audio/           # 配音配乐音效
├── 07_edit/            # 最终剪辑
└── workflows/          # ComfyUI工作流JSON
```

## 每个镜头的标准流程

```
1. 生成首帧参考图（Flux/SDXL 或 Wan 自带首帧模式）
   ↓
2. Wan2.1 I2V 从首帧生成 5 秒视频
   ↓
3. Upscale 到目标分辨率
   ↓
4. 保存到 05_shots/sceneXX_shotYY.mp4
```

**分辨率路线按显存分：**
- ≤16GB：首帧 → 480p 生成 → 4x upscale 到 1080p
- **32GB / 5080：首帧 → 720p 原生生成 → 2x upscale 到 1440p/4K**（少一代 upscale，画质更实）

**单镜头端到端耗时**：
- 16GB 卡：15–20 分钟/段（旧基线）
- 32GB 卡：**首次跑完一个镜头后用实测秒数填进来**，不要照抄本表。加速手段见 `acceleration.md`。

## 工期估算

| 电影时长 | 镜头数 | 16GB 基线 | 32GB / 5080 |
|---|---|---|---|
| 5分钟短片 | ~60段 | ~15小时 | **按 T0 实测重算**（见 acceleration.md 第 0 节） |
| 15分钟短片 | ~180段 | ~45小时 | 同上 |
| 50分钟长片 | ~600段 | ~150小时 | 同上 |
| 90分钟电影 | ~1000段 | ~250小时 | 同上 |

> 报工期前必须先跑一个镜头实测 T0，用 T0 × 镜头数 × 1.3 废片系数给用户。不要拿这张表当承诺。

## 优化技巧

1. **空镜多拍，人物少拍**：环境空镜可以复用，人物镜头才需要精雕
2. **动作镜头短，氛围镜头长**：打斗2-3秒/段，空镜8-10秒/段
3. **批量排队**：ComfyUI支持队列，晚上睡觉挂着跑
4. **先出粗剪再补镜头**：先把所有镜头跑一遍粗剪，缺的地方再补
5. **失败镜头记下来**：不要反复试同一个prompt，换个思路

## 废片局部修复（不要整条重做）

批量生成必然有大量废片，局部修复比重抽整条省时间：

1. **局部重绘（Inpaint）**：只错了某个人/物/背景，用inpaint蒙版单独修那一块
2. **首尾帧替换**：中间动作没问题，只是开头或结尾不满意，换首尾帧重新生成
3. **局部编辑节点**：ComfyUI的WanVideoWrapper支持局部编辑，指定时间段修改
4. **拼接修复**：错的那2秒单独重新生成，然后剪辑时拼回去

> 原则：能修就不重做，重做一次=10分钟，修一次=2分钟。

## 后期制作

- **本地配音（TTS）选型**：
  - **CosyVoice2（阿里开源）**：中文自然度最好，零样本克隆音色，32GB 卡可跑，首选。
  - **GPT-SoVITS v2**：需要自己录几分钟目标音色做克隆，角色固定、要专属嗓音时用。
  - **ChatTTS**：对话感强、出活快，但情绪控制弱，适合配角/旁白。
  - 三者都本地跑，不花钱；先按角色戏份选一个，不要三个都装。
- **配乐**：免版权素材（Pixabay Music / YouTube 音频库）起步；要原创再上本地音乐生成模型。
- **剪辑**：DaVinci Resolve 免费版（调色强）或剪映专业版（上手快）。
- **调色**：全片统一加一个 LUT，把不同批次生成的镜头色调对齐，否则观众会看出"分段拍"的痕迹。
