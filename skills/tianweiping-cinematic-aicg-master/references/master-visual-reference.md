# 大师视觉参数库

> 不是"参考XX风格"，而是把每个大师拆成可直接写进Prompt的视觉参数。

---

## 一、摄影大师（灯光/构图/色彩）

### 罗杰·迪金斯 Roger Deakins
**代表作：** 《银翼杀手2049》《1917》《老无所依》
**可执行参数：**
- 单一强光源，大面积暗部留黑
- 冷暖对撞：橙色火光 vs 蓝色阴影，饱和度压低
- 体积光穿过烟雾/灰尘，丁达尔效应明显
- 人物常被放在画面1/3处，大量负空间
- 镜头运动极其克制，几乎全是缓慢横移或固定
- **Prompt关键词：** "罗杰迪金斯式低照度""单光源冷暖对撞""大面积负空间"

### 维伦纽瓦 Denis Villeneuve
**代表作：** 《沙丘》《降临》《银翼杀手2049》
**可执行参数：**
- 极端大小对比：人 vs 巨物/旷野/火焰
- 对称构图，宗教感
- 色调统一到近乎单色（沙丘的橙、降临的灰蓝）
- 烟雾/沙尘作为画面主体元素
- **Prompt关键词：** "极端大小对比""对称构图""沙尘体积感"

### 是枝裕和 Hirokazu Koreeda
**代表作：** 《小偷家族》《无人知晓》
**可执行参数：**
- 自然光为主，不用戏剧性打光
- 日常生活场景里拍情感爆发
- 人物不看镜头，看别处/看手
- 留白：情感高潮时反而给空镜头（窗外、走廊）
- **Prompt关键词：** "自然漫射光""日常场景中的克制情感""空镜头留白"

### 安德鲁·怀斯 Andrew Wyeth（画家）
**代表作：** 《克里斯蒂娜的世界》
**可执行参数：**
- 空旷荒原+一个渺小孤独的人
- 土褐、灰绿、暗金的压抑色调
- 风、枯草、远处的农舍
- 人物背对或侧对，不看观众
- **Prompt关键词：** "怀斯式空旷孤独""土褐压抑色调""渺小背影在旷野"

## 二、动画/电影大师（叙事/节奏）

### 新海诚 Makoto Shinkai
**代表作：** 《你的名字》《天气之子》
**可执行参数：**
- 天空占画面1/2以上，云层极有层次
- 逆光+镜头光晕（lens flare）
- 蓝橙互补色对比
- 雨后地面反射所有光源
- 风、光、云作为角色情绪的外化
- **Prompt关键词：** "新海诚式天空云层""逆光镜头光晕""雨后地面反射"

### 宫崎骏/吉卜力
**代表作：** 《萤火虫之墓》《千与千寻》
**可执行参数：**
- 温暖的手绘质感，色彩偏饱和但不刺眼
- 日常细节极丰富：食物、衣物、旧物件
- 自然元素（风、树、水）有呼吸感
- 悲伤时不用惨黑色，用温暖的色调包裹
- **Prompt关键词：** "吉卜力手绘温度""日常物件细节""暖色包裹悲伤"

### 今敏 Satoshi Kon
**代表作：** 《红辣椒》《千年女优》
**可执行参数：**
- 极快的匹配剪辑（match cut）
- 现实与梦境无缝切换
- 特写镜头有压迫感
- 色彩浓烈但有序
- **用在：** 梦境、回忆、精神世界的片段

### 皮克斯 Pixar
**代表作：** 《寻梦环游记》《心灵奇旅》
**可执行参数：**
- 皮肤次表面散射（耳朵、鼻子透光）
- 汗水晶莹、毛孔可见
- 情感节拍精确：铺垫3秒→爆发1秒
- 道具承载情感（一朵花、一张照片）
- **Prompt关键词：** "皮肤次表面散射""汗珠高光""道具特写承载情感"

## 三、救火/灾难片参考

### 《勇往直前》Only the Brave (2017)
**吸收：**
- 真实的消防装备磨损：焦痕、汗渍、烟灰洗不净
- 不拍英雄时刻，拍疲惫时刻：坐在路边喝水、擦汗、发呆
- 火不是背景板，是有体积、有声音、有重量的活物
- 结尾列队看火的长镜头——不拍脸，拍背影

### 《烈火英雄》(2019)
**吸收：**
- 水炮喷射的水柱在火光中的形态
- 浓烟的黑色体积感
- 战斗服被烤焦的纹理

### 《救火英雄》(2014, 港片)
**吸收：**
- 香港摩天楼火场的垂直空间感
- 烟雾在管道中的流动

## 四、当代AICG/概念艺术家

### Simon Stålenhag
**风格：** 科幻废土+日常风景结合，油画笔触
**参数：** 低饱和色调、巨型物体压在小人物身上、朦胧雾气、怀旧感

### Beeple (Mike Winkelmann)
**风格：** 超现实巨型场景
**参数：** 极端大小对比、几何对称、霓虹色+暗底

### 国产动画《雾山五行》
**吸收：** 水墨笔触+武侠动作
**参数：** 留白构图、墨色浓淡、动作线写意

### 《长安三万里》
**吸收：** 唐代山水的留白、壮阔山河与人的渺小
**参数：** 仿宋画构图、远山层次、大气透视

## 五、可执行视觉检查清单

每次出关键帧前对照：

### 场景设计
- [ ] 这个场景有3层纵深吗？（前景/中景/远景）
- [ ] 有大气透视吗？远处的东西应该更淡更蓝
- [ ] 光源方向统一吗？全片主光从哪边来？
- [ ] 地面有反射吗？湿地面、玻璃、水面都能增加质感
- [ ] 场景里有生活痕迹吗？（不是空的舞台，是有人用过的空间）

### 角色设计
- [ ] 角色有职业痕迹吗？（疤、磨损、老茧、污渍）
- [ ] 服装不是崭新的，写具体哪里破/脏/褪色
- [ ] 表情不是摆拍，是刚经历过什么的瞬间
- [ ] 手画对了吗？（AI常画错手，特写手要检查）

### 灯光
- [ ] 主光源只有一个吗？（多光源会乱）
- [ ] 有明暗交界线吗？（伦勃朗光的核心）
- [ ] 暗部是死黑还是有颜色？（应该有冷色反光）
- [ ] 有没有体积光/丁达尔？（烟雾/灰尘里的光束）

### 留白
- [ ] 人物占画面比例合理吗？（抒情戏应该<1/3）
- [ ] 有没有呼吸空间？（不要满屏塞满）
- [ ] 情感高潮时敢不敢给空镜头？（窗外、墙、地面）
- [ ] 结尾敢不敢停？（不要急着切走）

### 视觉传达
- [ ] 这一帧不用旁白，观众能看懂情绪吗？
- [ ] 色彩在讲故事吗？（冷=孤独，暖=希望，橙=危险）
- [ ] 第一眼看到什么？第二眼看到什么？（视觉层级）
- [ ] 这张截图能当海报吗？（单帧审美测试）

## 六、艺术性 × 商业化平衡

用户要的是"艺术性的商业化作品"——不是纯艺术片没人看，也不是纯流水账没美感。

**公式：**
```
艺术外壳（光影/构图/留白/笔触）
+ 商业内核（清晰的情感线/一个明确的泪点/一个金句/一个记忆点）
```

- 艺术片：留白多、节奏慢、没有明确结局 → 观众看完说"好美"但不记得
- 商业片：满屏信息、节奏快、情绪直给 → 观众看完说"好燃"但3天就忘
- **好作品：** 用艺术的壳讲一个最朴素的故事（一个人冒死救了一个孩子），观众既觉得美，又被打动

**永远不要为了艺术而牺牲故事，也不要为了商业而堆砌特效。**
