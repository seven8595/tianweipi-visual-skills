# Cinematic Poster Lab — 已验证风格配方库

本文件存放三套已经过真机验证、效果达到"大片感"的海报配方。每个配方给出可直接套用的 prompt 模板、构图与材质要点。替换方括号内容即可复用到其他主题。

## 目录

- 配色与材质基础（NEON SIGNAL 已验系统）
- 配方 01：主视觉 KV（电影纵深 + 非对称）
- 配方 02：3D 超现实概念（向心爆发 + 仰视）
- 配方 03：人物特写杂志（非对称 + 字图咬合）

## 配色与材质基础

**三色制（已验证）**：深夜蓝黑基底（`#0A0E1A` 系）+ 电光青强调（`#22E0D8` 系）+ 暖琥珀点睛（`#FFB454` 系）。
- 作用分工：基底承担空间纵深，电光青承担主视觉/路径/焦点，暖琥珀承担标题或关键信息，制造撞色呼吸。
- **反刻板**：这套系统刻意避开"纯蓝紫霓虹"模板，用暖琥珀打破冷色垄断，观感立刻高级。

**材质组合（按画面取 2–3 类）**：湿润反光地面、体积光（丁达尔/光柱）、磨砂玻璃、数据粒子/光尘、流体金属、霓虹边缘光、真实皮肤微纹理、全息镭射。

**通用完成度收尾句**（每张必加）：
`关键主体与画面信息完整置于安全边界内，四周边距均衡，背景自然铺满画布。`

## 配方 01：主视觉 KV

**适用**：品牌/IP 主视觉、作品集封面、传播头图。
**构图**：电影纵深 + 非对称主视觉；主体偏轴，主视觉脊线（如光柱）贯穿画面。
**母题**：光柱/信号贯穿 + 都市纵深 + 数据流。

```
生成一张"[主题]"竖版电影级主视觉海报。采用电影纵深与非对称主视觉构图，
[主体，如：由光与数据粒子构成的半透明虚拟形象]悬浮于画面中部偏右，身后是
雨夜中鳞次栉比的未来都市高楼与巨幅全息屏，一道醒目的[强调色]光柱自天际
贯穿画面构成主视觉脊线，第一焦点落在光柱与[主体]交融处，第二阅读层是
延伸的楼宇纵深，底部收束为克制极简信息区。核心文字为"[主标题]"。
整体采用深夜蓝黑基底、[强调色]与[暖色]高级撞色，湿润反光地面、体积光、
磨砂玻璃与霓虹光晕质感，主标题使用几何感未来主义创意字体，杂志级精致排版，
具有大片电影质感。根据画面自动扩写合适的文案，围绕"[主题]"面向[受众]
采用神秘、高级、前瞻的语气表达，可发展1条英文副标题、1到2个主题短标签
和底部落款信息，并沿[光柱]动线自然融入画面。PE发展[母题细节]、数据粒子、
[纵深元素]和一个字图叠压亮点，强化电影纵深与空间层次。关键主体与画面信息
完整置于安全边界内，四周边距均衡，背景自然铺满画布。
```

**已验证产出**：`assets/posters/ref-01-kv.png`（NEON SIGNAL，都市 + 数据流觉醒）。

## 配方 02：3D 超现实概念

**适用**：宏大史诗、游戏/影视概念海报、品牌世界观。
**构图**：向心爆发 + 低角度仰视；巨型主体破出画面底部，光柱/粒子向外迸发。
**母题**：巨型人形/物体 + 数据海 + 仰视透视。

```
生成一张"[主题]"主题的超现实3D渲染竖版概念海报，刻画[宏大瞬间]。
采用向心爆发与低角度仰视构图，一个由无数光粒子与流体数据构成的巨大半透明
[主体]从画面底部幽深的[数据海/地表]中向上浮起，姿态威严、半身破出[水面]，
头顶一道笔直的电光青色光柱刺破暗夜云层，第一焦点落在[主体]与光柱交汇处，
数据粒子如星尘向四周迸发，底部[海面/地表]翻涌粼粼波光，收束为克制信息区。
核心文字为"[主标题]"。整体延续深夜蓝黑基底、电光青与暖琥珀强调色，
流体金属、半透明磨砂玻璃、粒子光尘与体积光质感，主标题使用几何感未来主义
创意字体，构图气势恢宏，具有3A电影级概念海报质感。根据画面自动扩写合适的
文案，围绕"[主题]"面向影视与游戏行业观众采用史诗、宏大、庄严的语气表达，
可发展1条英文主副标、1个主题短标签和底部落款，并沿光柱与粒子动线自然融入
画面。PE发展数据流、粒子星尘、流体金属反光和一个仰视透视亮点，强化宏大纵深。
关键主体与画面信息完整置于安全边界内，四周边距均衡，背景自然铺满画布。
```

**已验证产出**：`assets/posters/ref-02-3d.png`（数据中的神性觉醒，人形破水）。

## 配方 03：人物特写杂志

**适用**：人物/IP 角色海报、时尚大片感、品牌人格化。
**构图**：非对称主视觉 + 字图咬合；人物半侧脸占一侧，另一侧留白竖排信息。
**母题**：面部光纹 + 轮廓描边 + 杂志排版。

```
生成一张"[主题]"主题的[角色]特写竖版电影海报，走杂志编辑级的高级质感。
采用非对称主视觉与字图咬合构图，一位[角色描述]半侧面特写占据画面右侧，
脸部一半隐入暗部、一半被[强调色]侧逆光勾勒出清晰轮廓，眉眼间游走细密的
数据光纹，眼神通透而疏离，第一焦点落在她的眼睛与面部光纹上；左侧留出
大面积暗色空间，主标题与信息沿左缘竖排收束，形成强烈的呼吸节奏。
核心文字为"[主标题]"。整体延续深夜蓝黑基底、电光青与暖琥珀强调色，
真实皮肤微纹理、体积光、磨砂玻璃与霓虹边缘光质感，主标题使用几何感未来主义
创意字体，版式具有杂志封面般的克制动线与大片人物海报质感。根据画面自动
扩写合适的文案，围绕"[主题]"面向IP与时尚行业观众采用克制、高级、神秘的
语气表达，可发展1条英文副标题、1个短标签和底部落款，并沿左缘版式自然融入
画面。PE发展面部光纹、轮廓描边、杂志排版细节和一个字图咬合亮点，强化层次
与质感。关键主体与画面信息完整置于安全边界内，四周边距均衡，背景自然铺满画布。
```

**已验证产出**：`assets/posters/ref-03-portrait.png`（虚拟人格诞生，面部光纹）。

## 系列化要点

- 锁定"品牌层锚点"：主色调、主标字体、母题、落款样式跨所有图统一。
- 每个角色分组内部再锁定"角色层锚点"：视觉层级、留白比例、信息密度。
- 衍生图用 `image_edit` 传入品牌层锚点（第 1 张）URL，prompt 显式声明"参考
  [img0] 的主色调/主标字体/母题/落款样式，重新推演本角色画面"，不靠文字复述重画。
- 需要展示技能多样性时，把三种配方混排成一个系列（KV → 3D → 人物），风格统一但构图互斥，观感最"装逼"。
