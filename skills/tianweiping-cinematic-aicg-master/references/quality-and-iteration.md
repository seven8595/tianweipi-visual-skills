# 质检与迭代（出图后必做）

生成不等于完成。这一份是把"惊艳"从偶然变成稳定复现的最后一关：逐张质检 → 识别 AI 味 → 对症改稿 → 选片交付。

## 一、出图后逐张质检（对照五支柱）

拿到图先对着这张清单过一遍，任一不过就改：

- **构图**：有明确动势吗（偏轴/动势/破格/仰视）？还是死板居中？
- **配色**：是不是三色制（深底+强调+暖色点睛）？有没有变成俗套纯蓝紫全屏？
- **材质**：≥2 类真实材质落点吗？还是平涂塑料感？
- **排版**：三层阅读清晰吗？主标题够不够大、够不够有记忆点？
- **母题**：主题母题（光柱/数据流/楼宇）是否贯穿全图，而不是零散装饰？

## 二、AI 味识别（装逼成败的关键）

逐图扫这些破绽，命中即视为"一眼 AI"，必须改：

| 症状 | 识别点 | 修法 |
|---|---|---|
| 文字乱码 | 主标题缺笔、伪字、字母粘连、多余小字 | 主标题缩短（≤2 个英文词最佳）；只框定核心文字；让 PE 扩写的短标签字号小、位置靠边 |
| 人物畸形 | 多指/缺指、五官歪斜、眼神空洞 | 特写构图改远景/半身；或加"人物五官结构自然、手部五指关系自然"完成度句 |
| 装饰同质 | 满屏同款气泡/光斑/便签，机械重复 | prompt 里加"装饰形态多样、克制使用、不堆砌同质符号" |
| 呆板居中 | 主体正中央、左右对称、无动势 | 换非对称/偏轴/对角线构图，加一个灵动动作 |
| 单薄发空 | 背景一片空、无纵深、无材质 | 补远景纵深（楼宇/数据海）+ 补材质（湿润反光/体积光） |
| 堆砌杂乱 | 元素太多、信息拥挤、无层级 | 砍装饰、收窄三色制、信息按语义成组、加留白 |

## 三、"不够惊艳"时的改稿方向库

用户说"不够高级/不够大片/有点普通"时，按症状选改法，不要笼统重抽：

- **像模板** → 暖琥珀撞色加重（5–10%）、换非对称构图、加破格出画动作。
- **太空** → 加电影纵深（远景城市/数据海翻涌）、加材质层次（反光地面+体积光）。
- **太花** → 砍装饰、收窄三色制、信息成组、增大留白呼吸。
- **文字弱** → 主标题缩短、字号放大、换更重的创意字体。
- **人物不吸睛** → 加侧逆光轮廓、面部光纹、眼神光。
- **整体平** → 提高明暗对比、加一道体积光/光柱作为视觉脊线。

## 四、选片标准

- 同批出 2–4 张时，选：**第一眼焦点最明确、配色最克制统一、母题最突出**的那张作品牌层锚点。
- 淘汰：文字乱码、人物畸形、装饰同质化、居中呆板的。
- 用户已反馈某张不满意时，以该张为基准做局部改稿，不整张重画丢失已有优势。

## 五、交付前最后一遍

- 主标题无乱码、无裁切、可读。
- 画幅正确（3:4 / 9:16），无多余边距失衡。
- 无平台名、无水印、无编造的事实文字。
- 逐张 `present_files` 交付，单张交付成功后再做下一张。

## 实战经验（已验证）

- 主标题用英文/拉丁字符渲染更稳；中文标题要短、字少、字号大，避免长句中文糊字。
- 暖色点睛只占 5–10%，多了就俗；电光青 15–20% 是主强调。
- 竖版比例：3:4 用 2048×2731；9:16 用 2048×3641。
- "根据画面自动扩写"这句开放引导，能让 PE 自然补出副标题/短标签/落款，比自己死写更自然，但核心主标题必须自己用引号钉死。
