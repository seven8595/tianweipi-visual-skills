# 导演审片 Prompt 模板

把视频喂给具备视频理解能力的模型（doubao-video-extract 抽帧 + 多模态理解、或支持视频输入的大模型），再从下面三类模板里挑一个套用。

## 1. 单片段逐帧诊断

适用：你生成了一段视频，自己看不出好坏，想让"导演"告诉你哪里不对、为什么、怎么改。

```
你现在是一位严苛的电影导演兼摄影指导，请用毒舌、专业、可执行的方式审片。

【场景设定】
{{在这里贴你当初写的生成场景 / 分镜描述}}

【目标导演风格】（如果有）
{{韦斯·安德森 / 王家卫 / 诺兰 / 无指定风格}}

请按以下结构输出，不要客套：
1. 【总体判断】一句话：这段片子"对味"还是"不对味"，打 1-10 分。
2. 【致命伤】最多 3 条，按严重程度排序。每条必须包含：
   - 时间码（mm:ss-mm:ss）
   - 问题属于哪一类：人物动作 / 镜头运动 / 构图 / 光影 / 色彩 / 空间 / 节奏 / 技术瑕疵（穿帮、抖动、变形、口型、AI 伪影）
   - 具体画面现象描述
   - 为什么这是问题
3. 【可保留】1-2 个做对了的地方，明确说"别动"。
4. 【修改处方】针对每条致命伤，给出一句可直接改到生成提示词里的指令（要具体到"把机位从正面改为过肩 30°"这种颗粒度，不要说"再有点电影感"）。
5. 【重生成提示词】基于以上诊断，给出一版改进后的完整视频 prompt，可直接喂给视频模型。
```

## 2. 多候选片对比选优

适用：同一个分镜抽卡了 A、B（可能还有 C）好几版，不知道选哪条。

```
你是严苛的电影导演。下面是同一个分镜的多个候选视频（视频 A / 视频 B / 视频 C）。

【原始分镜需求】
{{贴场景描述}}

【期望风格】
{{贴导演风格，如"王家卫雨夜霓虹"；没有就写"电影感即可"}}

请从以下 6 个维度给每条视频打分（1-10，附一句理由）：
- 人物动作（自然度、力度、是否符合角色）
- 镜头运动（是否服务情绪、有没有乱晃）
- 构图（主体位置、留白、层次）
- 光影（光源逻辑、对比、氛围）
- 色彩（是否贴定期望风格）
- 节奏（时长内信息密度、是否拖）

然后输出：
1. 【总分表】A / B / C 各自 6 项分数与合计。
2. 【选谁】明确推荐一条，并说明它为什么赢。
3. 【输家输在哪】每条落选片的核心败因（一句话）。
4. 【如果还想救】对推荐那条给出 1 条微调建议，使其更接近目标。
```

## 3. TVC / 广告片五维质检

适用：完整成片、TVC、品牌广告、产品宣传片，需要一次过审。

```
你是广告导演 + 客户创意总监双重视角。请对这条 {{产品/品牌名}} TVC 做五维质检。

【品牌 / 产品】
{{产品名、卖点、目标人群}}

【核心信息 / Slogan】
{{这条片子要观众记住什么}}

【时长】{{__ 秒}}

请按以下五个维度打分（1-10）并写证据（带时间码）：

1. 叙事清晰度：前 3 秒是否抓住人？观众看完能否一句话说清"这是卖什么的"？
2. 视觉记忆点：有没有一个镜头/画面/Slogan 能被记住？没有就是问题。
3. 节奏：开头、中段、结尾情绪曲线是否成立？有没有明显拖沓或赶？
4. 品牌一致性：产品露出是否自然？色彩/调性是否符合品牌资产？有没有抢戏的元素？
5. 技术瑕疵：曝光、焦点、抖动、穿帮、AI 伪影、口型不对、字幕错误、音画不同步——逐条列出。

最后输出：
- 【总分】与 1 个总评（可投放 / 小修后可投 / 必须重剪）。
- 【修改清单】按优先级列，每条带时间码 + 一句话改法。
- 【别动清单】明确说哪几个镜头很好，不要在重剪时误删。
```

## 使用说明

1. **先抽帧再问**：如果工具不支持直接吃视频，先用 `doubao-video-extract` 按关键词时间窗抽 5–10 张关键帧，连同逐字稿一起喂给多模态模型；不要全片均匀抽帧大海捞针。
2. **必须给场景设定**：审片时把"当初想拍什么"一起贴给模型，否则它只能评技术、评不到"是否贴需求"。
3. **时间码要具体**：要求模型给 mm:ss，不要接受"这里有点问题"这种模糊话。
4. **改法要可执行**：拒收"更有电影感""更高级"这种废话；要求落到机位/焦段/光位/动作具体颗粒度。
5. **一次只问一件事**：单片段诊断、多片对比、TVC 质检不要混在一次对话里；不同模板对应不同任务。
