# Skill Catalog — 全量技能索引

本文件是所有已安装技能的**分类索引**。用途：
1. 用户问"你能做什么/有哪些能力"时，按类别列出并简要说明。
2. 接到新任务时，先在这里查有没有对应专用 skill，有就先 Read 该 skill 的 SKILL.md 再动手。
3. 所有 skill 的根目录见系统配置；本文件只做索引，不复制具体规则。

## 使用规则

1. **先查本表，再动手。** 接到任务先在这里搜关键词，有对应 skill 就先 Read 该 skill 的 SKILL.md。
2. **skill 根目录**：所有 skill 都在以下四个根目录之一：
   - `.skills`（系统预装）
   - `.user_skills`（用户自定义）
   - `C:\Users\seven\Doubao\skills`
   - `C:\Users\seven\.agents\skills`
3. **插件 skill** 以"（插件）"标注，在 installed-plugins 中注册，调用前先 Read 对应 SKILL.md。
4. **本表不是执行规则**，只是索引。具体操作以各 skill 自己的 SKILL.md 为准。
