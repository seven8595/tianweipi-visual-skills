# 模型选型对比

## 0. 默认通道：本地（不可动摇的第一顺位）

| 项 | 值 |
|---|---|
| 算力 | 本机 RTX 5080（16GB） |
| 生图栈 | ComfyUI + Flux.1-dev fp8 |
| 视频栈 | ComfyUI + MiniMax H3（int8 + turbo 8 步） |
| 超分 | Real-ESRGAN ncnn vulkan 逐帧 / ffmpeg Lanczos 快路径 |
| 费用 | 0（只耗电） |

**默认不烧云端 API。** 需要云端时，先说明理由（本地做不到什么）和预估费用，用户同意后再执行。

**本地三条已验证边界**：
- Flux dev **CFG 必须 = 1.0**（guidance-distilled，>3 崩图）
- 16GB 显存跑不动 4K，4K 靠原生小图 + 超分，或 Real-ESRGAN 逐帧
- ComfyUI 缺 ControlNet（MLSD/Lineart）与 Architecture LoRA，**线稿精确控制本地做不了** → 这类任务才是云端/节点画布的真实理由

---

## 1. 比哪四件事

| 维度 | 怎么量 | 注意 |
|---|---|---|
| **速度** | 实测单次推理耗时 | 官方模型常驻热启动；社区模型可能冷启动 |
| **成本** | 本地 = 电费；云端 = 按次或按 GPU 秒 | 社区模型按算力计费，跑几次看实际 metrics |
| **质量** | **同一条 prompt 跑多个模型**对比输出 | 质量是主观的，**匹配用途，不看排行榜** |
| **能力边界** | 看输入 schema：参考图 / mask / 画幅 / 多图输入 / 流式 / 输出格式 | 有 ControlNet / mask / 参考图 = 控制力最强 |

---

## 2. 关键取舍

| 想要 | 选什么 | 代价 |
|---|---|---|
| 最低成本 | 本地跑小模型 / 蒸馏版 | 慢、质量低 |
| 最低延迟 | 官方模型或 turbo / schnell 变体 | 单次更贵 |
| 最高质量 | pro / max / 质量档 | 慢且贵 |
| 最大控制力 | 支持 ControlNet / mask / 参考图的模型 | 输入配置更复杂 |

---

## 3. 选型流程（五步）

1. **明确约束**：本地还是可上云？预算？画幅？要不要精确结构控制？
2. **列候选**：本地候选从已装模型里挑；云端候选才需要浏览模型库
3. **抓 schema**：比输入输出能力（参考图 / mask / 画幅 / 多图 / 流式）
4. **查价**：本地算电费；云端看官方定价或实际 metrics
5. **小批量实测**：**同一条 prompt** 跑各处，比对输出，再决定

**不要跳过第 5 步就直接定。** 也不要只看排行榜——排行榜的测试集和你的用途通常不是一回事。

---

## 4. 常见任务 → 通道建议（本机实测）

| 任务 | 首选通道 | 理由 |
|---|---|---|
| 出图 / 改图 / 海报 | 本地 ComfyUI + Flux fp8 | 免费、可控、快 |
| 图生视频 / 短片段 | 本地 H3 | 5 秒 ≈ 60 秒渲染，10 秒 ≈ 180 秒 |
| 超分 / 放大 | 本地 Real-ESRGAN（精修）或 ffmpeg Lanczos（快） | 免费 |
| **需要精确线稿/结构控制** | 云端节点画布（保结构重绘） | 本地缺 ControlNet，做不到 |
| **需要 4K 原生生成** | 云端 | 16GB 显存跑不动 |
| 关键情感镜头的精品片 | 云端（额度允许时） | 风格化更强、运动更流畅 |

**策略**：关键镜头用云端精品，过渡 / 蒙太奇 / 补拍用本地批量。

---

## 5. 硬规矩

1. **不虚构参数**：模型名、镜头词、渲染器词不等于真的用了那个工具
2. **不承诺额度**：云端额度用完要等恢复，别承诺"无限跑"
3. **本地优先不是"绝不云端"**：是"云端要先说明理由和费用"
4. **改过阈值/参数必须复测**：本地量化内核的阈值改了要重跑 `autoloop.py selftest`
5. **结果按用途验收**：选型结论绑定真实产物，不用"应该更快/更好"下结论
