# 可编辑插图转 PPTX

## 功能
把一张图片（参考图/论文框架图/科研插图）重建成可编辑的 PPTX 文件：
- 矢量部件（框、线、箭头、矩形）→ python-pptx 形状
- 位图部件（照片、复杂纹理）→ 裁剪为图片插入
- 文字 → 文本框
- 最终输出可继续编辑的 .pptx

## 前置依赖
- Python 3.x
- python-pptx：`pip install python-pptx`
- Pillow：`pip install Pillow`

## 标准工作流

### 第一步：生成参考图
用生图模型（ComfyUI / MJ / 即梦）生成框架图：
- 提示词模板：`请调用 $ scientific-figure-reference-generator。 根据我提供的论文模块描述，并参考我上传图片的视觉风格，生成一张框架参考图。`
- 关键参数：图片方向、比例（16:9 / 4:3）、语言（中文/英文）、必须保留的术语/公式

### 第二步：转可编辑 PPTX
推荐提示词（直接发给 AI）：

```
不要用任何skill，拆解插图的每个部件为可编辑形状，将适合矢量编辑的部件重绘为形状，其余内容直接裁剪为图片插入，禁止按像素或色块重绘。然后通过 PowerShell 调用本地 WPS 接口在 ppt 中绘制。
```
