# Cinematic Shot Cards — 50镜头提示词库

## 使用方法

1. 根据当前场景需要选镜头类型（转场？对峙？氛围？布光？开场？收尾？）
2. 查 `references/shot_cards.json` 找到匹配镜头
3. 把提示词模板中的 `[角色名]`、`[场景]`、`[情绪]` 替换成实际内容
4. 根据模型适配：
   - **Wan 2.1 / H3 类 i2v**：提示词用于控制动作和运镜，首帧参考图锁定画面
   - **Seedance / 即梦 / 可灵 T2V**：提示词描述完整画面+运镜
5. 不要照搬整段，提取镜头语言结构（机位+运动+光+情绪）即可

## 重要提醒

- 提示词中的时长（4秒/5秒/6秒）是参考，实际受模型限制（Wan2.1约3-5秒，H3约3秒）
- `[角色名]` 必须替换
- i2v 模型不要在 prompt 里写 glow/reflection/flicker（会触发多余特效）
- 极特写（手部/眼睛）在量化模型上容易肢体变形，优先中近景
