# 质量门槛表 —— 阈值怎么定、为什么这么定

> 所有数字来自本机实测标定（Pillow 12.3 + numpy 2.3），不是抄来的。
> **跨 profile 不要比分数。** profile 是「同一类交付物」的意思。

---

## 1. 四套 profile

| profile | 用在 | 关键差异 |
|---|---|---|
| `poster` | 海报、KV、展架 | 分辨率门槛最高（短边 ≥1200），对比度要求高 |
| `product` | 电商主图、详情页 | 高光/暗部最严（各 ≤2.2%），商业图不能死白 |
| `illustration` | 插画、绘本、角色三视图 | 最宽松：允许大面积浅色纸底、允许低对比 |
| `video_frame` | 视频抽帧 | 分辨率门槛最低，噪点容忍度最高（视频编码本身有噪） |

`default` = `illustration`。

---

## 2. 硬门槛（不过就是错，没有商量余地）

| 指标 | poster | product | illustration | video_frame | 为什么 |
|---|---|---|---|---|---|
| `clip_high` 高光溢出比 | ≤ 2.0% | ≤ 2.2% | ≤ 4.5% | ≤ 2.8% | 纯白区块在印刷/屏幕上没有信息，且是不可逆的 |
| `clip_low` 暗部死黑比 | ≤ 3.0% | ≤ 2.2% | ≤ 4.0% | ≤ 4.0% | 同上；商品图的暗部尤其重要（看材质） |
| `over_sat` 过饱和比 | ≤ 4.5% | ≤ 5.0% | ≤ 7.0% | ≤ 5.5% | s>0.90 的区域在大屏上会「烧眼」 |
| `noise_sigma` 估噪 | ≤ 0.026 | ≤ 0.024 | ≤ 0.034 | ≤ 0.032 | 超过就是生成噪点或压缩纹，不是画风 |
| `min_side` 短边 | ≥ 1200 | ≥ 1000 | ≥ 800 | ≥ 512 | 印刷/放大余量 |
| `textsafe` 对比度 | ≥ 4.5:1 且底噪 < 0.10 | 同左 | 同左 | 同左 | WCAG AA，这是国际标准不是偏好 |

**怎么用**：`vqc.py score` 的输出里带 `[硬]` 标记的就是这些。`hard_fail` 必须为 0。

---

## 3. 软指标（合理区间 + 理想点）

打分公式：理想点 100 分，区间边缘 78 分，区间外继续衰减到 0。

| 指标 | poster | product | illustration | video_frame |
|---|---|---|---|---|
| `mean_luma` 平均亮度 | 0.40–0.92，理想 **0.62** | 0.40–0.90，理想 0.60 | 0.38–0.92，理想 0.62 | 0.28–0.86，理想 0.55 |
| `range95` 对比跨度 | 0.42–0.95，理想 **0.74** | 0.34–0.92，理想 0.68 | 0.28–0.92，理想 0.62 | 0.28–0.92，理想 0.62 |
| `mean_sat` 平均饱和 | 0.12–0.62，理想 **0.34** | 0.12–0.62，理想 0.36 | 0.10–0.62，理想 0.32 | 0.08–0.62，理想 0.30 |
| `hue_spread` 色相跨度 | 0–100°，理想 **≤10°** | 0–110°，理想 ≤12° | 0–130°，理想 ≤15° | 0–120°，理想 ≤12° |

**为什么「理想点」不是区间中点**：海报的实际经验值是偏亮、偏高对比、偏低饱和、极窄色相。
区间中点只是"不出错"，理想点才是"好看"。

**为什么 illustration 的亮度上限是 0.92**：绘本/海报大量使用米白纸底，
平均亮度天然在 0.8 以上。用 0.70 的上限会把所有正常作品判成偏亮。

---

## 4. 相对指标（**必须给 --baseline 才能下结论**）

| 指标 | 判读方式 | 阈值 |
|---|---|---|
| `sharp` | 与参考图的梯度能量差（dB） | ≥ 0 dB 视为不劣于参考；< −3 dB 判不合格 |
| `compose` | 启发式：三分点 / 居中二选一 + 边缘能量 + 对称性 | < 60 分才提示，**不作为交付门槛** |
| `plastic_ratio` | 平坦区高频占比 | 与画风强相关，只做提示 |

**为什么清晰度不能用绝对值**：一张极简插图的 Tenengrad 天然低于一张纹理特写，
差 3 个数量级都正常。实测同一套 8 张插图，`log_ten` 从 −3.4 到 −2.6，
但它们清晰度完全一致 —— 都是矢量风格的平滑色块。

---

## 5. 成套一致性（series）

| 指标 | 合格 | 说明 |
|---|---|---|
| 一致性总分 | ≥ 70 | 亮度离散 35% + 饱和离散 25% + 色相集中度 25% + 清晰度离散 15% |
| `luma_std` | ≤ 0.05 | 八张图亮度标准差 |
| `sat_std` | ≤ 0.05 | 饱和标准差 |
| `hue_concentration_deg` | ≤ 25° | 色相圆标准差 |
| `sharp_std` | ≤ 0.35 | 清晰度离散 |

**实测对照**：同一套 8 张绘本插图，未处理时一致性 82.3（luma_std 0.0218，
hue 集中度 8.0°，但饱和离散 0.0319、清晰度离散 0.0905）；
`vfix.py unify` 到参考图后升到 **96.0**（luma_std 0.0006，饱和离散 0.0066）。

## 6. 一次生成多少张

| 场景 | 候选数 | 理由 |
|---|---|---|
| 海报/KV | 4 | 构图差异大，抽到对的概率高 |
| 电商主图 | 4–6 | 要同时满足产品形态 + 信息层级 |
| 插画/分镜 | 4 | 成套要求高，多出的用 unify 拉齐 |
| 视频单镜 | 2–3 | 渲染贵，用 vframe 复检决定 |

**别超过 6 张**：候选越多，人越容易选"最花的那张"，而不是"最对的那张"。
用 `vqc.py pick` 排序，比自己看更稳。
