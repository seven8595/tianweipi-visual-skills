# 症状 → 处方（带实测前后参数）

> 每一条都对应 `vqc.py` 报出来的一个 key。先看是硬门槛还是软指标，再动手。

---

## A. 曝光类

### A1 发灰 / 雾蒙蒙
- **量化**：`range95` < 0.45（理想 0.74）；`p05` 和 `p95` 挤在中间
- **先改提示词**：加"通透、清晰层次、明暗对比明确"；删"柔和、朦胧、雾感"
- **再后处理**：`vfix.py autolevel --black 1.0 --white 99.0`
- **别做**：拉 S 曲线。会把已经到顶的部分推爆

### A2 整体偏亮 / 发白
- **量化**：`mean_luma` > 0.80 且 `clip_high` 接近门槛
- **处方**：`vfix.py autolevel --black 1.5 --white 97.0`
- **根治**：提示词里的"明亮、通透、高调"改成"中间调、光线克制"

### A3 高光溢出 / 死白
- **量化**：`clip_high` > 2.0%（poster）
- **处方**：`vfix.py autolevel --white 96`（把 96 分位映射到 255，收回高光）
- **根治**：删"强光、发光、过曝、逆光光斑、光晕"

### A4 暗部死黑 / 糊成一团
- **量化**：`clip_low` > 3.0%
- **处方**：`vfix.py autolevel --black 3`（抬暗部）
- **根治**：提示词加"暗部保留细节、有微弱补光"

### A5 亮度漂移（视频）
- **量化**：`luma_trend` 绝对值 > 0.002/帧
- **处方**：vframe 定位漂移起点 → **只重出那一段**，别重出整条
- **根治**：锁定种子 + 固定曝光/色温描述

## B. 细节类

### B1 糊 / 细节糊成一片
- **量化**：`sharp`（带 `--baseline`）比参考低 > 3 dB
- **先改提示词**：加"细节丰富、纹理清晰、微距质感"；**降噪强度调低**
- **再后处理**：`vfix.py unsharp --radius 2.2 --amount 120 --threshold 1`
- **别做**：反复锐化。amount > 150 出白边，`clip_high` 会立刻超标

### B2 塑料感 / AI 味
- **量化**：`plastic_ratio` 极低（平坦区几乎没有高频）
- **先改提示词**：加"胶片颗粒、皮肤纹理、纸张质感、布料纹理"
- **再后处理**：`vfix.py grain --amount 4`（**微量**，2–6 之间；超 10 就是加噪）
- **配合**：`unsharp --amount 45 --radius 1.4` 提一点微反差

### B3 噪点 / 色噪
- **量化**：`noise_sigma` 超门槛
- **处方**：`vfix.py chroma --size 5 --strength 0.8` —— **只对色度去噪，亮度不动**
- **别做**：整体高斯模糊/磨皮。会把 B1 直接变成新问题

### B4 分辨率不够
- **量化**：`min_side` < 门槛
- **处方**：`vfix.py resize --long 3840 --sharpen 55`（Lanczos + 补锐化）
- **说明**：纯缩放几乎不耗算力，比 AI 超分省得多；只有关键特写帧才值得上 AI 超分

## C. 色彩类

### C1 颜色花 / 不像一套
- **量化**：`hue_spread` > 90°；`series` 一致性 < 70
- **处方**：`vfix.py unify --ref 最好那张`（真 CIELAB 的均值/方差迁移）
- **实测**：一套 8 张插图，一致性 **82.3 → 96.0**，最低分 89.6 → 94.4
- **根治**：提示词里写死十六进制调色板，别用"暖色调"这种词

### C2 太艳 / 烧眼
- **量化**：`mean_sat` 高 + `over_sat` 超门槛
- **处方**：`vfix.py sat --gain 0.90 --vibrance 0.05`
- **说明**：`vibrance` 只抬低饱和区、不动高饱和区，比整体降饱和更不容易发灰

### C3 发脏 / 颜色浑
- **量化**：`lab_std` 大但 `mean_sat` 不高（颜色多但不干净）
- **处方**：先 `unify` 到参考图，再 `sat --gain 0.95`
- **根治**：减少提示词里形容颜色的词，只留色值

---

## D. 构图类

### D1 主体太贴边 / 被切掉
- **量化**：`compose.border_ratio` 偏高
- **处方**：提示词明确"主体居中，四周留出安全边距"，或改景别（特写→近景）

### D2 主体位置尴尬
- **量化**：`thirds_dist` 和 `center_dist` 都大
- **说明**：这是**启发式提示不是错误**。海报居中、插画偏三分，都对。
  只有当你觉得"看着别扭"时才去改

### D3 文字被图压住
- **量化**：`textsafe` verdict = warn/bad
- **处方**：给文字加 0.75+ 不透明度的衬底，或移到 `bg_busy < 0.10` 的区块
- **实测**：夜青色 `#2E4756` 配米白纸 `#F5EAD7`，对比度 8.19:1，AA 通过 ——
  但底噪 0.167 会判 warn，因为那一块有木纹/颗粒

## E. 视频类

| 症状 | 量化 | 处方 |
|---|---|---|
| 一闪一闪 | `flicker` 帧占比 > 5% | 锁曝光/色温/种子重出该镜；别整条重出 |
| 卡住不动 | `freeze_runs` 占比 > 20% | 检查运动描述是否太弱，加"明显运动" |
| 整体变暗 | `luma_drift` < −0.03 | 结尾几帧重出，或在剪辑里做微调色 |
| 色相跳 | `hue_jump` > 20° | 同场景统一色温描述，别一条里换光位 |

**视频检查顺序**：`extract` → `analyze` → 看 `sheet` 确认 → 才决定重出哪一段。
**绝不要**不看 `sheet` 就凭 analyze 的结论重出 —— 数字会漏掉"内容本身就不对"。

## F. 什么时候该回炉重生成（而不是修）

修图只能修**分布**（亮度/对比/饱和/色相），修不了**内容**：

| 情况 | 该修还是该重出 |
|---|---|
| 亮度/对比/饱和/色调不对 | **修**（vfix） |
| 清晰度略差 | **修**（unsharp，但别过量） |
| 塑料感 | **修**（grain）+ 下次改提示词 |
| 手指数量不对、肢体错位 | **重出** |
| 产品形态错了、logo 变形 | **重出** |
| 构图完全不对 | **重出** |
| 风格完全不是要的那个 | **重出，并且改 shot.py 的槽位** |

**判断口径**：能被一个全局数学变换改好的 → 修；需要改语义的 → 重出。
