# 发片前终检清单

> 导出/上传前最后过一遍。任何一项没过就不要发。
> 这是"最后 5 分钟能救回来"的清单，不是审片——审片在前面已经做过了。

## 一、技术规格（30 秒）

- [ ] 时长和预期一致（不要导着导着多了 2 秒黑场）
- [ ] 分辨率正确（竖屏 1080×1920 / 横屏 1920×1080 / 4K 按需）
- [ ] fps 正确（24/30/60，不要忽快忽慢）
- [ ] 编码 H.264 或 H.265，容器 mp4
- [ ] 文件大小符合平台要求（抖音 ≤4GB，B站 ≤8GB，YouTube ≤256GB）
- [ ] 首帧不是黑帧、末帧不是黑帧（黑帧会被平台压缩算法误判）

## 二、声音（60 秒）

- [ ] 最大音量不爆音（peak ≤ -1dBTP）
- [ ] 背景音乐不会盖过人声/旁白
- [ ] 环境音和画面对位（下雨有雨声、海边有浪声）
- [ ] 没有突然的音量跳变（前一段 -12dB 后一段 -24dB）
- [ ] 结尾不是戛然而止（BGM 淡出 1-2 秒）

## 三、字幕（60 秒）

- [ ] 没有错别字、病句、断句残缺
- [ ] 字幕停留时间够读完（每秒不超过 4 个字）
- [ ] 字幕不挡脸、不挡关键道具
- [ ] 字体在手机小屏上能看清（不要用细体/浅灰）
- [ ] 中英文混排时英文不要乱码

## 四、叙事（30 秒）

- [ ] 前 3 秒有钩子（划走率的生死线）
- [ ] 结尾有落点（不是突然黑屏）
- [ ] 关键信息没有被剪掉（上次审片说"这里不能动"的镜头还在）

## 五、平台适配（按发布目标）

- [ ] **抖音/快手**：9:16 竖屏，前 3 秒无 logo/水印，字幕安全区离边 ≥15%
- [ ] **B站**：16:9 横屏，封面单独做一帧（不要用首帧），时长 ≥30 秒
- [ ] **YouTube**：16:9，加缩略图（1280×720），加章节标记
- [ ] **小红书**：3:4 或 1:1，前 3 秒信息密度要高（小红书用户没耐心）

## 六、AI 片专项（仅 AI 生成片）

- [ ] 闪帧全部修掉（拖时间线逐秒过一遍）
- [ ] 关键道具（手电/望远镜/杯子）前后一致
- [ ] 主角的脸/衣服颜色没有漂
- [ ] 没有相邻两镜画面雷同（观众会以为卡了）
- [ ] 音画同步（口型对得上、动作对得上）

---

## 最后一条

**导出后自己再看一遍导出文件**，不要只看剪辑工程里的预览。导出后压缩、黑帧、音画不同步这些问题，预览里看不到。
