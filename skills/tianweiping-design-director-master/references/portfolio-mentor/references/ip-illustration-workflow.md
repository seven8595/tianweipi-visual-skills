# 角色 IP 二维插画工作流（龙狸宝贝项目沉淀）

适用：已有严格角色设定、需要出系列插画的 IP 项目。不适用：用户还没给任何参考的从零角色设计。

## 一、资料清单（必须先输出，不猜）

| 资料编号 | 用途 | 缺失时 |
|---|---|---|
| 简介大纲 | 性格/世界观/禁忌 | 不开始 |
| 图1、图2 | 角色比例/轮廓/整体最高标准，二选一 | 不开始 |
| 图8、视频9 | 结构核对 | 标记缺失 |
| 视频10 | 手爪/掌心/手背/背部局部 | 标记缺失 |
| 视频11–18 | 动作/表情/角度/场景 | 用静态图替代，标注限制 |
| 图19–27 | 创意启发，不能当造型标准 | 可选 |
| 图28–30 | 画风核对 | 用现有最完整成稿替代 |

读完先输出**已收到/已查看/缺失/矛盾**四态表，再往下走。

## 二、角色锁定表（基于转面图实测，不抄文字设定）

必须从官方转面表（front/side/back/3-4 view）逐项测量，不看大纲文字。字段：

- 头身比（如二头身）
- 主毛色 + 腹/脸渐变
- 犄角：形状、彩虹条纹顺序、**根部靠近耳朵的小绿根**
- 耳朵：形状、内侧色
- 眉眼：眼型、眉弓、鼻、嘴默认表情
- 手：**每只爪数**、手腕条纹、手心脚心
- 胸口：主星位置/大小/数量、小星数量
- 披风：颜色、材质、飘动方向（**不是翅膀**）
- 尾巴：条纹、上翘方向、**背脊彩色背鳍**
- 脚：**每只趾爪数**、鞋/脚底、脚心肉垫形状

未见到的部位标"未知"，不补设定。

## 三、画风二选一（不混）

**路线 A 厚涂绘本**（已验证用于龙狸宝贝）：
- 可见油画笔刷、纸纹、方向性笔触、手绘边缘
- 色彩浓郁但不刺眼
- 适用：大纲写"厚涂/油画/绘本"

**路线 B 柔和治愈**：
- 软边、低对比、毛绒朦胧
- 适用：大纲写"治愈/软萌"

选完在 prompt 里反复强调，不中途换。

## 四、提示词模板（已验证）

```
Children's book thick oil painting illustration, vertical 3:4.
[主体动作与位置]
[角色锁定项逐项列出：彩虹犄角+绿芽、胸口星、红披风布料不是翅膀、4爪手腕条纹、彩虹尾巴背鳍、3趾熊脸拖鞋]
[场景与道具]
[光线方向与时间]
[排除：no text, no watermark, no logo, no signature, no wings, pure 2D, no 3D render]
```

关键排除项必须写：
- `no text, no letters, no watermark`（用户要无文字时）
- `NO wings, NO bat wings, just red cloth fabric`（披风常见被画成翅膀）
- `pure 2D illustration, no 3D render`

## 五、自检清单（每张必查）

- [ ] 犄角根部小绿在不在
- [ ] 手爪数对不对（默认 4）
- [ ] 脚爪数对不对（默认 3）
- [ ] 胸口星位置和发光感
- [ ] 披风是布料还是翅膀（**高频错误**）
- [ ] 尾巴背鳍有没有
- [ ] 有没有意外出现的文字/水印
- [ ] 两张系列作品的光影方向是否一致
- [ ] 比例是否还是二头身（AI 容易拉长）

## 六、客户要求"非 AI 成稿"时

- AI 图只当构思参考，不当最终交付
- 明确告诉用户这张图的性质
- 可以出：构图草稿、色彩小稿、姿势参考、光影参考
- 不能：把 AI 图直接打包成"最终 PNG"交给客户
- 换格式/加噪点/滤镜不能把 AI 图伪装成手绘

## 七、龙狸宝贝具体锁定值（备查）

- 橙毛、二头身、圆腹短腿
- 彩虹犄角（红橙黄绿蓝紫）+ 根部小绿芽
- 红披风布料（不是翅膀）
- 胸口大黄星 + 2-3 小星 + 金粉
- 手腕彩虹条纹带
- 每手 4 白爪
- 彩虹尾巴 + 背脊彩色三角背鳍
- 红底熊脸拖鞋 + 每脚 3 橙黄趾爪
- 椭圆棕粉脚心

邻居变体（蓝/粉/金）是其他角色，不是主角换色。
