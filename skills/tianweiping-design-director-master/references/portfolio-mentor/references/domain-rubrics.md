# 多领域评审细则（V2.0）

审稿前按项目主领域对照本文件。每个项目一个主领域、最多两个辅助领域；不跨领域混用标准。

## A. 原画与概念设计

**重点**：轮廓、形体、透视、明暗、色彩、材质、世界观、生产可用性。

角色按岗位需要展示：造型探索、完整设定、关键视图、动作表情、服装道具、材质与尺度。
场景按岗位需要展示：构图探索、空间关系、动线、光色、建筑道具、局部设计。

检查：不同视图能否对应？设计是否有结构逻辑？
**红线**：没有真实三维模型或制作验证，不得声称已完成建模可行性验证；只一张完成图不得宣称具备完整角色设定能力。

## B. 剪辑

**重点**：信息顺序、叙事节奏、镜头动机、连续性、声音、字幕、色彩统一。

展示完整片段 + 关键时间码说明；剪辑集用于快速展示，必要时附完整作品证明叙事能力。

修改意见尽量定位到时间码：问题位置 → 观众感受 → 调整动作 → 预期作用。
没有可用素材时，先交脚本、素材需求、剪辑时间线，并明确这不是成片。
**红线**：只有静帧只评构图；无音轨不评混音；无法播放不称节奏已验收。

## C. 平面、品牌与包装

**重点**：层级、字体、网格、识别、系列规则、跨媒介应用。

同时展示关键平面稿与真实用途的应用效果；不要只用样机掩盖版式细节。
包装概念图与生产文件分开。
**红线**：未核对刀版、尺寸、工艺、出血、文字信息，不标"可量产"。

## D. 广告与快消品

**重点**：受众、场景、核心卖点、购买动机、产品识别、渠道适配。

建立链路：创意简报 → 单一核心主张 → 主视觉 → 渠道延展 → 验证方案。

快消品检查：品类是否清楚、产品是否突出、包装是否一致、口味是否可区分、食品质感是否可信、货架/电商缩略图/手机端是否可识别。
**红线**：成分、功效、认证、销量必须有依据；虚构品牌标注"概念项目"，不冒充已上市产品；不靠虚构销售增长证明设计有效。

## E. 编剧

**重点**：人物目标、阻力、选择、行动、冲突升级、因果、结局兑现。

按篇幅交付：一句话故事、人物关系、梗概、节拍表、分场、完整场景。

检查：人物是否主动推动剧情？转折是否有铺垫？对白是否各有声音？
**红线**：给修改至少附一处具体重写，不只说"增强戏剧性"。

## F. 导演

**重点**：主题、表演、场面调度、空间、镜头动机、光色、声音、制作可行性。

关键镜头说明：信息/情绪目的、景别、机位、运动、时长倾向、声音、衔接关系。

如实区分：分镜 / 动态预演 / AI 概念样片 / 实拍成片。
**红线**：不能用概念片证明尚未发生的现场执导经验；引用名家只拆解可学的具体方法，不拿名字当质量保证。

## G. 运营策划

**重点**：业务目标、用户、定位、内容机制、执行资源、指标、复盘。

区分：策略、执行样例、真实结果。没数据时交可验证的试验计划。
指标必注：定义、分子分母、时间窗口、数据来源、限制。
**红线**：不得把相关性写成因果；不得凭一张增长截图归功于某项策划；曝光/点击/关注/留存/线索/成交不得混用。
