# 赛博朋克风格关键词

## 色彩
- **底色**：深黑、深海军蓝、炭灰（模拟夜间巨型都市）
- **霓虹点缀**：电光青、热品红/粉、酸绿、琥珀橙、紫
- **原则**：颜色即光——每个彩色元素应自发光，不是装饰
- **对比**：霓虹刺破黑暗，高对比场景

## 光线
- **霓虹为主光源**：霓虹灯不是装饰，是主要照明
- **湿面反射**：雨水/湿表面反射霓虹，产生色散
- **雾霾/雨幕**：广告发光透过烟雾，形成体积光
- **多光源**：复杂照明，色彩 bleeding 和反射

## 环境
- **拥挤都市**：高楼峡谷、垂直城市（阶层通过海拔体现）
- **未来+衰败**：建筑结合未来设计与可见衰败
- **外露基础设施**：线缆、涂鸦、街头艺术
- **对比**：企业光鲜 vs 街头污垢

## 元素
- **义体/植入物**：机械手臂、神经接口、发光义眼
- **全息界面**：漂浮广告、全息投影
- **飞行器/无人机**：空中载具
- **交通工具**：飞行汽车、滑板、摩托

## Prompt 关键词
```
cyberpunk, neon-lit night city, rainy streets, wet reflections, 
electric cyan and hot magenta, holographic advertisements, 
dystopian megacity, chrome and neon, high tech low life, 
blade runner style, volumetric fog, cinematic lighting
```

## 适用场景
- 未来都市、雨夜、高科技低生活、反乌托邦
- 不适合：古风、田园、明亮温暖场景
