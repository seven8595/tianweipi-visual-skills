# 斯皮尔伯格风格关键词

## 标志性技法
- **Dolly Zoom（眩晕推拉）**：后拉同时前推，制造恐惧感（《大白鲨》海滩镜头）
- **Spielberg Face（敬畏特写）**：缓推近角色敬畏反应的脸，让观众代入惊奇
- **Spielberg Oner（长镜头）**：不超过3分钟的跟拍长镜头，无缝完成场景

## 构图
- **多层纵深调度**：前景/中景/背景同时承载叙事信息（如《大白鲨》布罗迪恐惧的脸+背景鲨鱼攻击）
- **儿童/弱势视角**：相机放在儿童或弱势角色视线高度
- **特写起幅**：从特写开始拉回揭示环境，制造惊奇

## 光线
- **God Light（神之光）**：强背光/高对比度光源，产生可见光束和轮廓分离
- **用途**：敬畏、启示、神圣感、宏大氛围
- **来源**：窗户、车灯、手电筒、外星发光、任何强动机光源

## 镜头运动
- **流体跟踪**：跟角色运动，相机从不为自己而动
- **动机驱动**：跟随动作/视线，不是炫技
- **动态摇臂**：增强情绪冲击

## Prompt 关键词
```
Spielberg style, dolly zoom, god light, backlit silhouette, 
multi-layer depth staging, tracking shot, awe-inspiring face close-up, 
child's eye level, cinematic wonder, 35mm film, warm golden hour
```

## 适用场景
- 冒险、敬畏、大场面、儿童视角、史诗感
- 不适合：都市暧昧、阴郁压抑、赛博朋克
