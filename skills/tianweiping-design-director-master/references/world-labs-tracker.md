# World Labs（李飞飞）追踪

## 触发时机
用户提到以下任一主题时使用本 Skill：
- 李飞飞、AI 教母、空间智能（Spatial Intelligence）
- World Labs 公司及其模型/产品：Marble、Atlas、RTFM、Spark、R2S2R、World API
- 世界模型、3D 世界生成、从图片/文字生成可探索 3D 场景
- 这些产品的**免费 / 收费 / 订阅价格 / 值不值得用**

## 核心原则：先查证，再作答
**模型和定价时效性极强，禁止直接依赖本 Skill 的快照回答"最新"。**
- 快照仅代表记录当天的状态，作为背景与对比基线。
- 作答前必须用下面的官方信源核实最新状态，尤其是"最新模型是什么"和"当前价格"。
- 如果用户要的是"最新/今天发布"，必须以实时检索结果为准，快照只作参考。

## 权威信源（按优先级）
1. **World Labs 官方博客**：https://www.worldlabs.ai/blog —— 模型发布、技术报告、产品更新的一手来源。
2. **Marble 官方文档 / 定价页**：https://docs.worldlabs.ai/api/pricing 与 https://docs.worldlabs.ai/marble/models —— 当前真实定价、积分消耗、套餐档位。
3. **World Labs 官网**：https://www.worldlabs.ai —— 公司动态、产品入口。
4. **权威科技媒体**（用于交叉验证与时效确认）：凤凰网科技、36氪、智源社区、InfoQ、机器之心等。
5. 可用 `general_search` 检索"World Labs 最新模型 / 定价 / 收购"等关键词补充。

## 标准工作流
1. **识别需求**：用户要"最新模型"、"是否免费"、还是"怎么用/值不值"？
2. **实时检索**：对"最新模型""当前定价"用官方文档 + 搜索做一次核实，不沿用旧结论。
3. **区分产品线**（不同产品免费策略不同，务必分开答）：
   - **Marble**（商业产品）：有免费版/付费订阅，分别列档位与限制。
   - **Atlas**（最新旗舰世界模型）：早期访问阶段，通常不向公众开放、无免费通道。
   - **RTFM 等研究预览**：面向研究社区公开，与商业产品免费逻辑不同。
4. **免费/收费判断**：明确说清"哪部分免费、哪部分收费、免费额度多少"，结合用户实际目的给出建议。
5. **时效标注**：回答中注明数据获取时间；若与快照不符，以新信息为准并更新快照。
