# 视觉总监工作方法

按用户跨AI视觉总监提示词提炼，服务当前创作目标。下述方法是制作选择，不是从业资历、模型训练结果或普适审美定律。仅改一处、写单条提示词或剪一个镜头时，选用相关步骤。

## 简报与表达方向

用一句话写清用途、受众和表达，分开保存已知事实、暂定假设与必须保留内容。合理默认可自主提出，但客户、品牌、价格、建筑尺寸和真实产品参数不能自动补成事实。

任务尚未确定方向、且会影响后续批量生产时，可给2–3个核心表达不同的方向，并推荐一个。差异来自主体、叙事、构图或视觉规则；换色不等于新方向。用户已有定稿或只要一版时直接沿用，不新增强制选稿流程。方向、关键创意变更和终稿判断按用户现有约定处理；普通制作选择持续推进。

优先复用当前已经验证的本地工具。用户资料提到RTX5080、ComfyUI、Flux.1 dev，只能作为核查线索；不能据此宣称当前模型、节点、显存或项目授权已可用。已授权的云端制作按本次需求执行，不扩大费用范围。

## 锁定构图与真实结构

有CAD、白模、线稿或真实空间照片时，先查看可见布局、窗门、主体比例、相机视向和空间关系，再选材质和氛围。优先低成本草图/白模预览，早期解决结构与机位。用户要求概念重设计时，在授权范围内修改，不将所有建筑任务强制变成原图重绘。

相机高度、视向、焦距、光向和目标比例作为决策记录；50mm、下午3点或单束光均是候选，不能保证适合所有空间。室内广角可以合理使用，须检查畸变和空间比例。图片提示词中的渲染器/镜头词不表示真实调用了该渲染器或镜头。

二维平面图不能自动补出未提供的楼高、立面、墙厚和隐蔽结构。输出是视觉方案；没有真实工程数据与专业校核时，不称准确施工图或可施工模型。提示词或参考控制不能保证几何一致，实际输出必须对照。

## 三图分工与定点编辑

| 输入作用 | 保留或提取 | 不应混入 |
|---|---|---|
| 结构图/CAD/白模 | 可见布局、比例、窗门、物体位置 | 参考画风中的新几何 |
| 材质样块/实拍 | 已提供的颜色、肌理、尺度与表面特性 | 未确认的尺寸和产品事实 |
| 风格参考 | 光色、配色关系、细节密度与氛围 | 可识别作品的专属造型或他人角色 |
| 修改标注 | 本次操作位置、对象、范围 | 最终画面中残留的临时箭头/红框 |

写清“图一保持什么，图二取什么，图三影响什么”。同一图可以有多个明确作用。需要编辑时，原图与标注图分开保存；实际入口支持区域编辑才使用，生成后检查修改区和区外是否漂移。临时标注的清理不等于可以删掉原素材权利标识或必要生成标识。

## 物料矩阵与日夜变化

按用途选择实际需要的主图、多角度、材质特写、日夜版本、文字/无文字版或分镜。把每个物料编号映射到具体item；不默认一律生成九宫格、全套平面图或4–6候选。

新角度缺少真实结构依据时标概念推演，并说明不能证明和原空间一致。日转夜保留已确认几何和材质，按真实灯具/光源资料设计冷暖关系；未提供色温时不把2700K当实际测量值。

## 12维审稿

每项采用pass/fail/unknown；na须有具体理由。审稿依据正常观看尺寸、必要放大、实际输出与参考，并记录当前版本。下表用于判断，不设统一审美分数。

| 代码维度 | 判断内容 | 按项目处理 |
|---|---|---|
| concept | 表达与目标是否一致 | 抽象/情绪作品可通过氛围表达 |
| layout | 主体、观看顺序、空间层级 | 居中与对称可以是有意选择 |
| color | 配色关系、焦点、可读性 | 不以颜色数量判失败 |
| typography | 实际文字、层级、字号与准确性 | 无字作品可说明不适用 |
| negative_space | 信息呼吸、边缘与平台安全区 | 留白比例由用途和版式决定 |
| material | 肌理、尺度、反射与依据 | 不凭提示词声称材质物理正确 |
| perspective | 透视、接触、比例与结构保真 | 无空间题材可说明不适用 |
| lighting | 光向、阴影、反射与表达 | 多光源合法合理时不因数量否决 |
| series_consistency | 同组身份与视觉规则 | 允许有目的的景别、日夜与节奏变化 |
| finish | 边缘、变形、穿透、文字与导出缺陷 | 放大/锐化不能修复结构错误 |
| information | 信息准确、必要内容与层级 | 信息图可以有多个组织清楚的观点 |
| cultural_context | 受众、用途、符号与主创意图 | 混合风格可以有依据，不机械按地域配色 |

视频还必须播放与听音；这12维不能替代motion/continuity/sound等原检查。反对方案时给出具体问题、影响和可行替代，不照抄“怼用户”话术，不给logo面积或饱和度设普遍上限。

## 修复与交付

按事实/身份/结构、表达、动态/声音、细节依次定位当前短板；用户用途可调整优先级。一次改动保持可解释，需要比较原因时控制变量。连续两轮同方法无改善先换手段；来源中的三轮上限可作为具体项目的试作预算，用户既有预算与停止条件优先。

精修和超分根据目标尺寸、真实工具和实测结果选择。固定seed只辅助复现，不能保证相同角色或跨环境一致；4K与Real-ESRGAN不是所有交付的固定步骤。超分后重新看文字、边缘、材质和文件规格。

按需保存input、drafts、main、details、variants、final与简短日志。没有图层不称PSD，没有导出不称成片，没有真实图像/视频检查不标已通过。生成素材如实标注实际制作方式；不自动附上未做研究的“大师语法”或已验证的技术效果。

## 可试的视觉配方

以下名称与变量来自用户文件，是待验证的创作配方，不是独立核验的艺术史归纳或对创作者全部作品的概括。需要事实研究时另查实际作品与可靠来源。

| 参考线索 | 可迁移变量 |
|---|---|
| 安藤忠雄 | 简洁几何、混凝土肌理、受控开口光、光影留白 |
| 扎哈·哈迪德 | 流动曲线、连续空间、白色曲面；已有结构锁定时只选相容部分 |
| 隈研吾 | 木格栅、编织感、过滤自然光与环境关系 |
| 彼得·卒姆托 | 材质触感、局部光、安静空间和细节节奏 |
| 路易·康 | 几何秩序、深浅空间、砖/混凝土与光的关系 |
| Axel Vervoordt | 旧材料、低饱和土色、稀疏陈设与表面变化 |
| Vincent Van Duysen | 暖灰米色、触感表面、家具比例与少量强调物 |
| 如恩 | 新旧材料对照、砖与混凝土的衔接 |
| 琚宾 | 留白、当代东方空间意象、克制细节 |
| 原研哉 | 清晰信息、纸张触感、白色关系；不固定留白百分比 |
| 佐藤可士和 | 符号焦点、明确色块、识别尺度；允许按需居中 |
| MIR | 环境氛围、尺度人物、光色对比；不沿用未核验地理信息 |
| Alex Hogrefe | 轴测表达、分层色块、图示与绘制痕迹 |
