# 视频制作

## 从故事到可生成镜头

先锁定片长、比例、主体卡、场景关系和声音需求。每镜至少记录 SHOT_ID、叙事作用、景别/机位、动作起点与终点、主体运动、摄影机运动、编辑长度、对白/字幕、声音和前后衔接。

主体动作与摄影机运动分开描述。不要同时要求“固定机位”和“持续环绕”。复杂动作不是一律禁止：按真实模型能力拆成易验收的动作阶段，保留用户关键情节。镜头数量由信息与节奏决定，不把所有片子套成同一秒数。

未经指定的短篇漫剧可沿用用户旧规范：9:16、45–75秒、8–12镜；单张图、商业片和长片不套用此默认。优先按当前目标规划节奏，不凭空增加钩子或改写结局。

## 锁定关键帧，再生成运动

有角色或产品连续性要求时，先验收代表性关键帧，再用可用参考方式生成动作。首尾帧须在人物、空间、光线和动作轨迹上可衔接；不要求一个短镜头跨越无解释的场景、姿态或服饰变化。

动作写成“准备 → 发生 → 收势”：例如停稳、伸手取物、手掌包住物体、收回并停顿。根据画面需要控制重心、接触点、速度变化和跟随动作；不堆砌所有动画法则关键词。

记录实际生成长度和编辑使用长度。模型支持的长度不等于成片镜头必须同长；必要时生成带余量素材，再依据已授权剪辑决定使用区间。项目校验模板表示已经选定的时间线片段，未处理的原片需先记录剪入剪出点，不能把原片时长冒充编辑长度。

## 连续性与时间线

同一场景保持角色身份、服装、持物手、道具状态、运动方向和主光。换场、越轴、昼夜变化可以作为有意设计，但要在分镜中说明连接方式。

帧率写为 `24` 或 `30000/1001` 等真实值。时间线采用整数帧、半开区间 `[开始帧, 结束帧)`：

```text
镜头开始帧 = 前镜结束帧 - 与前镜的重叠帧
镜头结束帧 = 镜头开始帧 + 本镜编辑帧数
成片帧数 = 各镜编辑帧数之和 - 各接缝重叠帧数之和
```

硬切重叠为零。两个叠化不能在同一镜内造成未规划的三镜叠加。先把目标秒数转成可表示的整数帧；分数帧率下某些整数秒无法精确实现，说明实际值，不偷偷改变帧率。

## 声音和字幕

对白先实测或试听，再调整时长；字数推算只作预警。字幕按语义断句、与声音同步，留出平台界面安全区。旧漫剧的每句12字是可改默认，不能强删剧情；多人字幕可分轨。

对白清楚后处理音乐与环境声，听检爆音、吞字、响度跳变和结尾截断。平台响度规范需当次核对，不用单一 LUFS 值覆盖所有交付。用户要求无声时明确记录 `audio_required: false`。

## 动态验收

完整播放各镜与导出全片；动态不能只看首尾帧。定位变脸、纹理闪烁、物体漂移、穿透、接触错误、运动突变及口型/声音问题。静止主体的平均像素差不能直接用来判定运动镜头闪烁；如做自动筛查，要考虑运动和遮挡，再回看问题时间段。

补帧前先解决错误动作和身份漂移；补帧可能加重穿透，超分不能补出正确运动。优先修复问题区间、缩小不必要的运动、改参考控制、拆镜或用已授权的合成方法，不重生成整片。

导出后实际探测容器、编码、尺寸、帧率、时长与音轨，并完整播放。探测过不代表已听音或动态通过；硬件编码、HDR、4K均以实际文件与设备验证为准。
