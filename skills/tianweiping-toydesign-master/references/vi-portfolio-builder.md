# VI 作品集快速制作 — 大师级质感版

## 适用场景

用户需要在短时间内拿出一套**看不出AI痕迹、像专业设计师手工制作**的品牌视觉设计作品集。

## AI痕迹诊断 — 必须避免的特征

| AI痕迹 | 表现 | 为什么假 |
|---|---|---|
| LOGO太完美对称 | 几何精确、线条均匀、无笔触 | 专业设计师会保留手工感、不完美 |
| mockup像3D渲染 | 光线均匀、阴影干净、像产品目录 | 真实作品是生活中随手拍的记录 |
| 排版居中模板化 | 一切居中、对称、无个性 | 专业设计师有排版主张，不居中 |
| 没有项目背景 | 只有图，没有客户名/时间/挑战 | 真实作品集有完整项目叙事 |
| 没有设计过程 | 只有最终成品 | 专业作品集展示草图、迭代、探索 |

## 去AI策略 — 大师级质感怎么做

### LOGO去AI
- **强调手绘感**：毛笔飞白、笔触粗细变化、不完美对称
- **强调印章/印刷感**：边缘晕染、墨色浓淡变化、手工盖印质感
- **禁止完美几何**：不要"完美圆形+精确对称"，要有手工温度
- **背景不要纯白**：用宣纸纹理、米黄色调、有质感的底色

### mockup去AI
- **强调真实摄影**：自然光、生活场景、有生活气息
- **禁止产品渲染感**：不要"干净的产品图+纯色背景"
- **加入工作室道具**：铅笔、尺子、咖啡杯、耳机等
- **胶片颗粒感**：不是完美数码摄影，有质感、有温度
- **场景是随手拍的**：不是摆拍的广告，是设计师工作室记录

### HTML排版去AI
- **不要居中对称**：用左对齐、网格系统、不对称布局
- **每本风格要统一**：东方本用衬线+宣纸色，瑞士本用无衬线+纯白，实验本用深色+荧光色
- **加入项目元数据**：CLIENT / YEAR / SCOPE / LOCATION
- **加入设计阐述**：不是只放图，要有设计师的思考

## 三种风格方向（每本独立风格）

### 风格A：东方手工风
- **气质**：安静、克制、有温度、东方美学
- **品牌案例**：茶文化/香道/独立书店
- **LOGO**：手工印章式、毛笔书法感、宣纸纹理背景
- **配色**：米黄 #f5f0e8 / 墨黑 #2a2a2a / 赭石点缀
- **HTML**：衬线字体、居中标题、大量留白、宣纸纹理叠加

### 风格B：瑞士国际主义风
- **气质**：理性、精准、商业感、极致克制
- **品牌案例**：建筑工作室/设计咨询/科技公司
- **LOGO**：字标为主、几何无衬线、左对齐网格排版
- **配色**：纯白 #ffffff / 炭黑 #1a1a1a / 灰阶层次
- **HTML**：无衬线字体、严格网格、左对齐、黑白灰

### 风格C：实验编辑风
- **气质**：大胆、有态度、独立杂志感、打破规则
- **品牌案例**：音乐杂志/独立媒体/文化品牌
- **LOGO**：实验性变形字母、打破基线网格、一个荧光色强调
- **配色**：深黑 #111111 / 白 #f0f0f0 / 荧光黄 #e8ff00
- **HTML**：超大刊头、不对称排版、打破网格、强调色点缀

## 标准产出

每本作品集包含：
- 1个品牌案例（LOGO主图 + 应用场景图）
- 1个完整HTML页面
- 项目元数据（客户/年份/范围/地点）
- 设计理念阐述

## 执行流程

### 第一步：定风格方向
根据用户需求选择1-3种风格方向，每本独立风格。

### 第二步：生成LOGO
用 `image_gen` 生成，prompt里必须包含：
- "不是光滑矢量，有手绘/手工/印刷感"
- "不完美，有笔触变化/飞白/晕染"
- 风格对应的背景质感（宣纸/纯白/深色）

### 第三步：生成应用mockup
用 `image_edit` 基于LOGO延展，prompt里必须包含：
- "不是3D渲染，是真实摄影质感"
- "像设计师工作室随手拍的记录"
- "自然光、生活场景、有温度"
- 加入工作室道具（铅笔/咖啡/耳机等）

### 第四步：组装HTML
每本独立HTML文件，风格和品牌方向统一：
- 东方本：衬线+宣纸色+居中标题
- 瑞士本：无衬线+纯白+网格左对齐
- 实验本：深色+超大刊头+荧光色强调

### 第五步：专业审核清单
生成后必须检查：
- [ ] LOGO不是完美几何？有手工感/笔触？
- [ ] mockup不是3D渲染？有真实摄影质感？
- [ ] 排版不是居中模板？有个性/网格？
- [ ] 有项目元数据？客户/年份/范围？
- [ ] 有设计阐述？不是只放图？

## 关键红线

1. **禁止完美几何LOGO**——必须有手工感、不完美、笔触变化
2. **禁止3D渲染mockup**——必须是真实摄影质感、生活场景
3. **禁止居中模板排版**——必须有个性、网格系统、编辑设计感
4. **禁止只有图没有叙事**——必须有项目元数据和设计阐述
5. **每本风格必须独立**——不要3本都是同一种排版风格

## PPT作品集制作规范（飞书Slides版）

### 设计系统（大师级深色编辑风）

| 元素 | 规格 | 说明 |
|---|---|---|
| 背景 | `rgb(10, 10, 10)` | 深黑，不是纯黑也不是深灰 |
| 主文字 | `rgba(240, 237, 232, 1)` | 米白色，不是纯白 |
| 次文字 | `rgba(138, 133, 125, 1)` | 暗灰米色，正文和说明文字 |
| 分隔线 | `rgba(138, 133, 125, 1)` | 短横线，60px长，不是通栏 |
| 字体 | 微软雅黑 | Windows环境默认 |
| 画布 | 960×540 | 飞书Slides固定 |

### 案例页版式（左图右字）

```
┌─────────────────────────────────────┐
│  01 · COFFEE BRAND     ← 小字标签，letterSpacing=3
│                                     │
│  ┌─────┐   Beano's Coffee  ← 大标题30px bold
│  │     │   咖啡品牌包装系统  ← 副标题12px dim
│  │ 图  │   ──────          ← 短分隔线60px
│  │ 片  │                   ← 说明文字13px dim
│  │     │   DELIVERABLES    ← 交付物标签10px
│  └─────┐   纸袋 · 手提袋 · ... ← 交付物列表12px
│                                     │
│                          07 / 20    ← 页码右下角
└─────────────────────────────────────┘
```

**图片放置规则：**
- 竖图高度固定400px，宽度按原图比例计算
- 图片垂直居中在左侧，左边距80px
- 方形图缩小到320×320，避免文字区超出画布
- 禁止裁剪图片——`width:height`必须对齐原图比例
- 图片和文字区间距80px

### 封面版式（左对齐编辑风）

- 顶部小字标签：`BRAND VISUAL DESIGN PORTFOLIO`，letterSpacing=4
- 大标题两行：第一行米白色bold，第二行暗灰色bold=false
- 下方短分隔线60px
- 署名：田伟平 · Brand Visual Designer
- 右下角年份：2026

### 常见坑（必须避免）

1. **图片被乱裁剪**——img的width:height必须对齐原图比例，否则会自动居中裁剪
2. **文字超出画布**——方形图占宽度大，text_x + text_w 不能超过880（留80右边距）
3. **fontWeight属性不支持**——用 `bold="true"` / `bold="false"`，不要写fontWeight
4. **批量生成XML必须按案例调图片宽度**——不同比例的图宽度不同，不能用统一值
5. **文字颜色太亮**——不要用纯白#fff，用米白rgba(240,237,232,1)更高级

### 交付流程

1. 写XML文件到本地ppt-work目录
2. 逐页用 `+update-slide` 替换（已有幻灯片时）
3. 全部完成后 `+export` 导出pptx
4. 用 `present_files` 交付本地文件+在线链接

### 版式节奏（必须有变化）

大师级作品集不是每页都一样：
- **左图右字页**：占60%，标准案例介绍
- **全屏大图页**：占20%，视觉冲击，展示完整作品
- **双图横排页**：占15%，两个小案例并排
- **章节分隔页**：占5%，超大字号+编号，呼吸感

### python-pptx 关键代码模式

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN
from pptx.enum.shapes import MSO_SHAPE
from PIL import Image

# 空白版式
slide = prs.slides.add_slide(prs.slide_layouts[6])

# 背景色
f = slide.background.fill
f.solid()
f.fore_color.rgb = RGBColor(8, 8, 8)

# 文本框
box = slide.shapes.add_textbox(x, y, w, h)
p = box.text_frame.paragraphs[0]
p.text = "文字"
p.font.name = "微软雅黑"
p.font.size = Pt(14)
p.font.color.rgb = RGBColor(242, 239, 234)
p.font.bold = True

# 短分隔线（用矩形模拟）
line = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, x, y, width, Pt(0.75))
line.fill.solid()
line.fill.fore_color.rgb = RGBColor(60, 60, 60)
line.line.fill.background()

# 图片按比例放置（不裁剪）
def img_fit(slide, path, x, y, maxw, maxh):
    im = Image.open(path)
    w, h = im.size
    r = w / h
    br = maxw / maxh
    if r > br:
        nw = maxw
        nh = int(maxw / r)
    else:
        nh = maxh
        nw = int(maxh * r)
    ix = x + (maxw - nw) // 2
    iy = y + (maxh - nh) // 2
    slide.shapes.add_picture(path, ix, iy, nw, nh)
```

### 常见坑

1. **中文引号嵌套**——Python字符串里用「」代替""，避免语法错误
2. **图片裁剪**——必须按原图比例计算宽高，不能固定宽高
3. **字间距**——python-pptx没有直接的letterSpacing属性，需要操作XML：
   ```python
   rPr = p.runs[0]._r.get_or_add_rPr()
   rPr.set('spc', str(int(字间距 * 100)))
   ```
4. **页码**——右下角统一放 `XX / 30`，保持一致
5. **章节分隔页**——超大字号（60pt）+ 章节编号，营造仪式感

直接保存 `.pptx` 文件，用 `present_files` 交付本地路径，不需要在线链接。
