# Art Style Lexicon — 大师风格拆解词典

## 什么时候用

- 做原创角色设计、潮玩IP、手办/卡牌向角色
- 赛博朋克/未来都市插画
- 需要统一画风的系列图
- 生图前需要锁定风格参数时

## 怎么用

1. 先读 `references/toy-character-principles.md`（潮玩角色硬约束，必看）
2. 按当前项目调性选 1-2 个风格方向，读对应 ref
3. 把大师风格**转译**成通用视觉参数写入 prompt（不写艺术家名字）
4. 系列图全程锁定同一套参数，不中途换风格

## 风格方向速查

| 方向 | 核心气质 | 适用场景 | ref |
|---|---|---|---|
| 赛博朋克硬表面 | 冷钢+霓虹、建筑级精确、负空间光影 | 未来都市、机能角色 | `cyberpunk-hard.md` |
| 复古装饰少女 | 圆脸大眼+写实身体、Art Deco、柔光复古 | 短发少女、复古机械 | `retro-deco.md` |
| 野性厚涂 | 暗底高饱和、兽性眼神、巴洛克线条 | 野性男性、暗黑力量感 | `wild-impasto.md` |
| 暗黑生物机械 | 交叉排线、生物机械融合、巨构尺度 | 暗黑科幻、异形机械 | `biomech-dark.md` |
| 晶莹厚涂原画 | 暗部高饱和、像素级细节、色彩通透 | 游戏原画、史诗感 | `crystal-painterly.md` |
| 潮玩Q版概括 | 强剪影、少色块、圆润夸张 | 盲盒手办、周边衍生 | `toy-chibi.md` |

## 红线

- prompt里禁止出现在世艺术家姓名、作品名、受保护IP名
- 所有风格必须转译为：线条粗细/配色比例/头身比/材质/光影/构图
- 系列图跨图必须保持：头身比、脸型结构、主色占比、线条风格一致
