## 2. 角色IP五阶段工作流

```
研究与主题 → 创意探索 → 主方案 → 系统延展 → 精修交付
```

| 阶段 | 交付物 | 关键动作 |
|---|---|---|
| 一 研究与主题 | 简短研究卡+创作命题 | 按一个明确创作问题选艺术家 |
| 二 创意探索 | 2-3个表达逻辑不同的小稿方向 | 换轮廓/行为/材质，不只换颜色帽子职业 |
| 三 主方案 | 核心角色或主视觉 | 验证构图、结构、情绪 |
| 四 系统延展 | 转面、表情、动作、场景、产品适配 | 按实际用途做，不一次铺全套 |
| 五 精修交付 | 统一笔触/色彩/边缘/文件规格 | 修复AI痕迹，保留用户有意的个性 |

**每次推进只解决一个关键问题，不无限扩展。**

## 3. 角色设计执行（核心）

### 3.1 先区分原创与既有IP
- **原创**：可探索轮廓、比例、性格、配色、标志性特征
- **既有IP**：锁定比例、五官、纹样、结构、色彩。新动作/场景/衍生不擅自改变角色身份

### 3.2 角色卡（从内核出发，不堆标签）
它是谁；最想得到什么；最害怕什么；平时怎样行动；独特小习惯；观众为什么陪伴它。

性格必须影响造型：
- "谨慎但好奇" → 收拢姿态、前探重心、停顿、试探动作
- 不能只写在简介里，要体现在体块和表演上

**不要默认**大眼睛、圆脸、短四肢、渐变色、满身装饰——可以用，但必须服务角色意图。

### 3.3 角色标准卡（每个角色维护一版）

| 字段 | 记录内容 |
|---|---|
| 身份 | CHARACTER_ID、版本、名称、定位、欲望与性格矛盾 |
| 体块 | 总高相对单位、头身关系、躯干四肢比例、站姿重心 |
| 面部 | 眼位间距、鼻嘴形状、面部区域边界；无此部件明确写"无" |
| 标记 | 形状、数量、精确位置；左右以角色自身为准 |
| 色彩 | 主色/辅助色/点缀色及分布 |
| 材质 | 各部位材质、软硬、粗糙度、接缝/关节表现 |
| 表演 | 默认姿态、动作习惯、情绪表达、允许及禁止的变形 |
| 锁定项 | 不可变身份特征；可变的表情/动作/服装/道具 |
| 依据 | 参考文件、已认可主稿、版本状态、待验证问题 |

### 3.4 三视图与表情动作
- 正面+指定侧面+背面，**同比例、同基线、中性姿势、同镜头高度，尽量无透视**
- 四分之三视角另列，不替代侧面
- 跨视角检查：眼线、肩线、腰线、脚底高度、头部深度、耳/角连接、尾巴根、色块绕体方向、接缝归属
- 背面看不到五官时，**不复用正面描述生成背面脸**
- 表情通过眼睑、嘴形、头姿、身体共同表达，不是每个表情换一张脸
- 动画动作拆：预备 → 主动作 → 缓冲/停顿
- 视频查起止帧和运动过程：部件增减、穿插、滑步、材质漂移、左右标记翻转

### 3.5 玩具化与衍生
先分动画版 vs 实体概念版，记录简化点和保留的身份锚点：
- **毛绒**：体块缝合、绒毛对小表情的遮盖、刺绣表达
- **硬质摆件**：支撑、悬挑、薄小部件、分件、涂装边界
- **可动玩具**：关节位置对轮廓与动作的影响

这些是**设计审查项，不是量产结论**。

### 3.6 面向豆包的提示词组织
不臆造豆包参数、固定种子、参考权重、独立负面栏能力。

**静态角色模板**：
> 任务：根据所附角色主稿制作【本次唯一目标】。角色固定设定：【实际可见的体块、脸部关系、角色自身左右标记、配色分布与材质】。本次视角与姿势：【明确描述】。构图：【全身/局部、主体占比、留白】。照明与背景：【便于识别结构的安排】。保持：【本次必须保留的特征】。只调整：【已授权项目】。避免：【针对该图的具体缺陷】。

**动作模板**：
> 使用已认可角色【ID/版本】与参考画面。固定外形与材质：【可见锚点】。起始姿态：【姿态与接触关系】；预备动作：【行为】；主动作：【方向与幅度】；结束：【停稳姿态】。镜头：【机位及是否运动】。场景：【必要信息】。变形规则：【软硬部位与范围】。检查重点：【接触、支撑、左右标记、部件数量等】。

**一个提示词只安排一个清楚的生成目标。**

## 4. AI痕迹诊断与修复

用户说"像AI"时，结合实际作品检查，**只列最影响作品的三个问题**。

### 诊断清单（按顺序查）
1. **造型模板化**：是否落入通用AI角色套路（大眼圆脸渐变满身装饰）
2. **结构矛盾**：头颈、肩臂、手掌手指、腿脚、尾巴躯干的连接
3. **材质光影无依据**：高光/阴影方向是否统一
4. **细节随机**：纹路、小零件、装饰、反光是否承担作用
5. **笔触机械**：是否全局统一颗粒感、全局锐化或全局模糊
6. **拼接感**：主体与背景是否像不同作品拼的
7. **文字图案扭曲**：文字、纹样、logo是否可读正确
8. **表情空泛/姿态僵硬**：表情是否只有嘴变，身体不参与

### 先结构后表面
- 检查连接关系和受力：动作必须有重心、支撑、清楚受力
- 手握道具：接触、遮挡、抓握，不用模糊装饰盖错误
- **局部精细不能抵消整体结构错误**

### 笔触跟随形体
- 笔触方向帮助表达体块、动作、空间
- 不随机制造脏边、错位、不对称假装人工痕迹
- 用户原稿中有意的简化、夸张、节奏要保留

## 5. 数字绘画全流程

```
参考收集 → 构图草稿 → 线稿 → 铺大色 → 体积塑造 → 细节刻画 → 质感收尾
```

| 阶段 | 占比 | 关键动作 |
|---|---|---|
| 参考收集 | 10% | 找3-5张参考，分析构图/配色/笔触 |
| 构图草稿 | 10% | 剪影、大形、重心、视觉动线 |
| 线稿 | 15% | 外轮廓粗，内线细，结构准确 |
| 铺大色 | 15% | 分大色块，不抠细节 |
| 体积塑造 | 25% | 亮部暗部，光源统一，材质区分 |
| 细节刻画 | 20% | 五官、道具、纹理、边缘 |
| 质感收尾 | 5% | 整体调色，噪点/纹理，统一氛围 |

### 构图原则
三分法 / 视觉动线 / 正负形 / 对比（大小·明暗·冷暖·繁简）/ 均衡不对称

### 色彩理论
| 方案 | 说明 | 适用 |
|---|---|---|
| 互补色 | 色环对面 | 强对比、视觉冲击 |
| 邻近色 | 色环相邻 | 和谐、统一 |
| 三色 | 等边三角形 | 丰富、活泼 |
| 单色 | 同色相不同明度 | 高级、简洁 |

光源配比：**主光70% / 辅光20% / 轮廓光10%**

### 厚涂技法
1. 笔刷：干画笔/厚涂笔刷/粉笔
2. 颜料堆叠：多层叠加，不一次涂匀
3. 笔触方向：顺结构/材质方向走
4. 边缘：焦点处实，远处虚
5. **不要磨皮**：保留笔触肌理

### 素描结构基础（造型底层语法）
1. **动态线**：一条线从头贯穿脊柱到脚，捕捉整体动势。AI图角色僵不僵先看这条线
2. **块面化**：头颅=球、胸腔=楔形、骨盆=蝴蝶形、四肢=圆柱、关节=小球
3. **透视**：一点/两点/三点/五点（鱼眼）
4. **椭圆定方向**：圆形越接近边缘椭圆越窄，短轴对齐消失方向
5. **近大远小+近实远虚+遮挡**

**AI生成图结构检查清单**：动态线通不通 / 三大体块关系 / 关节位置和遮挡 / 手脚透视椭圆方向 / 前后遮挡物理依据

### 儿童绘本风要点
造型圆润无棱角 / 颜色温暖明亮 / 笔触可见但不杂乱 / 角色夸张可爱 / 构图简洁留白 / 情绪温暖治愈

## 6. SEVEN个人风格语言（手绘铅笔/彩铅）

> 详细档案见 `references/seven-style-profile.md`

### 质感：手绘铅笔/彩铅，不是数字光滑
- 交叉排线画体积，不追求平滑渐变
- 边缘有手写感，不画干净矢量线
- 保留笔触层次，不全局模糊/磨皮
- **禁止**：3D光滑渲染、数字粉系平涂、滤镜统一颗粒

**排线规则**：亮部稀疏顺形体；暗部密集交叉叠色2-3层；焦点（眼睛、宝石）整块压重不打圈

### 眼睛是第一重点
- 永远画得最重——整块墨色压黑，或大而圆带高光
- 眼神有故事：斜睨、直视、含泪、发呆
- **禁止**：愤怒皱眉、挑眉、凶狠眼神
- 眉毛角度放平，表现好奇/谨慎，不表现攻击性

### 密集装饰围绕主体（不是空背景）
- 主体周围要有装饰呼应：雨滴、蝴蝶、宝石、花纹、建筑局部
- **禁止**：空背景居中站姿

### 配色倾向
- 暖黄/橙做主体，冷色或宝石色做点睛
- **禁止**：全灰阶无倾向、马卡龙粉系光滑插画

### 情绪：安静内省
- 窗前看月、贴电话、含泪蝴蝶、空静物——克制带一点忧郁
- 不画热闹、不画动作戏

### 静物功底
透明材质高光要准、金属明暗交界线清晰有磨损感、木头纸柔和排线

## 8. 本地ComfyUI + Flux dev img2img 实战

> 详见 `references/local-flux-refine.md`

### denoise选型表（5080 16GB实测）
| denoise | 效果 | 适用 |
|---|---|---|
| **0.15-0.30** | 几乎不动结构，只刷材质笔触 | ✅精修/去AI味/面部修复 |
| 0.30-0.45 | 大构图在，细节小改 | 换光影/微调 |
| 0.45-0.65 | 大姿势在，细节重生成 | ⚠️风格迁移，但易崩角色 |
| 0.65-0.85 | 只保留大致构图 | ❌只适合重构图 |
| 0.85+ | 仅松散参考 | 不用于IP衍生 |

**核心规则**：**精修用0.25-0.30，重绘才用0.55-0.65**——选错直接崩。

### 关键判断：什么时候**不该**用生图模型
| 任务 | 正确做法 | 错误做法 |
|---|---|---|
| 已有成品IP图，只改画幅/加效果/upscale | PIL pad + LANCZOS放大 + 加倒影 | Flux img2img（必崩角色） |
| 已有成品IP图，想换笔触风格 | 直接用原图加纹理/滤镜 | 高denoise让Flux自由发挥 |
| 真正的新构图/新姿势 | Flux文生图或低denoise img2img | — |

### 工作流节点
UNETLoader(fp8_e4m3fn) + DualCLIPLoader(clip_l+t5xxl, type=flux) + VAELoader(ae) + KSampler(cfg=1.0, euler, simple, steps=20-26) + FluxGuidance(3.0-4.0)

### Prompt写法教训
- Flux dev **不吃**"impasto oil painting / palette knife / canvas texture"强油画词——会输出光滑数字插画
- Flux擅长"soft fluffy fur, dreamy hazy lighting, creamy yellow, children's book illustration"
- **cfg=1时negative不生效**，要靠positive把方向钉死
- 保角色时prompt第一句必须"preserve the exact character, pose and composition from the input image"

### 600 DPI交付流程（PIL路线，不占GPU）
```
原图 → LANCZOS放大到目标像素 → 贴到目标比例画布
→ 底部pad区加高斯模糊倒影 → save(PNG, dpi=(600,600))
```
- 3:4竖版600DPI推荐：2400×3200 或 4608×6144
- 2×以上放大应用ESRGAN模型，不是PIL

### 队列管理
- 提交前先 `GET /queue` 看running/pending
- 插队：`POST /queue {"delete": ["<prompt_id>"]}` 清前面的pending
- **不要 `/interrupt` 当前running**（会毁正在跑的任务）

| 脚 | 红色圆头小鞋，鞋口蓝绿边，每脚3根黄色三角爪 |
| 尾巴 | 彩虹条纹长尾巴，上方一排黄色三角背鳍，尾尖收尖不加彩球 |
| 毛发 | 有粉色彩色挑染 |

### 常见错误（必查）
1. 脚画成熊猫脸拖鞋——错！是红鞋蓝绿边+3黄三角爪
2. 胸口画成小五角星——错！是发光大星+周围小星
3. 手画成3根爪——错！是4根白爪
4. 背鳍画成彩色——错！是黄色三角
5. 犄角根没有小绿芽——必须有蓝绿小卷芽
6. 手环画成普通条纹——是彩虹波浪+上方黄毛边
7. 毛发没有粉色挑染

### 强制规则（ERR-ART-001 永久生效）
1. AI出图仅作草图，禁止直接交付原始AI图
2. 手部必须PS重绘：5根手指、关节透视正确、手掌比例协调
3. 交付前必须逐项打勾自检清单
4. 倒立姿势重点检查：重心、脖子弯曲度、衣服褶皱方向、头发因重力垂落

### 画风标准
厚涂油画impasto笔触，可见画布纹理 / 儿童绘本质感 / 暖黄奶油背景 / 纯2D禁3D禁AI光滑 / 300DPI

## 10. 审美判断六维

| 维度 | 问什么 |
|---|---|
| 意图 | 作品想表达什么，看不看得出来 |
| 独特性 | 是否有属于这个项目的选择 |
| 整体性 | 造型、色彩、笔触、叙事是否互相支持 |
| 取舍 | 焦点明确，细节有主次 |
| 完成度 | 结构与制作是否可靠 |
| 延展性 | 进入其他载体后是否仍成立 |

不把写实、精细、复杂、低饱和自动视为更高级。

**验收顺序**：身份结构 → 跨视角一致 → 表情动作可读 → 材质与应用适配

---

## 11. 系列开发三层规则

- **固定项**：角色身份、核心比例、识别特征、关键配色、世界观约束
- **变化项**：动作、表情、场景、视角、道具、具体故事
- **例外项**：节日/限定/实验作品中允许改变的内容

每张系列作品承担不同表达任务，**避免重复"居中角色+装饰背景"**。

### 检验IP能否持续产生内容
为角色写三个不同的日常小故事，检查：是否都体现同一性格 / 是否有不同动作情绪 / 是否不靠新增复杂设定也能成立。
如果只能想出换衣服/换颜色/换场景，说明角色行为与内在动机不充分。

---

## 12. 审美建议五要素（每条建议必含）

**问题位置 / 可见依据 / 具体改法 / 预期作用 / 可能损失**

> 例："缩小右侧装饰，保留人物手势周围的空间，使动作更易读。"
> 禁说："更高级、更有大师感、更像某艺术家。"

---

## 13. 参考优先级（硬顺序）

1. 当前项目与客户硬性要求
2. 用户当前明确指令
3. 用户已确认的个人风格规则
4. 用户原稿中可观察的创作特点
5. 外部参考方法

既有IP项目必须保持原角色标准；个人表达只能进入获允许的范围。
**外部收藏图只证明兴趣，不证明用户已形成该风格；AI生成图不算用户亲笔创作证据。**
