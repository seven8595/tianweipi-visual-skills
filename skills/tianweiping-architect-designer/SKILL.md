## 1. A 学习路线（从零到设计总监）

**先把现实讲清**：软件只是入场券，总监卡的是**方案能力**和**谈单能力**，这两样靠真实项目喂，不靠课程。

- 现实路径：**3-4 个月学会画图出图 → 能独立出方案 → 再用真实项目喂设计与管理**。
- "几周成为大师"是骗人的；先达成"能入职/能接单"的里程碑，再谈总监。

**三选一定赛道**（别混着学）：

| 赛道 | 核心软件 | 出图速度 | 天花板 |
|---|---|---|---|
| **室内设计**（平面+效果图，主流） | CAD + 3ds Max/V-Ray + PS | 快，酷家乐秒出 | 高（可谈单当总监） |
| 建筑外观表现 | CAD + SketchUp/3ds Max + D5 | 快 | 中（纯表现岗） |
| 景观/深化 | CAD + SketchUp + Lumion | 中 | 高 |

**省钱软件栈**：酷家乐（最快）→ SketchUp + D5（免费）→ Blender（免费深度），一样能出商业级效果图。免费替代：浩辰/中望CAD 替 AutoCAD，GIMP 替 PS。

**六阶段**：认知(1周) → CAD平面(3-4周) → 3D建模(4-6周) → 渲染后期(4-6周) → 设计能力(3-12月) → 总监级(长期)。每阶段必须交出一个可展示的输出物。

**四条最快方法**：项目驱动（学完一个功能当天做完整案例）／临摹 > 看书（60% 时间）／作品集 > 证书／前置设计审美（边学边存大师图）。

> 完整版（含每周目标、每日节奏、免费资源清单、第一个月练习清单）见 `references/learning-roadmap.md`。

## 2. B 建筑视觉 6 步管线（任何建筑视觉项目都走这条）

### STEP 1 纸笔草图
A4 + 2B 铅笔，**不上电脑**。1 小时 30 个概念小稿，每稿 ≤2 分钟。线条重叠、页面乱没关系——这是**找**想法，不是**记录**想法。
检查：哪一张能用一句话讲清核心概念？

### STEP 2 线稿精修
外轮廓线 0.8pt，内部结构线 0.3pt，阴影用排线。
- **安藤风**：轴测铅笔稿，只画核心几何+阴影，大面积留白
- **扎哈风**：连续曲率流动曲线，重叠破碎的书法式线条
- **BIG风**：黑白图解，一张图讲清一个 idea

检查：缩到 1cm 见方还认得出形状吗？

### STEP 3 灰模 Clay Model（最关键，不可跳过）
SketchUp / 3ds Max / Blender 建白模，**不上任何材质**。必须书面确认 3 件事：
1. **相机位置**（人视高 vs 鸟瞰）
2. **镜头焦距**（建筑效果图用 50mm 左右标准镜头，避免广角变形）
3. **光线方向**（下午 3 点侧光最显高级；阴天均匀光最诚实）

检查：**纯灰模状态下构图和光影已经好看了，再往下走。**
⚠ 这一步改相机最便宜，上了材质再改 = 重渲。

### STEP 4 材质 + 灯光
- 先看**纹理比例**：砖大小、板宽、缝间距对不对？（90% 的"假"感来自纹理比例错）
- 玻璃反射必须反射天空和周边，不能纯黑或纯透明。
- 灯光情绪：规划报批→阴天均匀光（诚实）；商业宣传→低角度夕阳（显高级，但会遮丑，要自知）；室内→自然光+暖人工光混合。
- 先出低分辨率预览，确认了再渲大图。

### STEP 5 渲染输出
V-Ray / Corona / Octane / D5 任选。必须输出多通道：Z深度、AO、反射、高光、Shadow。
检查：暗部有细节、亮部不过曝、玻璃反射合理。

### STEP 6 PS 后期
顺序：色彩平衡曲线 → 加天空/树/人/车配景 → 轻微胶片颗粒 → 锐化。
配景尺度：人高 = 建筑 1 层窗高，树高不超 2 层窗。
避免：配景人"飘"在地上、玻璃里映出不存在的树、过饱和。

### 三大师风格选谁

| 项目调性 | 选谁 | 视觉特征 | 适用 |
|---|---|---|---|
| 极简、静谧、光影感 | 安藤忠雄 | 大面积留白、单色、铅笔排线阴影、轴测 | 美术馆、住宅、宗教空间、高端地产 |
| 流动、未来感、曲线 | 扎哈·哈迪德 | 连续曲率、破碎重叠、参数化 | 文化地标、商业综合体、科技项目 |
| 叙事性、易理解 | BIG | 黑白图解、爆炸图、"Yes is More" | 方案汇报、投标、概念推演 |

> 6 步管线完整版见 `references/master-6step-pipeline.md`。

## 3. C 建筑宣传片

**流程**：建筑概念 brief → 关键帧效果图（Flux dev）→ 分镜脚本 → 逐镜头 I2V（Wan2.1）→ 配音配乐 → 剪辑成片。**全本地，零云 API。**

### 概念阶段（出片前必须想清）
片长（30 秒招商快剪 / 2 分钟方案汇报 / 5 分钟宣传片）／受众（政府汇报 / 甲方决策 / 购房者 / 招商客户）／调性（高端克制 / 温暖生活 / 科技未来 / 文化底蕴）／核心主张（一句话：这支片要让观众记住什么）／画幅（16:9 汇报招商，9:16 抖音朋友圈）。

**禁止**：没想清楚就出图。没有主张的宣传片就是 PPT 轮播。

### 分镜脚本（2 分钟标准 = 8-12 镜，每镜 3-5 秒）
远景开场 → 鸟瞰总平 → 中景主入口 → 近景细节 → 人视跟随 → 室内横移 → 特写材质 → **黄昏/夜景蓝调（氛围高潮）** → 远景拉升收尾。
节奏：开场慢 → 中段稳 → 高潮（夜景）→ 收尾慢，**不要全程一个节奏**。

### 运镜提示词（喂 I2V，只写动作和运镜，不写画面）
`缓慢推进` / `缓拉远` / `横移` / `拉升` / `俯角缓移` / `跟随人视` / `穿越推进` / `环绕` / `微移固定`。

**禁忌（会崩）**：不写 `glow / reflection / flicker / light particles`（会加多余特效）；不写急推急拉（会糊）；不写多人复杂动作（肢体崩坏）；首帧必须是静态关键帧。

### 本地参数
- 关键帧（Flux dev fp8）：1216×832 横版 / 832×1216 竖版，euler+simple，24 steps，**cfg=1.0**，guidance=3.5；风格词 `architectural photography, blue hour, cinematic, photorealistic, 28mm, two-point perspective`
- I2V（Wan2.1 14B FP8）：1280×720 原生，每段 3-5 秒，首帧用 Flux 关键帧，TeaCache/BlockSwap 压到 2-3 分钟/段
- 后期：剪映/DaVinci 剪辑，本地 edge-tts 或录人声，版权免费 BGM，字幕微软雅黑

> 完整版（含 9 镜脚本表、9 条英文运镜 prompt、4 类项目关键镜头）见 `references/promo-studio.md`。

## 4. D 设计提案 PPT

把效果图拼接升级为"设计总监级"提案：**概念 → 基因 → 案例 → 系统 → 应用 → 愿景**。

### 四色制（硬约束）

| 名称 | 色值 | 占比 | 职责 |
|---|---|---|---|
| 夜幕蓝 | `#0A1628` | 60-70% | 深色页基底 · 封面/效果图页/收尾页 |
| 纸感米白 | `#F5F0E8` | 30-40% | 浅色页基底 · 概念/系统/品牌页 |
| 琥珀暖光 | `#D4AF6E` | 5-10% | 强调色 · 分隔线/副标题/重点 |
| 玻璃冷光 | `#4A6FA5` | 5% | 辅助 · 英文标签/次级信息 |

**双色制**：一页只用一种底色。深色页=夜幕蓝底+白字+琥珀点缀；浅色页=米白底+深墨字+琥珀点缀。

### 11 页结构
封面 → 项目概念 → 视觉基因 → 白天立面 → 夜景立面 → 设计表达（线稿/钢笔淡彩）→ 空间视角 → 色彩系统 → 品牌系统 → 应用场景 → 设计愿景。

### 排版
中文标题微软雅黑粗体 36-72px；正文微软雅黑常规 16-18px；英文标签 Segoe UI 全大写 11-14px；页码右下 11px 浅灰。
左右边距 80px（1920 宽），标题下 40px 处放 40px 长琥珀分隔线；大图页底部图注条距底 100-140px，叠加半透明黑遮罩。

### 红线
不要一页塞多图（一页一主题）；不要花哨配色（四色够）；正文不用楷体/宋体；不居中满屏（左对齐留白）；logo 只在品牌页放一次；**效果图页不配大段文字，图自己说话**。

> 规格全文见 `references/proposal-ppt-spec.md`；可直接套用的配色/字体/各页结构代码骨架见 `references/proposal-ppt-quick-template.md`。

## 5. 本地渲染参数速查

| 用途 | 参数 |
|---|---|
| Flux dev 出图 | euler + simple，24 steps，**CFG=1.0**（guidance-distilled，CFG>3 崩图），约 40 秒/张 |
| 负向提示词 | CFG=1 时不生效，只能靠正向 prompt 钉方向 |
| 精确文字/logo/编号 | Flux 不擅长，必须后期 PS/AI 排版，不要让模型生成 |
| I2V 视频 | Wan2.1 14B FP8，1280×720，每段 3-5 秒 |
| 超分 | Real-ESRGAN ncnn（动画模型 `realesr-animevideov3-x4`）逐帧；快路径用 ffmpeg Lanczos + unsharp |
| 本机 ffmpeg | 支持 `libopenh264` / `h264_mf` / `hevc_mf` / `libmp3lame` / `libopus` / `libvpx`；**无 libx264、无 drawtext** |
| 显存 | 16GB 跑不动 4K；32GB 可直跑 1280×720 I2V |

## 6. 交付前质量红线

1. 灰模阶段有没有确认相机和光线？没确认就上材质 = 返工风险
2. 纹理比例对不对？（近景砖缝宽度和远景是不是一套尺寸）
3. 配景人有没有"落地"？脚和阴影对得上吗？
4. 三件套（海报 + 动画 + PPT）是不是**同一套色板和字体**？（这是"高端感"的核心）
5. 有没有大面积留白？堆满素材 = 廉价；留 1/3 空白 = 高端
6. 宣传片：每段视频和首帧一致吗？运镜方向空间逻辑一致吗？蓝调时刻天空颜色统一吗？招牌有没有乱码？节奏有快慢吗？最后一镜有项目名+slogan吗？
7. PPT：每页文字 ≤3 行吗？大图页只有图注吗？logo 只出现一次吗？

**状态标注**：待制作 → 制作中 → 已生成待检查 → 已检查需修改 → 已通过。没看到真实结果不得标"已通过"。
