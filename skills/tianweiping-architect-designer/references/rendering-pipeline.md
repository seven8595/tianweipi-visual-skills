# 专业效果图管线 — 田伟平制作流程（本地5080算力版）

> 基于DC Studio等专业工作室标准流程，适配田伟平本地RTX 5080算力、零云渲染的工作方式。

## 输入包准备（给渲染前要备齐的东西）

### 必备清单
- [ ] 3D模型（SketchUp / Rhino / Revit）+ 对应2D图纸（平面、立面、剖面）
- [ ] 材料清单：带样品照片或产品型号（"浅木色"不是指令，"橡木白蜡木15cm板宽"才是）
- [ ] 场地信息：周边现状照片、北针、地形高差
- [ ] 情绪参考图：附说明"我喜欢这张的什么"（"喜欢黄昏光"而不是"这张好看"）
- [ ] 每张图的用途和最终尺寸：展板、印刷、网页——构图完全不同

### 模型清理（发送前必做）
- 删除未用图层
- 隐藏施工辅助几何
- 统一单位
- 检查有没有重复墙、杂线

## STEP 1 · 灰模 Clay Model（最关键阶段）

### 为什么必须先做灰模
灰模去掉了颜色和材质，所有人只看**构图、比例、光影**。这是改相机最便宜的阶段——上了材质再改相机 = 重渲。

### 灰模阶段必须书面确认的3件事

| 项目 | 选项 | 适用场景 |
|---|---|---|
| **相机高度** | 人视高（1.6m） | 展示人真实体验感 |
| | 轻微鸟瞰（10-20m） | 展示场地关系 |
| | 高鸟瞰 | 总平面图用 |
| **镜头焦距** | 24-35mm广角 | 室内、小空间显大 |
| | **50mm标准** | 建筑效果图首选，比例真实 |
| | 85mm以上长焦 | 压缩空间、显高级 |
| **光线方向** | 阴天均匀光 | 规划报批、诚实展示 |
| | **下午3点侧光** | 商业宣传、显质感 |
| | 低角度夕阳 | 营销海报、遮丑（慎用） |

### 田伟平风格默认值
- 相机：人视高 + 50mm标准镜头（安藤的克制）
- 光线：下午3点侧光，阴影方向统一（田伟平出品所有图同一方向的光）

## STEP 2 · 材质 + 灯光

### 材质检查优先级
1. **纹理比例**（90%的"假"感来源）：
   - 砖多大？缝多宽？
   - 板多宽？分格在哪？
   - 玻璃幕墙竖梃多窄？
2. **玻璃行为**：
   - 反射天空（不是纯黑）
   - 反射周边建筑（不是镜子）
   - 透明度：从外面能隐约看到内部灯光
3. **粗糙度/金属度**：
   - 混凝土：粗糙、无反光
   - 金属板：半哑光、有环境反射
   - 玻璃：高反射但不是镜面

### 灯光情绪设定
| 场景 | 自然光 | 人工光 | 适用 |
|---|---|---|---|
| 高端商业 | 黄昏冷色天光 | 室内暖黄灯光透出 | 海信类项目 |
| 美术馆 | 阴天均匀光 | 重点射灯打在展品 | 安藤风 |
| 未来科技 | 夜景深蓝 | 室内LED冷白光 | 扎哈风 |

### 低分辨率预览
正式渲大图前，先出1024px宽的低清预览。确认：
- 构图对不对？
- 材质比例对不对？
- 灯光情绪对不对？

## STEP 3 · 渲染（本地RTX 5080）

### 引擎选择（按5080适配度）
| 引擎 | 5080表现 | 适用 |
|---|---|---|
| **Octane Render** | 极好，GPU原生 | 电影级效果图 |
| **D5 Render** | 好，实时渲染 | 快速出图、动画 |
| **V-Ray GPU** | 好，兼容老项目 | 传统项目 |
| **Corona** | CPU为主，慢 | 不推荐5080用 |

### 必输出通道
- Beauty（主图）
- Z-depth（景深通道）
- AO（环境光遮蔽）
- Reflection（反射通道）
- Shadow（阴影通道）
- Specular（高光通道）

### 5080渲染参数建议
- 采样：1024-2048（静帧）
- 尺寸：4K（3840×2160）起步
- 动画：D5实时预览，Octane出最终帧

## STEP 4 · PS后期

### 标准流程
1. **基础调色**：色彩平衡曲线，暗部偏蓝、亮部偏暖
2. **加天空**：替换过曝的天空，选黄昏或阴天
3. **加配景**：
   - 树：高度不超2层窗
   - 人：人高=1层窗高，脚落地有阴影
   - 车：尺度参考车身长≈5m
4. **加氛围**：轻微胶片颗粒（5-10%），镜头光晕（克制）
5. **锐化**：USM锐化，半径1px，数量50-80%

### 田伟平风格后期特征
- 整体偏冷调（蓝灰底子）
- 暗部不死黑，有细节
- 配景少而精（不是每个角落都塞人）
- 最后加一层轻微的"纸纹"质感（致敬安藤的铅笔稿）

---

## 修改轮次管理（专业工作室标准）

- 每项目含2轮修改
- 第1轮：灰模阶段（改相机、改构图）——最便宜
- 第2轮：材质/灯光/后期调整——中等成本
- 超过2轮 = 新需求，加钱加时间

### 修改清单写法
- ❌ "感觉不对"
- ❌ "再高级一点"
- ✅ "第3张图相机抬高2米"
- ✅ "玻璃反射太亮，降到30%"
- ✅ "配景树的位置往右移3米"
