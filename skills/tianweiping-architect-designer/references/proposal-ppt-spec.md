# Archviz Proposal PPT — 建筑设计提案PPT方法论

把普通效果图拼接升级为"设计总监级"的完整提案。核心不是堆图，是用**概念→基因→案例→系统→应用→愿景**的叙事结构，让老板看完觉得"这是专业团队做的"。

## 1. 什么时候用

- 楼盘/商业综合体/养老社区的设计提案汇报
- 给甲方老板看的视觉方案小样
- 招商PPT、品牌视觉提案
- 有效果图素材，需要包装成专业提案

## 2. 配色系统（四色制，硬约束）

| 名称 | 色值 | 占比 | 职责 |
|---|---|---|---|
| 夜幕蓝 | `#0A1628` | 60-70% | 深色页基底 · 封面/效果图页/收尾页 |
| 纸感米白 | `#F5F0E8` | 30-40% | 浅色页基底 · 概念/系统/品牌页 |
| 琥珀暖光 | `#D4AF6E` | 5-10% | 强调色 · 分隔线/副标题/重点 |
| 玻璃冷光 | `#4A6FA5` | 5% | 辅助 · 英文标签/次级信息 |

**双色制规则**：深色页用夜幕蓝底+白字+琥珀点缀；浅色页用纸感米白底+深墨字+琥珀点缀。不要一页里混两种底色。

## 3. 11页结构模板

| # | 页面 | 底色 | 内容 |
|---|---|---|---|
| 01 | 封面 | 夜幕蓝 | 项目名+副标题+底部信息栏 |
| 02 | 项目概念 | 米白 | 一句话主张+正文阐述+英文副标 |
| 03 | 视觉基因 | 米白 | 3-4个视觉元素编号列表 |
| 04 | 白天立面 | 夜幕蓝 | 大图铺满+底部图注条 |
| 05 | 夜景立面 | 夜幕蓝 | 大图铺满+底部图注条 |
| 06 | 设计表达 | 米白 | 钢笔淡彩/线稿图+图注 |
| 07 | 空间视角 | 夜幕蓝 | 街角/鸟瞰大图+图注 |
| 08 | 色彩系统 | 米白 | 四色色板+色值+用途说明 |
| 09 | 品牌系统 | 米白 | 主品牌logo+业态列表 |
| 10 | 应用场景 | 米白 | 2-3个应用场景卡片 |
| 11 | 设计愿景 | 夜幕蓝 | 居中slogan+项目名+落款 |

## 4. 排版规范

### 字体层级
- **中文标题**：微软雅黑粗体，36-72px
- **中文正文**：微软雅黑常规，16-18px
- **英文标签**：Segoe UI，11-14px，全大写
- **页码**：右下，11px，浅灰

### 边距与网格
- 左右边距：80px（1920宽度下）
- 顶部边距：80px
- 底部图注条：距底100-140px
- 分隔线：标题下40px处，长度40px，琥珀色

### 图注条（大图页）
```
04 / DAYTIME FACADE          ← 英文标签，浅灰
白天 · 商业立面               ← 中文标题，白色
```
位置：图片底部叠加，有半透明黑色遮罩。

## 5. 叙事逻辑

老板看PPT的心理路径：
1. **这是什么项目？**（封面→概念）
2. **你们怎么想的？**（视觉基因）
3. **做出来什么样？**（效果图页）
4. **系统完整吗？**（色彩→品牌→应用）
5. **最终愿景是什么？**（收尾页）

**关键**：效果图页不要配大段文字，图自己说话；概念页和系统页才用文字展开。

## 6. 制作流程

1. **收素材**：白天效果图、夜景效果图、钢笔淡彩/线稿、街角视角
2. **定概念**：一句话项目主张（不是"做个PPT"，是"XX想传达YY给ZZ"）
3. **写基因**：提取3-4个视觉元素（从建筑特征里提炼）
4. **拼版**：按11页模板逐页生成，深色页用大图铺满，浅色页用网格排版
5. **质检**：每页文字不超过3行，大图页文字只留图注

## 7. 红线

1. **不要一页塞太多图**——一页一个主题，效果图页就放一张大图
2. **不要用花哨配色**——四色制够了，加色就乱
3. **不要用楷体/宋体做正文**——微软雅黑够专业
4. **不要居中排版满屏**——左对齐，留边距，有呼吸
5. **不要每页都加logo**——品牌页放一次就够了
6. **效果图页不要配大段文字**——图自己说话

## 8. 已验证案例

- 海信悦公馆·悦生活广场商业配套设计提案（2026-10）
  - 11页，1920×1080
  - 配色：夜幕蓝#0A1628 + 纸感米白#F5F0E8 + 琥珀#D4AF6E + 冷蓝#4A6FA5
  - 结构：封面→概念→基因→白天→夜景→线稿→街角→色彩→品牌→应用→愿景
  - 对标：《蓝调时刻·商场海报设计概念提案》PPTX
