# 总监级工作流：从一句话需求到可交付成品

> 目标：用户只做 3 个决策，其余全自动。
> 原则：先小样后批量、先灰模后材质、先锁相机后渲染、哪坏修哪不整张重抽。

---

## Step 1：Brief 自动补全（3 分钟）

收到需求后，**不要追问**，按项目类型默认值补全：

| 字段 | 建筑外观 | 室内效果图 | 平面/户型图 | 海报KV |
|---|---|---|---|---|
| 概念 | 这是什么建筑、给谁看、什么情绪 | 这个空间给谁住、什么氛围 | 户型流线是否合理 | 品牌主张一句话 |
| 受众 | 业主/评审/政府 | 业主/软装客户 | 业主/设计院 | C 端消费者 |
| 调性 | 3 关键词 → 大师后缀 | 3 关键词 → 大师后缀 | 清晰可读为主 | 3 关键词 → 大师后缀 |
| 禁忌 | 无水印/无乱码/无畸形 | 同左+家具不能飘 | 尺寸标注不乱 | 文字必须可读 |
| 尺寸 | 16:9 横版 2K | 3:4 或 16:9 | 原比例 | 按平台 |
| 交付物 | 主图+日转夜+鸟瞰 | 主图+多角度+空镜/带人物两版 | 彩色平面图 | 主KV+3 个尺寸 |

补完后给用户看一行："我理解你要的是 XX，风格走 XX 大师方向，对吗？"——不是问问题，是给确认机会。

---

## Step 2：出 2-3 个真实差异方向小样

**差异必须来自核心创意/叙事/视觉规则，不是换颜色**：

| 方向 A | 方向 B | 方向 C |
|---|---|---|
| 安藤克制：混凝土+一束光，留白 60% | 扎哈流动：白曲面+连续曲线 | 如恩新旧对话：红砖+混凝土嵌接 |

每个方向出 1 张小样（不超过 512×512），30 秒内出完，用户选一个再批量。

**禁止**：方向 A 和方向 B 只是把沙发从米色换成灰色——这不叫方向差异。

---

## Step 3：灰模/白模锁构图（关键步，不可跳）

在这一步书面确认 3 件事（Agent 自决，不问用户）：

1. **相机位置**：人视（1.5m 高）/ 鸟瞰 / 街景平视
2. **镜头焦距**：
   - 建筑效果图：**50mm 标准镜头**（避免广角畸变）
   - 室内：24-35mm（需要空间感）
   - 海报特写：85mm（压缩感）
3. **光线方向**：
   - 下午 3 点侧光 = 最显高级（推荐默认）
   - 阴天均匀光 = 最诚实（报批图用）
   - 蓝调时刻 = 夜景提案用（MIR 风格）
   - 单束顶光 = 安藤/卒姆托氛围用

**改灰模相机最便宜，上材质再改 = 整图重渲。**

---

## Step 4：批量出图矩阵

按交付物清单一次跑完：

### 建筑外观项目
- [ ] 主日景人视（16:9）
- [ ] 主夜景人视（蓝调时刻）
- [ ] 鸟瞰全景
- [ ] 主入口特写
- [ ] 材质细节特写 2 张
- [ ] 平面图/总平面（彩色）

### 室内项目
- [ ] 主空间空镜（16:9 或 3:4）
- [ ] 多角度 3-4 个视角（用节点画布"多角度"按钮）
- [ ] 主空间带人物版（生活化，不酷脸）
- [ ] 材质特写 2 张
- [ ] 日景/夜景各一版

### 海报/KV
- [ ] 主 KV（按平台尺寸）
- [ ] 文字版/无字版
- [ ] 三宫格/九宫格延展（如需要）

---

## Step 5：12 维自动审稿 + SMART REPAIR

每批出完自动过 `redlines-and-checklist.md` 的 12 维清单。

### SMART REPAIR 原则
- **只改失败区域**：用红框法（视频技术点 3）局部 inpaint，不整张重生成。
- **一次只改 1-2 个变量**：不要同时改光线+材质+构图。
- **3 轮修不好就停**：停下来重新判断问题出在哪一层——是 brief 错了？相机错了？还是模型能力不够？换方法，不要无限重试。

---

## Step 6：终稿精修 + 超分 + 归档

用户选终稿后：
1. 固定 seed 复现
2. Real-ESRGAN 超分到 4K（本地 RTX 5080 跑，不烧钱云端）
3. 轻度 PS 后期：统一色温、加胶片颗粒、修边缘杂色
4. 命名归档：
   ```
   F:\项目名\
     01_input\           # 用户给的 CAD/参考图
     02_drafts\         # 小样/方向
     03_main\           # 主图
     04_details\        # 特写
     05_variants\       # 日转夜/多角度
     06_final\          # 终稿超分版
     WORKFLOW_LOG.md    # 每步改了什么、为什么
   ```

## 本地 vs 云端双路径（2026-10-13 已实测）

### 路径 A：本地 RTX 5080 + Flux.1 dev（默认，免费，已验证可跑）

**环境（已确认）**：
- ComfyUI 便携版：`F:\ComfyUI_windows_portable\`
- GPU：RTX 5080 16GB，空闲约 13.6GB
- 主模型：`flux1-dev.safetensors` (22GB, fp8 加载)
- 文本编码器：`t5xxl_fp8_e4m3fn_scaled.safetensors` + `clip_l.safetensors`
- VAE：`ae.safetensors`
- 超分：`4x-UltraSharp.pth`
- 启动器：`F:\ai智能体田伟平总监水平自动工作流\local_pipeline\start_comfyui.bat`

**一键出图命令**（ComfyUI 已启动时）：
```powershell
F:\ComfyUI_windows_portable\python_embeded\python.exe `
  F:\ai智能体田伟平总监水平自动工作流\local_pipeline\flux_generate.py `
  --prompt "安藤忠雄风格清水混凝土住宅，前池反射，水平光缝" `
  --width 1344 --height 768 --steps 24 --seed 42 `
  --out my_test.png
```

**默认参数（实测有效）**：
- 采样器 euler + simple，Steps 24，**CFG 1.0**（Flux dev 是 guidance-distilled，CFG 调高反而崩）
- 分辨率 1344×768（横版）/ 768×1344（竖版）/ 1024×1024（方图）
- 出图后存到 `local_pipeline\output\`
- 出图时间：5080 上约 30-60 秒/张

**已验证出图质量**：
- ✅ 安藤风格清水混凝土+螺栓孔+悬挑板+前池反射——一次命中
- ✅ 不需要 Architecture LoRA（纯 Flux dev 原生语法已足够建筑/室内概念图）
- ⚠️ 缺 ControlNet 模型，线稿/红框精确结构控制暂时做不了
- ⚠️ 缺 Architecture/Realistic LoRA，写实度比 SDXL+LoRA 略弱但足够概念阶段

### 路径 B：Linktel/Lynkvis/即梦节点画布（网页端，需要保结构时用）
- 工具：linktelai.com，浏览器打开
- 优势：保结构重绘、红框法、三图融合、九宫格、多角度、图生视频——本地 ComfyUI 暂时做不到这些节点工作流
- 适合：有 CAD/SU 白模要精确重绘、要批量营销物料、要出分镜视频
- 注意：体验版 5 次额度，正式版按积分扣费；用户已明确价格敏感，**批量前先出小样验证方向**，不要一上来跑几十张

### 路径 C：云端 image_gen（仅应急，不默认）
- 工具：豆包 image_gen (seedream_5.0_flash)
- 触发条件：本地 ComfyUI 没启动 / 本地显存被占 / 用户明确要快速预览
- 用户硬偏好：本地优先。云端只在本地不可用时兜底。

### 什么时候选哪个
- 用户给了 CAD/线稿/户型图 → 路径 B（Linktel 节点画布）
- 用户只给了一句话、要概念氛围图 → 路径 A（本地 Flux，免费）
- 要视频分镜 → 路径 B（LLM 节点+图生视频）
- 路径 B 出了图要超分放大 → 路径 A 的 4x-UltraSharp
- 本地 ComfyUI 没起来又急着看方向 → 路径 C 应急
