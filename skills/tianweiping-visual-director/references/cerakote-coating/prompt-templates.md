# Image Edit Prompt 模板

每次调用 `image_edit` 时按这个骨架写。把 `{占位符}` 换成具体方案内容。

## 通用骨架

```
基于[img0]这把{枪型/品牌}的实拍照片，将其{当前涂装状态，如"全黑涂装"}改为{目标方案名}，配色方案参考[img1]。严格保留手枪全部外形结构、滑套上的{品牌}标志和"{品牌英文全称}"白色印刷字、{战术灯型号}战术灯及上面的白色"{战术灯标识}"标识、{瞄具类型}、握把防滑stippling粗糙纹理、弹匣底座形状。

具体颜色改动：
- {部位1}改为{颜色描述}哑光cerakote质感
- {部位2}改为{颜色描述}金属光泽
- {部位3}保持{保留色}

保留原图的{背景描述，如"粉色波浪纹鼠标垫背景、白色游戏鼠标、桌面杂物"}和拍摄光影方向不变，透视角度与原图完全一致。
```

## 实盘示例（这次任务验证过的可用 prompt）

### 示例 A — FDE 沙漠色
```
基于[img0]这把Taran Tactical改装格洛克手枪的实拍照片，将其全黑涂装改为FDE沙漠色战术配色方案，配色比例参考[img1]。严格保留手枪的全部外形结构、滑套上的TTI标志和"TARAN TACTICAL INNOVATIONS"白色印刷字、X400 Ultra战术灯及上面的白色"X400 ULTRA"标识、红点瞄准镜、握把防滑stippling粗糙纹理、弹匣底座形状。具体颜色改动：滑套套筒主体、枪口外圈、弹匣底座改为FDE沙漠色（Flat Dark Earth）哑光cerakote质感；下机匣框架、握把区域、X400 Ultra战术灯、红点瞄保持哑光黑色；扳机改为香槟金色小点缀。保留原图的粉色波浪纹鼠标垫背景、白色游戏鼠标、桌面杂物和拍摄光影方向不变，透视角度与原图完全一致。
```

## 无配色参考图时（纯文字描述配色）
把"配色方案参考[img1]"改成"配色按以下方案执行"，然后直接列部位颜色。参考图列表只传 `[img0]`。

## 换干净产品背景时（用户选中方案后追加）
```
将背景替换为深灰色哑光产品摄影棚背景，柔和侧光打在枪身上突出cerakote质感，枪主体居中略倾斜放置，去除原有桌面杂物。
```
