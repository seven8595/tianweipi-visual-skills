# Gun Cerakote Designer — 玩具枪涂装效果图设计

## 核心定位
把用户实拍的玩具枪照片作为底图，保留外形/配件/标识/背景，只改涂装配色，输出可直接拿去对喷/做cerakote的视觉效果图。**不是**从零画枪，**不是**做插画风格，是写实照片级改色。

## 标准工作流

### 1. 识别输入图角色
- **[img0] = 用户的枪（编辑底图）**：必须保留其外形、改装件（红点瞄/战术灯/消焰器/弹匣底座）、握把纹理、原厂logo印刷字、拍摄角度、背景环境。
- **[img1..n] = 配色参考图**：只取其颜色比例和配色逻辑，不取外形。可以是实枪照片、产品图、插画、网图。

### 2. 判断是否需要澄清
- 用户只给了自己的枪、没给配色参考 → 直接从 `references/color-schemes.md` 里挑 3 个经典方向出试稿（FDE / 枪灰+金 / 哑光黑+铜）。
- 用户给了配色参考图 → 直接按参考图配色出 2-3 版比例微调。
- 用户明确指定颜色（"我要沙色""我要橙色"）→ 按指定色出 1-2 版。
- **不要**问用户"你想要什么风格"，直接出图让他选编号。

### 3. 生成效果图（必须用 image_edit，禁止 image_gen 重画）
- 模型：`seedream_5.0_flash`（默认）或用户指定。
- 参考图列表：`[用户枪URL, 配色参考图URL]`。
- 比例：保持底图原始比例（用户竖拍就出竖版，横拍就横版）。
- 每次生成 1 张 → 立即下载到本地 → 单独 `present_files` 交付 → 再生成下 1 张。**禁止批量出图后一起交付**。

### 4. Prompt 结构（I2I 改写）
按"编辑目标 → 保留项 → 编辑项（分部位写颜色）→ 背景保留"写，完整模板见 `references/prompt-templates.md`。

**保留项必须写死：**
- 全部外形结构、改装配件位置
- 滑套上的品牌logo和文字逐字保留
- 配件上的标识字（如 "X400 ULTRA"、"SUREFIRE"）
- 握把 stippling 粗糙纹理
- 原始背景、桌面物品、光影方向、透视角度

**编辑项按部位写：**
- 滑套套筒主体色
- 下机匣/握把色
- 金属小点缀色（抛壳窗/枪口/扳机）
- 配件（战术灯/红点瞄/弹匣底座）色

## 涂装配色方案库
详见 `references/color-schemes.md`，包含经典配色方向、部位分配规则、推荐比例。

## 交付规则
- 每张图独立命名：`paint-scheme-{A/B/C}-{英文名}.png`，下载到本地后单独 present_files。
- 交付后用表格列出方案编号 + 配色逻辑 + 适用场景，让用户选编号。
- 用户选中后可继续：调比例、换干净产品级背景、加 camo 纹路、局部做旧。

## 红线
- 不改变枪的外形结构、改装件数量和位置。
- 不涂改原厂logo文字，保留白字/刻印。
- 不把背景换成纯产品图棚拍风，除非用户明确要求"出干净背景产品图"。
- 涉及真铁枪械敏感时不评论合法性，纯视觉设计。
