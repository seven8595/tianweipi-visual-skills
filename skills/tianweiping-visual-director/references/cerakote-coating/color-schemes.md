# 涂装配色方案库

按"主体占比 → 点缀占比"组织。每个方案给出部位分配和 prompt 里该写的颜色词。

## 经典三方案（默认出试稿用这三个）

### A. FDE 沙漠色战术风
- **主体（滑套套筒/枪口外圈/弹匣底座）**：FDE Flat Dark Earth 沙漠色，哑光 cerakote
- **保留黑（下机匣/握把 stippling/战术灯/红点瞄）**：哑光枪黑
- **小点缀（扳机）**：香槟金或黄铜色
- **比例**：沙漠色约 50%，黑色约 45%，金色点缀约 5%
- **适用**：CQB/户外战术风格，最跳、识别度最高
- **参考风格**：图2 FDE 双色改装 Glock

### B. 深枪灰 + 香槟金（Salient 风）
- **主体（滑套套筒）**：Tungsten Grey 深枪灰，哑光 cerakote
- **点缀（抛壳窗内部/枪口外圈/扳机）**：香槟金 champagne gold，金属光泽
- **保留黑（下机匣/握把/战术灯/红点瞄/弹匣底座）**：哑光枪黑
- **比例**：枪灰约 40%，黑色约 50%，金色约 10%
- **适用**：精致改装感，低调但有细节，最耐看
- **参考风格**：图1 Salient Arms International

### C. 哑光黑 + 玫瑰铜（Combat Master 风）
- **主体（滑套/下机匣/握把/战术灯/红点瞄）**：Rifle Black 哑光枪黑，统一细腻
- **点缀（抛壳窗边缘装饰条/枪口外圈/trigger shoe）**：玫瑰铜 Rose Bronze，金属光泽
- **比例**：黑色约 90%，铜色约 10%
- **适用**：最低调、最隐蔽，跳色小但精致
- **参考风格**：图3 Taran Tactical Combat Master

## 扩展方向（用户选完三选一后可继续探索）

### D. 双色拼接 Two-Tone
- 上半滑套一种色、下半握把一种色，分界线在滑套-机匣接缝
- 经典组合：白+黑（银黑）、红+黑、OD 绿+黑
- prompt 关键词："上半滑套与下半机匣双色拼接，分界线沿滑套机匣接缝笔直水平"

### E. 迷彩 Camo
- Multicam / 丛林迷彩 / 沙漠迷彩纹路覆盖滑套和机匣
- prompt 关键词："滑套和机匣表面覆盖 multicam 迷彩 cerakote 纹路，握把保留黑色 stippling"

### F. 做旧 Battleworn
- 新涂装基础上边缘磨白露底层色，模拟实战磨损
- prompt 关键词："边缘棱角处自然做旧磨损，露出底层金属色，战损风格 cerakote"

### G. 霓虹赛博（艺术向）
- 主体深钢蓝/炭灰，标识线/点缀用电光青或电光红
- prompt 关键词："深钢蓝哑光主体，滑套边缘电光青色细线装饰，高对比"

## 部位分配速查表

| 部位 | 默认保留 | 可改色范围 |
|---|---|---|
| 滑套套筒主体 | — | 主色（占最大面积） |
| 抛壳窗内部 | 金属本色 | 金色/铜色点缀 |
| 枪口外圈/螺纹 | 金属本色 | 金色/铜色/黑色 |
| 下机匣框架 | 黑 | 与滑套同色或对比色 |
| 握把 stippling | 黑纹理 | 一般保留黑，纹理必须保留 |
| 扳机/trigger shoe | 黑 | 金色/红色/铜色 |
| 战术灯（X400/X300） | 黑 | 一般保留黑 |
| 红点瞄 | 黑 | 一般保留黑 |
| 弹匣底座 | 黑 | 与滑套同色或黑色 |
