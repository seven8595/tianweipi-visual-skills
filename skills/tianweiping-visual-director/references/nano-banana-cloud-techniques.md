## 3. 逐个玩法 + 本地对应做法

### 玩法 1 · 精准局部精修（当成美图秀秀用）

**片中原话要点**：上传照片 → 让女生瘦一点（约 100 来斤）、瘦得匀称、脸保持完美、**纹身都没变**；同理可让她胖一点、让这个人有肌肉、**肚子平了之后还对应地去掉了高光**；去痘、去眼镜、上粉色妆容，**人脸保持度 99%**。
**核心逻辑（教程自己点出的）**：**精准控制**。把它想象成美图秀秀——手臂细一点、画烟熏妆、换发型，细节任你拓展。

**可迁移的技法**：把"改什么"和"不能动什么"分开写死。凡是"变了但你没让它变"的地方，都会暴露一致性崩掉。

**提示词骨架**
```
Keep the subject's face and identity completely unchanged.
Keep the tattoo on the [部位] unchanged.
Only modify: [手臂粗细 / 腰腹 / 高光 / 眼镜 / 妆容 / 发型].
Re-light accordingly so the removed highlight matches the new body shape.
```

**本地对应做法**：inpaint 局部重绘，`denoise 0.25–0.35`，其它区域锁定。
⚠ **本机缺 ControlNet / 面部锁定 LoRA，身份保持明显弱于云端** —— 本地只建议做**材质、光影、妆容**级修改；改脸型/体型这类高一致性需求，如实告诉用户本地做不到位。

---

### 玩法 2 · 废片修复 / 老照片修复上色

**片中原话要点**：抓拍丑照 → 让他笑起来、吃得优雅一点、换个**显高的角度**、换个**优美的姿势**，非常一致。
基于这种**多角度、多姿势的一致性**，还可以"根据一个画面生成多个机位的镜头"——**做 AI 视频的人会变简单**（这是给分镜/多机位用的关键点）。
老照片修复："修复并上色他，连皱纹、腮红都还原得这么生动"。

**可迁移的技法**：**同一主体、多机位输出**。这正好对上本技能「自主执行模式」里的批次出图：一次出多个机位，供选稿。

**提示词骨架**
```
Same subject, same clothing, same location, same lighting logic.
Shot list: ① eye-level medium  ② slight low angle full body（显高）
③ over-the-shoulder  ④ close-up detail
Only the camera changes — identity, wardrobe and background stay locked.
```

**本地对应做法**：同一 `seed` + 固定提示词结构 + 只改机位行；老照片修复用 `Real-ESRGAN` 超分 + 上色，**上色质量与云端有差距**。

---

### 玩法 3 · 时代穿越写真

**片中原话要点**：AI Studio 里用这个模型做了若干小应用，"这个是最火的"——**上传一张自己的照片，一次性生成 50 / 60 / 70 / 80 / 90 年代和千禧年的造型照片**。
**背后逻辑**：就是**风格化提示词**，你自己也能手动打造不同主题的写真。

**可迁移的技法**：**一次写真 = 一套年代风格卡 × 一张原照**。年代感靠四件套固定：胶片颗粒、发型服装、影调色温、道具陈设。

**提示词骨架**
```
Portrait of the same person, unchanged facial identity.
1980s Chinese style: [发型][服装][影调] , film grain, warm faded tones, period-appropriate props.
```
> 做 7 个年代 = 复制 7 次，只换年代风格卡那一行；主体描述逐字不动。

**本地对应做法**：✅ 完全可做，风格化是 Flux 强项。配年代 LoRA 效果更稳。

---

### 玩法 4 · 电商设计（多轮迭代）

**片中原话要点**：因为它是**原生多模态、有 32K 上下文**，所以可以**基于前面的生成继续迭代编辑**——先让这个女人穿上这条裤子 → 再把这张图变成杂志封面 → 再把文字改成"秋之"。
"迭代了这么几次，还是保留了她那颗纳米级的痣，以及商品图。**这次是真的商用级，保持产品不变形了**。"

**可迁移的技法**：**把改动做成一条链，每一步都显式声明"不可变项"**。云端赢在 32K 上下文能记住整条链；本地没有，得靠人（或脚本）维护一张清单。

**本地对应做法**：维护一张 `不可变项.md`（产品外形/颜色/logo 位置/人物身份），每轮改图前把清单贴进提示词，改完逐项核对。这就是本技能 12 维审稿里"品牌调性 + 完成度"两项的实操化。

> ⚠ 商用红线：教程那句"商用级"指的是**产品不变形**，不代表可以直接对外商用。见第 4 节。

---

### 玩法 5 · 家装设计（分步方案迭代）

**片中原话要点**：毛坯房照片发给他 → 先刷墙壁，**不喜欢可以再换** → 再上窗帘沙发 → 再来书柜绿植 → 再来点装饰 → 再多点装饰 → 再来点生活气息。
"这里面**每一步都可以按你的喜好来换方案再设计**，租房买房者必备。"

**可迁移的技法**：**软装分层推进**，天然对应本技能的"样稿 → 检查 → 系列扩展"流程。层次顺序：墙地顶 → 大件家具 → 收纳/柜体 → 绿植 → 装饰 → 生活痕迹。

**本地对应做法**：✅ 本技能强项。商业空间/室内走 `commercial-space-cases.md` 与 `commercial-space-local-execution.md`；硬约束照抄：
> 禁止改变原始模型场景结构、物体位置和几何形状，严禁改变空间布局

---

### 玩法 6 · 模型手办（万物手办化）

**片中原话要点**：出于它的一致性保持，可以**把万物变成 3D 手办**（杰伦手办、花木兰手办、秋枝手办），或者贴纸（秋枝贴纸、宠物贴纸、名人贴纸）；
"以及我们可以为图中的主体做一个**等距的模型**（isometric）"；
拓展方向：毛绒玩具、乐高积木都行。

**可迁移的技法**：主体 → 手办/贴纸/等距模型，三档不同输出。

**提示词骨架**
```
Turn the subject into a 3D collectible figurine: [材质——哑光树脂/搪胶]
isometric view / studio lighting / clean seamless backdrop / product-shot framing
```

**本地对应做法**：✅ 走 `田伟平潮玩设计大师`（注意该技能已明确记录：**用户拒绝 3D 光滑款潮玩**，走手绘铅笔/彩铅 + 和风密集装饰）。**手办化要选对风格，别默认出 3D 亮面**。

> ⚠ 名人形象（杰伦、花木兰等）：**不得生成可识别的在世真人肖像与受保护 IP 用于商用**。见第 4 节。

---

### 玩法 7 · 时间流逝（问它未来）

**片中原话要点**：因为它本身有理解能力，所以把图发给它问"**10 分钟后会发生什么？**""**10 年后会发生什么？**"结果非常合理。

**可迁移的技法**：这是**推理型**用图，不是画图。适合做故事板/分镜的时间推演、场地随时间变化的概念图。

**本地对应做法**：❌ **云端独有**。本地 Flux 没有世界知识与时序推理，硬做只会得到一张"像那么回事但没逻辑"的图。
→ 本地替代：**人工写时序脚本文本**，再逐帧生成；逻辑靠人补，不靠模型。

### 玩法 8 · 标注生成（看图上的注释）

**片中原话要点**：它**不仅能看懂提示词，也能看懂图片上的注释**。
- 例：让"这个人和这个人保持这个位置关系"，**完美复现**；
- 例：**在封面草图上写好——这里要这样、那里要那样，全部一一精准兑现**。

**片中的实拍证据**（抽帧 `f_006.jpg`，标牌「标注生成」）：粗糙手绘涂鸦 + 手写英文标注箭头——
`Nano` / `Banana` 大字、帽子上写 `Q Z`、箭头标 `hat`、`American comics bg`（背景）、`confident smile`（表情）、`suit` / `tie`（服装）、`Radial`（放射线）、手臂标 `Banana`（用香蕉做手臂）。

**可迁移的技法（本案最有价值的一条）**：**草图 + 文字标注 = 一份"图上需求文档"**。把该方法搬到本地：先在草图上把"要什么"标清楚，再当参考图喂进去。

**本地对应做法**：⚠ 本机**缺 ControlNet（MLSD/Lineart）**，无法做精确的线稿结构控制。可行的降级路径：
1. 标注图当参考图走 img2img（精度有限，别承诺"精准兑现"）；
2. 出图后用 **PIL 后期叠字**（精确文字一律后期，不靠生成）——这一点与本技能既有结论一致。

---

### 玩法 9 · 科普利器（世界知识 + 理解力）

**片中原话要点**：原生多模态的另一大优点是**本来就有世界知识和理解力**：
- 把猫的照片发给它 → 生成一张**解剖图**；
- 网上看到的美食发给他 → **还原食材**（滑蛋肉丝、鸡排：蜂蜜、料酒、生姜）——"他是懂做菜的"；
- 把**科普文章**发给他 → 总结主题与核心要点 → 生成一个**展示看板**；
- 地理老师：给照片 → 把**标注的位置变成现实的视图**；或者**直接谷歌地图截一张图**，让他**画出红色箭头方位所看到的画面**；
- 随手一张照片 → 当作 **AR 生成器**，在图片中注释重要信息（教程称"眼镜厂商终于等来了这个模型"）。

**片中的实拍证据**：`f_007.jpg` 标牌「科普作图」——河湾卫星图 + 一个红箭头；字幕"或者直接谷歌地图一咔嚓"。`f_008.jpg`——俯拍建筑群（平面排布读作「QZ」字母），字幕"和标志性的庄园"。

**可迁移的技法**：**地图/卫星图 + 红箭头 → 目标视角画面**，这条对建筑与城市设计方案汇报很有用（把"站在箭头处能看到什么"直接画出来）。

**本地对应做法**：❌ **世界知识类（解剖图、还原食材、文章看板）云端独有**。
✅ 但"**地图 + 红箭头 → 视角画面**"本地可近似：卫星图当参考图 + 明确的相机方位描述 + 建筑 6 步管线里的机位纪律（见 `田伟平建筑设计师/references/master-6step-pipeline.md`）。**表述要诚实：这是概念推演，不是地块真实还原。**

## 4. 三条硬提醒（第 4.1 条是红线）

### 4.1 "眼见为实"失效 —— 生成图不得伪造人与背书

教程后半段用**一张照片**演示了完整造假链条（此处**只记录风险类别，不记录可复用做法**）：
伪造人物学历与履历、伪造"联合顶级科学家开发"的**医疗功效**、伪造名人代言与地标露出、伪造豪车庄园等财富证据、并给出低价代理加盟话术。

**本技能红线（照旧执行，不因模型变强而放宽）**
- ❌ 不生成可识别的在世真人肖像、不伪造任何人物的身份、履历、关系与代言；
- ❌ 不生成医疗功效、健康承诺、财富承诺、政策背书类内容；
- ❌ 不生成虚假证照、资质、获奖、销量、评价；
- ✅ **AI 生成图必须标注"AI 生成"**（SKILL.md 真实性红线原文）；
- ✅ 交付时主动提示"该图可被用于误导，请在对外场合标注来源与生成方式"。

> 教程自己给出的结论值得记住：**"这个模型也正式地让'眼见为实'这个成语失效了……用的高兴的同时，记得提高警惕。"**

### 4.2 中文与文字

教程自述**中文输出仍有瑕疵**；实操上也一直有"招牌乱码"这类问题。
→ **所有精确文字（标题、价格、logo、参数）一律后期排版**，不靠模型生成。这条与本技能既有结论完全一致。

### 4.3 别把"演示效果"当"已验收成品"

教程里的"人脸保持度 99%""纳米级的痣""商用级"都是**作者口播的演示结论**。本技能照旧执行状态标注：
**待制作 → 制作中 → 已生成待检查 → 已检查需修改 → 已通过**。
没看到真实结果不得标"已通过"。

## 6. 与本地路线的取舍（一句话版本）

> 两者不冲突：**用云端想清楚，用本地做成品**。

## 8. 神诀三 · 两段提示词（画面照录）

> ⚠ **照录，非改写。** 这两段是**云端大模型**的写法，与本技能「不写 8K/电影级/大师级」的本地铁律**正面冲突** —— 详见第 9 节的处理原则。
> 来源 `frames_v6/f_011.jpg`；`[?]` 标记处原片文字模糊。

**prompt 1**
```
以超写实、超细致的16K单反质量修复照片。修复划痕、撕裂、噪点和模糊。
保持自然肤色的同时增强鲜艳色彩。完美锐化面部、眼睛、头发和衣服细节。
增添逼真光影和景深。专业级PS后期处理。高动态范围，超高清，逼真纹理，
电影般[?]后，清晰干净背景，完全还原和提升原照片
```
> `[?]` 处原片为一字，字形似"仕/锐"，读不通；疑为"**锐化**"或"质感"，**以原片核对为准，我未臆补**。

**prompt 2**（结构化五段式）
```
[核心指令] 大师级老照片修复，超高保真度，100%锁定原始面部特征与骨骼结构，
绝对不改变人物身份，100%还原照片中场景。
[画质与细节] RAW格式原片画质，8K超高清分辨率，超精细的微肌理，
真实的皮肤毛孔与瑕疵（拒绝过度磨皮），次表面散射效果（模拟真实皮肤光泽），
根根分明的发丝，衣物织物纹理清晰可见。
[光影与摄影] 影棚级柔光照明，伦勃朗光或蝴蝶光（根据原图），自然的眼神光，
阴影层次丰富，全画幅单反摄影，85mm人像镜头，f/1.8大光圈，景深自然柔和。
[色彩] 电影级色彩校正，柯达胶片质感，色彩还原准确自然，饱和度适中。
[负面排斥] 无卡通滤镜，无AI绘画感，无塑料质感皮肤，无面部变形，无模糊噪点。
以超写实、超细[及后文被画面裁切]
```
> **观察（非确证）**：prompt 2 末句与 prompt 1 起句相同（"以超写实、超细…"），疑为「**结构化五段前缀 + prompt 1 正文**」的组合写法。此为从画面推断，未经作者确认。

**真正值得抄的是它的结构，不是它的形容词**：
- **`[核心指令]` 里先锁"不可变项"**（面部特征 / 骨骼结构 / 人物身份 / 场景）—— 与本技能「不可变项清单法」同源，**这一条可直接搬到本地**。
- **`[负面排斥]` 单独成段**（无 AI 绘画感 / 无塑料皮肤 / 无面部变形）—— 本地 CFG=1 时负向提示词不生效（见 SKILL.md 本地实测），所以本地这条要靠 **`vqc.py` 症状处方 + `vfix.py`** 来兜，不能只写在提示词里。

## 9. 三条硬提醒（本技能的处理原则）

**① "16K / 8K / RAW 画质"是话术，不是产出承诺。**
源片像素就那么多，修复**不会凭空增加真实分辨率**。交付时必须如实说清"输出尺寸 vs 真实细节量"，不得因为提示词里写了 16K 就当 16K 交付。

**② 云端这类"堆形容词"写法，搬到本地 Flux 基本无效。**
本技能已实测：Flux dev 是 guidance-distilled，**CFG 必须 = 1.0**，CFG=1 时负向提示词不生效；堆"电影级/8K/大师级"对结果影响甚微。
→ **本地改写原则**：把这些形容词**全部换成具体参数** —— 相机/镜头/光圈/光位/色温/材质/材质粗糙度。
> 本地改写示例（同样的"修复+增强"意图）：
> `restore damaged photograph: remove scratches, tears, noise, blur; keep original facial features and identity unchanged; natural skin texture with visible pores (no over-smoothing); sharpened eyes, hair strands and fabric weave; soft key light from upper left, 45°, 3200K; 50mm lens, f/4, natural depth of field; muted film color, low saturation; clean neutral background`
> 然后在**后期**做锐化/色阶（走 `vqc.py` 打分 → `vfix.py autolevel / unsharp / chroma`），而不是指望模型一次到位。

**③ 去水印的边界。**
神诀一在本技能里成立的前提是：**去掉的是"你自己产出物上平台加的水印"**。
- ✅ 可用：自己生成的图、自己拍的图，去掉工具水印。
- ❌ 不可用：去除**他人的版权水印 / 图库水印 / 署名**，那是侵权，不在本技能范围内。
