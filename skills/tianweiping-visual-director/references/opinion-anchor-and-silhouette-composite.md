## 2. 从首帧作品逆向归纳的技法：剪影内嵌场景（Silhouette Double-Exposure）

**首帧展示的成品**（画面证据 `frames_v5/f_001.jpg`）：标题 **OLYMPUS / THE HOME OF THE GODS**。
右侧是**宙斯的石雕侧脸**（作为容器/轮廓），左侧沿轮廓展开成一片神话场景群像 ——
持闪电的老神、戴盔持矛的雅典娜、头戴冠冕的女神、帕特农神庙、飞马、鹰、持双蛇杖的赫尔墨斯、持三叉戟者、竖琴与云海山崖；
底部有小字图例（ZEUS / ATHENA / HERMES 之类）。

**这类图的成败在四条，不在元素多少**：

| 要点 | 做法 | 做错就废 |
|---|---|---|
| **容器要硬** | 主体轮廓（侧脸/器物/图腾）必须是**单一、可辨识**的剪影，石雕/金属等硬材质 | 轮廓模糊 → 看起来只是拼贴 |
| **内嵌要有叙事** | 轮廓内填的不是"好看的纹理"，而是**主题相关的具体场景清单** | 填通用风景 → 变成廉价双重曝光 |
| **过渡要统一** | 轮廓边缘用**云 / 雾 / 烟**溶解，**只有一种过渡方式**，且不外溢 | 多种过渡混用 → 视觉散架 |
| **色调要收** | **单一色调族**（本图：大理石白 + 暖米 + 淡金 + 冷灰蓝），**低饱和** | 高饱和多彩 → 掉到廉价感 |

**提示词结构（可复用骨架，非视频原文）**

```
【容器】<人物侧脸 / 器物 / 图腾> 石雕质感，单一清晰剪影，作为画面容器
【内嵌】轮廓内部由以下场景组成：<逐项列清：场景1、场景2、场景3…>
【过渡】轮廓边缘以云雾溶解进背景，过渡方式统一，不外溢
【色调】单色调族：大理石白 + 暖米 + 淡金；整体低饱和
【光线】柔和侧光，突出体积与浮雕感
【构图】主体偏置一侧，另一侧留白承载标题
【质感】石雕 + 云雾 + 古典绘画质感融合，细节密集但统一
【禁止】高饱和、多主体抢戏、轮廓外溢、贴纸式拼贴、文字乱码
```

- **标题与图例文字一律后期排版**（本技能铁律：Flux 不擅长精确文字/logo）。
- 这类图**元素天然很多**，审稿时不要用"元素是否丰富"判分，只看**统一性**：一种色调、一种过渡、一个光向、一个容器。
- 可迁移场景：品牌 KV（品牌符号做轮廓 / 产品史做内嵌）、城市宣传（地标剪影内嵌城市生活）、人物传记视觉、展览主视觉、IP 世界观图。

## 3. 作者给的判断标准（比技法值钱，建议纳入验收）

> **"设计做的好看并不难，难的是把复杂的信息通过图像来传递出去。"**

转成可执行的审稿动作 —— 在 12 维审稿的**「概念」与「信息架构」**两维上加这一问：

- [ ] **把图给别人看 3 秒，他能不能说出这张图在讲什么？** 说不出 → 概念或信息架构不合格。
- [ ] 图上的**信息是"完整、准确"的**，还是只是"氛围对"？氛围对但信息错 = 不合格。
- [ ] 有没有"**多一点理解**"—— 图是否说出了文案没说的那层？没有 → 只是配图，不是设计。

> 这条与已有原则一致（一图一主张 / BIG 的图解 / 概念 > 形式），此处只是把它**明确成一条可打的勾**。

## 4. 对本技能的现实含义（一条务实提醒）

**执行层（画得像、质感好）正在变得越来越不稀缺；判断层（把复杂信息转译成图像）才是护城河。**

所以本技能的重心继续压在：
① 第零步 brief 对齐 → ② 概念主张（一图一主张）→ ③ 信息架构 → ④ 12 维审稿与 SMART REPAIR。

**不要**把精力花在堆"8K/电影级/大师级"这类形容词上 —— 那正是作者说的"我们曾经引以为傲的方法"里最容易被替代的部分。
