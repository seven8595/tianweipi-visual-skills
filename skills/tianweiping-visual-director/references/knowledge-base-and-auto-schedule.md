## 1. 为什么值得写进视觉技能（四条真价值）

1. **本地 Markdown 是 AI 最好读的格式**（视频原话：Markdown 最适配 AI，也是 AI 最好读取的格式）。
   本技能的风格卡、配色、审稿记录都已是 `.md` —— 但散在 `references/` 里，**只能靠人记着去读**。做成库后可被 Agent 自动检索、自动回填。
2. **全部本地，零云算力** —— 符合本技能「本地 RTX 5080 优先、不调云端」的硬约束。
3. **"自生长"机制**：本技能的经验状态（待验证 / 局部通过 / 可复用 / 已撤回）和素材库目前靠手动维护；配一个**每周复盘定时任务**就能自己长。
4. **自带省钱技巧**（见 §5），与"免费工具优先、价格敏感"一致。

## 5. 定时任务三件套 + 一个省钱技巧

| 用途 | 工具（画面核实） | 要点 |
|---|---|---|
| 自主调度 / **夜间复盘** | **AI Scheduler** | 规划 + 定时执行 + 通知 |
| 定点发任务 | **Claudian Scheduler** | **把请求排到 DeepSeek 低谷时段（北京时间 00:30–08:30）自动发出，节省 API 成本** |
| 跨机续接 | **Claudian Session Sync** | 会话文件同步到另一台机器继续 |

> **省钱那条特别值得抄**：重活排到低谷时段自动跑 —— 与"免费优先、成本敏感"一致。

## 6. 给 AI Agent 装 Skill 的标准动作（可迁移）

视频里装 **AIHOT Skill**（每日精选全球 1000 条 AI/科技资讯）的方式很干脆：**把一段安装提示词直接发给 Agent**，自己不手动装。

**画面核实的实际过程**
- 发给 Codex 的指令形如：
  `安装 AIHOT Skill: <README 链接>`，并追加一个参数：`--actor <你的 actor id>`
- Agent 回报：**版本 v1.5.4 / 装到 `%USERPROFILE%\.agents\skills\aihot` / SHA-256 校验全部通过 / 已确认只有一份**
- 报完提示：**需要开新会话或重启 Codex 才能稳定加载新 Skill**

**可迁移结论（本技能同样适用）**
- 给 Agent 装能力 = **给一段带来源链接的安装指令**，由 Agent 自己拉取并校验（校验哈希是好习惯）。
- **装完要开新会话**才稳定生效。
- ⚠ **`--actor` 是"你自己的"标识**：视频画面里那串 id 和路径属于**博主本人的机器与账号**，**不要照抄**，按官方页面获取自己的。

**定时任务建议**

## 8. 边界（别误读）

1. **装了它不会让图变好** —— Obsidian/Claudian/Codex 解决的是**沉淀与调度**，不是画质。
2. **不是出图的必要条件** —— 只用本技能的七大技术 + 本地 Flux 照样出图；这条是"锦上添花的资产层"。
3. **AIHOT 是别人的 Skill** —— 资讯质量与可持续性未验证；接入第三方 Skill 前先看它要什么权限。
4. **未实测** → 本文件状态 **待验证**；实测通了请升级为「局部通过 / 可复用」。
5. **名称以画面为准**：插件是 **Claudian**（不是转写里的 "Claudion"）；资讯 Skill 是 **AIHOT**（不是 "AI HUNT"）；作者是**卡兹克**。
