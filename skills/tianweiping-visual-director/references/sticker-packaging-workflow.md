# 快消品贴纸/包装合成实战 · 踩坑记录（海信生活 2026-10）

> 来源：海信生活团购贴纸改版项目。从 PDF 原稿 → 国潮插画 → 品牌板对齐 → 实物贴纸文字提取 → 多版本合成。以下是踩过的坑，下次同类项目直接避坑。

---

## 一、照片抠图（实物贴纸/包装拍照）—— 不要硬来

### 坑 1：硬颜色阈值对拍摄素材完全失效
- **现象**：实物贴纸贴在泡沫箱上拍，有反光、光照不均、透视变形。预设阈值（如深绿 r<80,g<100,b<70）检测文字全部为空，只有暗红/灰色能抠出来。
- **原因**：照片反光导致颜色偏暖偏亮，深绿文字 RGB 值和白底差异被光照压缩。
- **正确做法**：
  1. 先运行 `sample_colors.py` 采样实际像素值，再校准阈值。
  2. 采样后仍不干净 → **放弃照片抠图，改用 PIL 按内容重新绘制**（文字内容已知，颜色匹配，字体尽量接近）。
  3. PIL 绘制比照片抠图干净 10 倍，矢量级清晰，不需要透视校正。

### 坑 2：白色元素在白色预览里看不见
- **现象**：从橄榄绿底上抠出的白色文字/剪影，输出透明 PNG 后在白色预览里完全看不见。
- **原因**：白色透明底 PNG 在白色背景上自然不可见。
- **正确做法**：交付时明确标注"白色元素透明底，放到深色背景上使用"，不要反复重抠。

## 二、字体问题

### 坑 3：本机没有目标字体，国外 CDN 全被墙
- **现象**：用户要"华文行楷"（STXingka），本机没装 Office，GitHub/jsdelivr/ghproxy/wfonts 全部超时或 404。
- **正确做法**：
  1. 先查 `C:\Windows\Fonts` 和 F 盘有没有现成字体。
  2. 没有就直接说"本机没有，两个选择：你手动下/我用楷体替代"，不要浪费轮次试国外镜像。
  3. 楷体（simkai.ttf）是手写感的最佳系统替代，再配合 PIL 倾斜变换可以做签名体效果。

### 坑 4：PIL 做签名体/艺术字
- **方法**：`Image.AFFINE` 剪切变换做右倾（slope=0.22），底部加 arc 弧线收尾。不需要专门的签名字体。

## 三、合成布局坑

### 坑 5：在已有文字的背景图上叠白色文字 = 重影
- **现象**：背景图上本来就有深绿色 slogan 和电话，又叠了一层白色上去，变成深绿+白色重影。
- **正确做法**：
  1. 永远用**干净背景图**（AI 原始出图，无烘焙文字）。
  2. 所有文字元素全部用透明 PNG 自己叠。
  3. 不要在 preview/合成图上二次叠加文字。

### 坑 6：白色文字在浅色背景上不可读
- **现象**：青绿山水顶部是米白色，白色 slogan 和电话在上面几乎看不见。
- **正确做法**：
  1. 顶部米白区域用深绿色文字。
  2. 底部深色山水区域用白色文字。
  3. 或者：文字加柔和投影/描边保证可读性。

### 坑 7：品牌板对齐 = 顶栏+中间+底栏三段式
- **正确布局**（对齐品牌板规格）：
  - 顶部 15%：橄榄绿底（或米白底），左手写 slogan，右服务电话
  - 中间：插画铺满，中央放 Hisense logo
  - 底部 21%：白色中英文公司名居中（或橄榄绿底+农耕地剪影+白色公司名）
- **不要**全画面铺满插画+全白文字，层次不如三段式。

## 四、文件命名和交付

### 坑 8：多版本迭代要清晰
- 版本命名：`sticker_B_v1.png` → `v2` → `v3` → `final`，不要用 `new`、`final_final`。
- 每个元素单独存透明 PNG 在 `output/brand_elements/` 或 `output/grape_sticker_text_clean/`，方便用户复用。
- 印刷版导出 6000×3600（5:3），预览版 2400×1440。

## 五、快速检查清单（贴纸合成前过一遍）

- [ ] 背景图是干净的吗？有没有烘焙文字？
- [ ] 白色文字放在深色区域了吗？
- [ ] logo 是透明 PNG 直接叠的，不是白底卡片？
- [ ] 字体本机有吗？没有就提前说。
- [ ] 有没有重影？（在已有文字的图上又叠了一层？）
- [ ] 顶部 slogan 和电话位置对齐品牌板了吗？
- [ ] 底部公司名中英文两行居中了吗？
- [ ] **文字有没有和背景主体重叠？**（slogan 放在叶子上？电话放在藤上？）
- [ ] **有没有硬涂底色带破坏插画衔接？**（底部不要涂纯色条，直接叠白字）
- [ ] **视觉层级对吗？**（logo 是主角 > 产品名次之 > 辅助信息退到角落）

## 六、V2 项目新增踩坑（2026-10-14 二次迭代）

### 坑 9：在已有文字的背景上叠新文字 = 双重重影
- **现象**：v2 原图底部已有中文公司名，又叠了一层新的中文+英文，变成两个中文重叠。
- **正确做法**：要么用干净背景重新合成全部元素，要么只加缺失的那一层（如只加英文，不动中文）。不要既保留旧文字又叠新文字。

### 坑 10：底部硬涂底色带破坏插画衔接
- **现象**：为了擦掉旧文字，用平均色涂了一条橄榄绿色带，和上面的青绿山水衔接生硬。
- **正确做法**：不要涂底色。要么用干净背景重新合成，要么直接在原山水上叠白色文字，接受旧文字被新文字覆盖（同色同位置自然融合）。

### 坑 11：文字位置和背景主体重叠
- **现象**：slogan 放在葡萄叶子上看不清，服务电话放在葡萄藤上被遮挡。
- **正确做法**：
  1. 先看背景图的主体在哪（葡萄在右侧，山在左侧）。
  2. 文字放在空白区域（米白/淡墨区），不要压在主体上。
  3. slogan 放左上角 logo 旁边，电话放左下角，都在空白区。

### 坑 12：三段式布局 > 全铺满
- **现象**：全青绿山水铺满 + 全白文字，层次不如三段式（顶部米白+中央 logo+底部山水+白公司名）。
- **正确做法**：食品/农产品贴纸用三段式：顶部浅色区放 slogan/电话，中央放 logo，底部深色区放公司名。视觉层次分明。

### 坑 13：中央品牌组居中 > 分散布局
- **现象**：logo 在顶部、公司名在底部，两者分散，视觉焦点散。
- **正确做法**：logo + 公司名组成一个视觉组，居中放置，成为画面主角。slogan/电话缩到角落。符合安藤克制原则（一个主角）。

### 坑 14：字体优化不要瞎换
- **现象**：公司名从微软雅黑换成黑体，用户觉得不好看，要求恢复。
- **正确做法**：不要擅自换字体。用户给的字体参考是什么就用什么。微软雅黑粗体比黑体更精致，不要为了"更有力量感"瞎换。
