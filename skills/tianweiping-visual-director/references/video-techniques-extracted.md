# 视频技术提炼：Linktel / Lynkvis / 即梦节点画布七大技法

> 来源：2026-10-13 用户提供的 11 个微信教学录屏（约 108 分钟）。
> 统一结论：11 个视频教的是**同一个工具**——Linktel AI（linktelai.com）/ Lynkvis AI 节点式设计画布，网页端，底层字节 seedream-pro 图像 + doubao-seed/GVLM 多模态 LLM。视频 11 与视频 9 是同一期卫浴教程的重复上传。
> 本文件按**技术点**索引，不按视频。每个技术点给：原理、逐字提示词模板、参数、适用场景。

## 技术点 1：白模/CAD/户型图 → 照片级写实（保结构重绘）

### 适用
用户已有 3dmax/SU/酷家乐/CAD 白模、线稿、户型图，想一键变成照片级效果图，**不许 AI 改户型/挪家具**。

### 逐字提示词模板（核心硬约束，必须整段保留）
```
首先精准识别模型图中的窗户位置、尺寸与朝向，据此判断自然光的入射方向与自然光影路径，
然后自然光从窗外柔和射入。主光均匀照亮室内主体，墙面漫反射辅光自然补亮暗部，
环境光通透柔和，全视角材质纹理、光影层次、物体样式完全一致，
画面干净无多余元素，无水印无文字，透视准确，空间真实还原，
物体材质、光影、比例完全统一，无任何变化，室内纪实拍摄。

【硬约束】
- 禁止改变原始 3dmax、SU、酷家乐模型场景结构、物体位置和几何形状，严禁改变空间布局
- 保持所有家具、灯具和装饰品的原始样式与比例
- 材质转换为高精度符合物理规律的真实材质表现，保留原始模型的几何比例关系
- 保持原图比例、结构、主体、所有物体与细节不变
- 模型上贴图的颜色和纹理，禁止修改贴图色调、饱和度、明度、材质风格和纹理图案
```

### 参数
- 模型：seedream-pro（节点最适）
- 分辨率：auto-2K（最高 4096×2264）
- 相机模拟：iPhone 17 Pro Max（出手机纪实质感）/ 不指定（出摄影质感）
- 调色：自然通透
- 勾选"提示词优化"让 GVLM/doubao-seed-2 自动润色
- 步数 30，seed 随机

### 反面教材
- 不写硬约束 → AI 自由发挥把三居室改成大开间
- 只写"现代简约客厅" → AI 随便摆家具，和白模对不上

## 技术点 2：三图参考融合（结构+材质+配色分图锁定）

### 适用
用户有 SU 线稿、工地实拍（贴了一半砖）、想要的配色参考，三张图融合出落地级效果图。

### 逐字提示词模板
```
在图一的基础上，附着图二的瓷砖颜色和缝隙，参考图三的配色和材质，生成效果图。
不要改变图一的比例以及模型细节。
```

### 三图分工
| 图位 | 内容 | 锁定什么 |
|---|---|---|
| 图一 | SU/CAD 黑白线稿（可带毫米尺寸标注） | 结构、比例、家具位置 |
| 图二 | 工地实拍/材质样块/贴了一半砖的现场 | 砖缝颜色、真实材质感、施工尺度 |
| 图三 | Pinterest/花瓣上保存的风格参考图 | 配色、软装氛围、家具款式 |

### 关键句式
- "附着图二的 X"（不是"参考"，是"附着"=强制贴上去）
- "参考图三的 Y"（软参考）
- 尾句必带"不要改变图一的比例以及模型细节"

## 技术点 3：红框红箭头局部修改法（最重要的省时技巧）

### 适用
AI 出图后某个局部不对（镜柜灯带位置错、开关位置不对、某块材质要换），不想整图重抽。

### 操作步骤
1. 在 AI 生成的结果图上，用任何画图工具（PPT/系统画图/Figma）画**红色方框**框住要改的区域、画**红色箭头**指向具体位置。
2. 把"原图"作为图一、"红框标注图"作为图二，接入新节点。
3. 提示词固定句式：

```
在图一基础上，参考图二标注的内容修改，生成后删除红色方框、红色箭头、红色文字，
不改变基础结构和比例。
```

### 进阶
- 一次红框只改一类问题（不要一张图标 10 处）。
- 改完节点输出自动抹掉红框痕迹。
- 把上一节点输出接回下一节点作为图一，形成"生成→红框改→再改"流水线。

### 为什么省时间
- 整图重抽 = 重新掷骰子，结构可能漂移。
- 红框法 = 精确外科手术，结构 100% 保留。

## 技术点 4：平面图红箭头标视角 → 出 3D 效果图

### 适用
给一张 2D 户型图，想从某个房间、某个视角出对应的人视 3D 效果图。

### 操作
- 在 2D 平面图上用红框选中要出图的房间，画红箭头标相机朝向（站在哪、看向哪）。
- 喂给节点画布，提示词：
```
参考图一平面图，按图二红框选定房间、红箭头朝向的相机位置，
生成人视高度（1.5m）的 3D 写实效果图，不改变平面图墙体和门窗位置。
```

## 技术点 5：六大功能按钮 + 九宫格批量物料

### 六大功能按钮（不用写提示词）
| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| 灯管效果 | 控制柜灯/台灯发光 | 夜景/暗调氛围 |
| 默认无光 | 纯窗外环境光，无人工光 | 白天写实/报批图 |
| 一键加人物 | 自动放生活化人物 | 提案看尺度/营销 |
| 反色光泽增强 | 强化材质高光反射 | 大理石/金属/玻璃空间 |
| 后期调色 | 套电影感 LUT | 出图后统一调性 |
| 多角度统一 | 同一空间多视角保持材质一致 | 出整组户型图 |

### 九宫格一键出物料
| 九宫格类型 | 产出 | 用途 |
|---|---|---|
| 剧情九宫格 | 9 张带人物的电影感分镜 | 品牌故事/宣传片素材 |
| 九宫格分镜 | 9 张不同机位 | 方案汇报 |
| 光影九宫格（暗调） | 9 张暗氛围 | 夜景/高端酒店 |
| 光影九宫格（亮调） | 9 张明亮版 | 住宅/办公 |
| 人物九宫格（虚焦暗调） | 虚焦人影剪影 | 氛围感海报 |
| 人物九宫格（生活化不露脸） | 做饭/走路/坐沙发的真人感 | 住宅营销/小红书 |

### 关键提示词
```

```
"不酷脸"是关键字——AI 默认出模特脸，加这句变路人感。

## 技术点 6：多角度自由相机

### 面板参数
- 跟随相机视角滑杆：**方位角** / **俯仰** / **距离**
- 快捷机位：正面 / 侧拍 / 仰拍 / 侧面 90°15° / 俯视 160°0° / 鸟瞰 222°82°
- 典型值示例：方位角 45°、俯仰 24°、距离 12m（人视）；鸟瞰俯仰 82°

### 用法
在已写实的图上拖参数，不用重画结构，一键出整套视角。适合：
- 一个户型出客厅+餐厅+走廊+卧室 4-6 张
- 建筑外观出人视+街景+鸟瞰 3 张

## 技术点 7：日转夜 + LLM 分镜 → 图生视频

### 日转夜提示词
```
转化成夜景，霓虹灯闪烁，外景柔和的低饱和度蓝色月光与室内暖黄的灯光形成强烈对比，
光线细腻有层次。
```
配套：MIR 风格后缀（见 master-style-lexicon #12），出蓝调时刻电影感。

### LLM 分镜节点
在节点画布接一个多模态 LLM 节点（doubao-seed-2 / Lynkvis GVLM），提示词：
```
请根据提供的图片，生成一段视频分镜脚本，包含镜头编号、画面描述、镜头运动、
15s 时长、无旁白/无字幕，用 Markdown 表格输出，以〔王家卫/韦斯·安德森/是枝裕和〕导演风格。
```
输出表格后喂给视频节点（seedance/i2v）。

### 关键坑
- 视频节点**要求参考图里有真人**，否则报错"当前参考图内无真人，请换参考图"。
- 解法：先跑"人物九宫格（生活化不露脸）"，选一张含人的镜头再喂视频。
- 极特写手/眼做 i2v 会崩；一个 prompt 不要塞两个场景。

```
一束光穿透黑暗，仅依靠水晶灯散发的漫反射光微弱勾勒〔物体〕，
逼真物理材质，Octane Render 渲染，光线追踪，戏剧性的光影氛围，极致纯净的画面质感。
```

## 通用参数速查

| 项 | 默认值 | 备注 |
|---|---|---|
| 模型 | seedream-pro | 节点画布最适；本地备选 Flux.1-dev fp8 |

| 提示词优化 | 开 | GVLM/doubao-seed-2 自动润色 |
| Seed | 随机 | 满意后固定 seed 复现 |

## 工具现状（2026-10-13 实测）
- 平台：linktelai.com / lynkvis 网页端，节点式黑色画布。
- 底层图像：字节 seedream-pro。
- 底层 LLM：doubao-seed-2 / GVLM 3.1/3.5。
- 体验版有 5 次额度限制；正式版按积分扣费（单图 30 积分，多角度 28 积分）。
- 本地备选：RTX 5080 + ComfyUI 便携版，Flux.1-dev fp8 + Architecture LoRA 0.7 + Realistic LoRA 0.5（见 `田伟平总监审核标准/references/local_model_tuning.md` 与本 skill `references/local-flux-tested.md`）。
