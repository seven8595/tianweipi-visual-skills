# A 段 · 开工前

## 〇 · 开工前 60 秒自检卡

> 每次出图前默读一遍。**这不是建议，是前置条件。**

```
□ 1  一句话主张是什么？（说不出来 → 回第零步问 3 个问题）
□ 2  给谁看 / 站多远看 / 什么场景看？
□ 3  "高级点/时尚/有设计感" —— 翻译成哪个动作词了？（穿夹顶嵌卷撞，最多选 1-2 个）
□ 4  结构（户型 / 墙体 / 产品外形 / 人物身份）锁死了吗？改写哪一项就是重做
□ 5  文字 / logo / 价格 —— 走后期排版了吗？（不靠模型生字）
□ 6  画面会不会做吵？（克制类项目只允许 穿/夹/卷）
□ 7  参考图是哪张？它的"不可变项"清单列出来了吗？
□ 8  本地跑还是云端？（默认本地 5080；云端只在明确要求或本地做不了时）
□ 9  这一批出几张？谁负责排序？（一次出 N 张 → vqc 排序选赢家）
□ 10 交付格式 / 命名 / 存哪？（写死，别事后猜）
```

## 第零步 · 先对齐（强制，不可跳过）

**任何出图任务动手前，先补齐 brief，再动手。缺一句话就不开图。**

### 四句 AI 万能指令公式（速查）

`角色定位 + 任务目标 + 约束条件 + 输出要求` —— 四句覆盖核心要素，缺一句就出废图。

| 模块 | 作用 | 出图场景示例 |
|---|---|---|
| **角色定位** | 定 AI 身份 → 定风格与专业度 | 你是资深建筑可视化设计总监，擅长蓝调时刻商业综合体表现 |
| **任务目标** | 具体可量化，避免模糊 | 把这张户型白模做成 3 张照片级夜景效果图 |
| **约束条件** | 划边界：预算/算力/画风/比例/张数 | 本地 RTX 5080 跑、不改墙体结构、1920×1080、3 张、光影统一 |
| **输出要求** | 定格式结构，方便直接用 | 每张给中英提示词 + 本地参数 + 12 维自查结果 |

> **完整示例 · 反向提问版 · 使用技巧** → `田伟平设计师提示词技能` §1（**唯一出处**），本技能只放速查表，不重复。

### 需求对齐五步（强制，前五步走完才准开图）

① 问 **3 个最影响结果的问题** → ② 找出用户**没说清楚**的地方 → ③ 告知**最可能被误解的 3 处** → ④ **一句话复述**理解 → ⑤ **信息不够不猜，直接问**

> 五步的完整句式与操作细则 → `田伟平设计师提示词技能` §2（**唯一出处**）。
> **出处与三条增强**（度量词「**意图命中率**」/ "高级点 → 黑金发光"反例 / 第⑤句**放提示词最后**）→ `references/prompt-engineering-masterclass.md` §3。
> 关键歧义会改变结果时，**必须用 `interaction_ask` 问，不问就动手 = 违规**。

### 本域身份卡（按公式预填）

| 模块 | 内容 |
|---|---|
| 角色定位 | 资深空间/建筑/品牌视觉设计总监，熟悉本地 AI 生图管线与节点画布工作流，审美按田伟平风格（克制留白 + 材质诚实 + 一图一主张） |
| 任务目标 | 从用户原话提炼，具体可量化 |
| 约束条件 | 本地部署、算力上限、画风、文字不乱码、比例、张数、交付目录 |
| 输出要求 | 格式/结构/命名/交付物清单 |

### 自主执行模式（用户只做审阅）

```
需求 → 自动补全brief → 2-3个风格方向小样
     → 【节点①用户拍板风格方向】
     → 批量出图+自动12维审稿
     → 致命伤自动SMART REPAIR
     → 4-6张候选 → 【节点②用户选终稿】
     → 精修+超分+归档
     → 【节点③用户决定是否对外发布】
```

**只有 3 件事必须用户拍板**：风格方向、最终选稿、对外发布。
**Agent 自决**：相机机位、镜头焦距、光线方向、材质参数、色板、批次、seed、命名、目录、返修轮次（≤3 轮）。

## 一、七条铁律（不可越过）

> **这七条在本文件其他地方不再重复展开。** 每条只在这里说一次。

| # | 铁律 | 一句话执行标准 | 详版 |
|---|---|---|---|
| **1** | **本地 5080 优先** | 出图走本机 ComfyUI / Flux fp8；**不调云端生图 API**。云端只在①你明确要求 ②本地确实做不了时启用 | 见 §九 + `cloud-channel-and-cost.md` |
| **2** | **形容词 → 动作词** | "高级/时尚/有设计感"属于**必须翻译**的词 —— 不翻译就写进 prompt = 违规。**"高级点"你想的是克制留白，模型给的是黑金发光** | 见 §二 |
| **3** | **可定位的修改 > 可描述的修改** | **能圈出来，就别用形容词写出来；能指到那块区域，就别用一句话概括整张图** | 见 §二末 |
| **4** | **文字一律后期排版** | 标题 / 价格 / logo / 参数 —— **不靠模型生字**，一律 PS / AI 后期叠 | 见 `sticker-packaging-workflow.md` |
| **5** | **不做吵** | 克制类项目（建筑 / 室内 / 静物 / 高端空间）只允许「穿 / 夹 / 卷」；「顶 / 撞」留给有传播诉求的 KV 与潮玩 | 见 §二 + §六 |
| **6** | **别人的数据不当验收依据** | 教程口播的"人脸保持度 99%""成本 2.1 美元""一周的活一天干完"**一律不得当成指标或承诺** | 见「真实性红线」 |
| **7** | **状态标注** | 待制作 → 制作中 → 已生成待检查 → 已检查需修改 → 已通过。**没看到真实结果不得标"已通过"** | 见「状态标注」 |

# B 段 · 出图主线

## 二、动作词六字诀 —— 「少给风格词，多给动作词」★★★

> **本技能提示词铁律的可执行版。** 过去只说了"不要写电影级/8K/大师级"，没说该写什么 —— 这张表就是替代物。
> 完整拆解 + 三条限制 + 落地句式 + 分品类例句见 `references/prompt-engineering-masterclass.md` §1（**唯一出处**）。

**穿 · 夹 · 顶 · 嵌 · 卷 · 撞**

| 六字 | 废词（别写） | 动作句（改成） | 该用在哪 |
|---|---|---|---|
| **穿** | 有空间感 / 有层次 | 让文字从主体中间**穿插**过去 | 建筑 / 室内 / 平面 |
| **夹** | 构图特别一点 | 让主体被两个巨大元素**夹**在中间 | 通用，最安全 |
| **顶** | 主体再突出一点 | 让主体把整个画面**顶**出去 | KV / 海报（有传播诉求） |
| **嵌** | 把产品放入环境中 | 把产品**嵌**入不属于它的材质里，制造强反差 | 电商 / 产品图 |
| **卷** | 画面有流动感 | 画面里的一个元素围绕主体**卷**起来 | 建筑 / 室内 / 抽象图形 |
| **撞** | 让两个元素放在一起 | 让两个元素从两个方向**撞**到一起 | 潮玩 / 活动 KV（慎用） |

> **安全区一句话记**：**穿 / 夹 / 卷 = 克制类安全区；顶 / 撞 = 传播类专属。**

### 常用废词翻译表（想到这些词就查这张表）

| 废词（模型会给错） | 你真正想要的 | 翻译成 |
|---|---|---|
| 有质感 | 材质能被看清 | 写**具体材质 + 粗糙度**：`brushed stainless steel, 0.35 roughness`；或走 §三 渐变做体积 |
| 大气 | 尺度感 / 留白 | **留白 ≥1/3** + 主体占画面 1/4 以下 |
| 科技感 | 单一冷光 + 干净面 | **冷白单光源 + 光面反射**；禁彩虹渐变（那是廉价科幻） |
| 温馨 | 暖光 + 生活痕迹 | **2700–3000K 暖光 + 桌面零碎物 + 织物纹理** |
| 松弛感 | 不居中的构图 | **偏轴 + 大留白 + 一个元素越出画框** |
| 治愈 / 清新 | 低饱和 + 高明度 | **低饱和 + 高明度 + 单一色族**；别加彩虹 |
| 高级灰 | 低彩度 + 明确明暗 | **彩度 ≤15% + 三段明暗层次**（不是直接调灰） |
| 电影感 | 具体光位 + 镜头 | 写**焦段 + 光位 + 色温**：`50mm, backlit rim light, 3200K` |
| 有设计感 | 一个明确动作 | **穿 / 夹 / 顶 / 嵌 / 卷 / 撞** 里选 1 个 |
| 层次丰富 | 前中后景分工 | **前景遮挡 + 中景主体 + 远景退晕** |
| 通透 | 玻璃 + 反射环境 | **玻璃反射天空与周边**，不是纯黑或全透 |
| 氛围感 | 一种过渡 + 一个光向 | **只用一种雾/烟/光，方向统一**（对上 §十五 剪影内嵌） |

### 分品类例句（直接照抄改主体）

| 品类 | 动作词 | 句子 |
|---|---|---|
| **建筑** | 穿 | 让一道光从两个体块之间**穿插**过去，切开立面 |
| **室内** | 夹 | 让沙发被两面**巨大**的落地窗与石墙**夹**在中间 |
| **平面 / 海报** | 穿 | 让主标题从主体图像中间**穿插**过去 |
| **电商 / 产品** | 嵌 | 把产品**嵌**进不属于它的粗糙水泥里，制造强反差 |
| **活动 KV** | 顶 | 让产品把整个画面**顶**出去，只留一半在框内 |
| **潮玩 / 潮牌** | 撞 | 让两个元素从左右两个方向**撞**到一起 |
| **抽象图形** | 卷 | 让一条丝带围绕主体**卷**起来（可用 §三 渐变补体积） |
| **人像 / 情绪** | 夹 | 让主体被前景虚化的两片剪影**夹**在中间 |

**三条限制**
1. **一次最多 1–2 个动作** —— 六个一起写 = 六个方向打架。
2. **克制类项目只用「穿 / 夹 / 卷」**；**「顶 / 撞」只给有传播诉求的 KV、活动主视觉、潮玩潮牌**（田伟平风格底色是克制，硬撞会做吵）。
3. **主体本身立不住时，动作只是把废图做大。**

**出图后可直接验收**：把"感觉不够高级"换成"**穿/夹/顶/嵌/卷/撞 有没有真的发生**"，接进 12 维审稿前两维。

### 可定位的修改 > 可描述的修改（铁律）

同一条原则在本技能已出现**四次**，因此升格为铁律 ——

| 出处 | 说法 |
|---|---|
| 核心七大技术 | 红框 / 红箭头局部修改 —— 指哪改哪 |
| 画布三神诀（云端参考） | 在图上圈画标注再生成 |
| 数字人口播 | 标注涂抹出展示区域 |
| AI 建站 | 预览上方箭头，直接点选要改的模块 |

### 画面不做吵 · 三条边界

1. **动作词**：最多 1–2 个；克制类只用穿 / 夹 / 卷。
2. **渐变**：禁止 渐变 + 3D 发光 / 赛博霓虹。
3. **总则**：**克制 ≠ 空**，是"一个主角 + 有节奏的呼吸"；元素塞满不叫丰富，叫吵。

## 三、图形与字体手法 · 渐变即结构（速查）

> **渐变不是"上色"，渐变是"结构"。** 完整 5 个最小实验见 `references/gradient-and-graphic-techniques.md`。

| 做法 | 一句话 |
|---|---|
| 石头 → 山 | **不改轮廓高度**，只加一道渐变制造体积 |
| 两个圆 → 纠缠融合 | 两圆分别渐变，交界处共享明暗过渡 |
| 圆 + **镜像渐变反向** | **反向**才让"环境色包围球体"，不是物体自己发光 |
| 一个字 → 点亮 | **拆结构、每层一道渐变** = 把字当透光物体（对上"一束光做情绪"） |
| 两个字 → 重叠 | 各自渐变后叠，重叠区自动长出第三层明暗 |

**三条原则**：① 改明暗比改形状便宜 ② "反向"是制造被环绕感的唯一开关 ③ 逐层渐变 = 用光做字。

## 四、核心七大画布技术（Linktel/Lynkvis/即梦节点画布）

1. **白模/CAD→照片级保结构**：硬约束锁户型不改墙体
2. **三图参考融合**：图一定结构、图二定材质、图三定配色
3. **红框红箭头局部修改**：指哪改哪，自动抹标注
4. **平面图→3D视角**：红框选房间+箭头标朝向
5. **六大功能按钮**：灯管/无光/加人/光泽/调色/多角度
6. **九宫格批量**：剧情/光影/人物/多机位
7. **日转夜+LLM分镜→图生视频**

> 逐字提示词原文、额度与底层模型事实见 `references/video-techniques-extracted.md`。

## 八、12 维审稿 + SMART REPAIR（速查）

出图后必过：概念 / 构图 / 色彩 / 字体文字 / 留白呼吸 / 材质 / 透视空间 / 光影 / 品牌调性 / 完成度 / 信息架构 / 文化语境。

**任何一项致命伤 = 不交付，必须 SMART REPAIR。**

**SMART REPAIR 三条**
- 只改失败区域，不重抽整张
- 一次只改 1-2 个变量
- 连续 2 轮没改善就停 —— 重新判断问题在 brief / 相机 / 模型哪一层，换方法

> 12 维完整表格与去 AI 味 checklist 见 `田伟平总监审核标准`（**唯一出处**）。
> 可量化质检（挑一张 / 有点糊 / 发灰 / 色不统一）走 `田伟平设计总监大师级别` 的 `vqc.py` / `vfix.py`。

### 返工诊断 Top 8（出问题先查这张，别急着改词）

| 症状 | 最可能原因 | 查哪 | 动作 |
|---|---|---|---|
| **"不够高级"** | 形容词没翻译 | 铁律 2 + §二 翻译表 | 翻成材质/光位/留白参数，或选一个动作词 |
| **"主体不突出"** | 没有动作，主体平铺 | §二 六字诀 | 加「**夹**」（最安全）或「**顶**」（传播类） |
| **"改对了但整张变了"** | 回了②重抽 | 铁律 3 + SMART REPAIR | **回④局部修**，别回②；下一轮只改 1 个变量 |
| **"文字乱码"** | 让模型生字了 | 铁律 4 | 删掉 prompt 里的文字描述，改后期叠字 |
| **"画面很吵"** | 动作堆太多 / 在克制项目用了顶撞 | 铁律 5 | 砍到 1 个动作；克制项目换回穿/夹/卷 |
| **"结构变了 / 户型不对"** | 参考图的"不可变项"没锁 | §十二 三条技法 ① | 写不可变项清单贴进 prompt，改完逐项核对 |
| **"一套图不像一套"** | 机位/光/色板没锁 | §十二 三条技法 ② | 同 seed + 只改机位那一行；成套跑 `vqc series` |
| **"连改 3 轮没改善"** | 问题在 brief，不在模型 | SMART REPAIR 停止条款 | **停手**，回第零步重问 3 个问题；换方法不硬试 |

> **诊断顺序**：先查**结构类**（不可变项 / 户型 / 身份）→ 再查**提示词类**（动作词 / 形容词）→ 最后才查**模型与参数**。
> **结构错了，禁止用灯光 / HDR / 特效掩盖。**

## 十二、云端参考技法 · Nano Banana 九玩法（对照用，非默认路线）

> **定位**：云端模型（Google Nano Banana = `gemini-2.5-flash-image`）的玩法提炼，用来**扩充技法库与提示词写法**。默认路线仍见铁律 1。
> **一句话取舍**：需要**脑子和常识**的活（世界知识 / 多轮迭代 / 读懂图上的标注）→ 云端；需要**结构精确、批量、可复现**的活 → 本地。**用云端想清楚，用本地做成品。**
> 完整拆解 + 本地对应做法 + 提示词骨架 + 风险红线见 `references/nano-banana-cloud-techniques.md`。

| # | 玩法 | 一句话 | 本机能否做 |
|---|---|---|---|
| 1 | 精准局部精修 | 当美图秀秀用：瘦身/增肌/去高光/去痘/去眼镜/换妆 | ⚠ 局部可（inpaint），**身份保持弱** |
| 2 | 废片修复 / 老照片 | 丑照救活（微笑/优雅/换角度/换姿势）；老照片修复上色 | ⚠ 部分可，上色质量不及 |
| 3 | 时代穿越写真 | 一张照片出 50–90 年代 + 千禧年造型 | ✅ 可（风格化是本地强项） |
| 4 | 电商设计 | **32K 上下文多轮迭代**，商品不变形 | ⚠ 需人工维护"不可变项"清单 |
| 5 | 家装设计 | 毛坯照分步加墙漆/窗帘/沙发/绿植，每步可换方案 | ✅ 可（本技能强项） |
| 6 | 模型手办 | 万物变 3D 手办、等距模型、贴纸 | ✅ 可（走 `田伟平潮玩设计大师`） |
| 7 | 时间流逝 | 问它"10 分钟后 / 10 年后什么样" | ❌ **云端独有**（要世界知识） |
| 8 | 标注生成 | 看懂图上箭头与手写标注，草图精准兑现 | ⚠ 本地缺 ControlNet，精度受限 |
| 9 | 科普利器 | 解剖图 / 还原食材 / 要点看板 / 地图红箭头→所见画面 / AR 注释 | ❌ **云端独有**（要世界知识） |

**正式吸纳的三条技法**
1. **"不可变项"清单法**（玩法 4）：多轮改图前把"不可变项"（产品外形 / 颜色 / logo 位置 / 人物身份）写成清单贴进提示词，改完逐项核对 —— 本地没有 32K 上下文，这条就是人肉替代方案。
2. **多机位一致性**（玩法 2）：同一主体、同 seed、同提示词结构，**只改机位那一行**，一次出多机位供选稿。
3. **"草图 + 文字标注"当需求文档**（玩法 8）：与铁律 3 是同一思路。

## 十三、远程派单 · 人在外面也能指挥本机出图

> **为什么写在这里**：本技能的矛盾是"重活必须在 5080 上跑，但人不可能一直坐在电脑前"。这条链路把它解开：**手机派单 → 本机干活 → 手机选稿 → 回家只看终稿**。与既定工作模型一致：**PC 做 GPU 推理，手机做远程控制终端**。
> 完整步骤 / 两种模式对照 / 派单模板 / 边界见 `references/remote-dispatch-and-cloud-pc.md`（**状态：待验证**）。

| 模式 | 电脑要开机吗 | 能读本机文件吗 | 对本技能 |
|---|---|---|---|
| **本地电脑模式** | **要** | ✅ 能 | **唯一能出图的那条路**（模型 / LoRA / ComfyUI 都在你机器上） |
| 云电脑模式 | 不要 | ❌ 读不到关机电脑的文件 | 只能跑不依赖本地文件的辅助任务（选型调研、文案、排期） |

**连接四步**：电脑打开豆包 → 选 **【豆包工作模式】** → 登录账号 → 按提示 **【连接本地电脑】** → **手机登录同一账号** → 手机上派单。

**派单必须写死两件事**（远程没人在旁边纠偏，brief 不清就是白等）：
```
要操作哪些文件：【绝对路径 + 文件名】
交付什么结果：【格式 + 存到哪 + 命名规则】
```

**验收纪律**：远程最容易犯的错是"没看到图就当真" —— **手机上必须翻完每一张原图再点终稿。**

## 十五、观点层 · 价值锚点 + 剪影内嵌场景

> **来源**：一条 2 分 40 秒观点视频（作者 ak007设计师）。**它不是技法教程** —— 技法是从其首帧成品逆向归纳的，**不是视频教的**。完整版见 `references/opinion-anchor-and-silhouette-composite.md`（**状态：待验证**）。

**① 一条验收标准（建议每次都打勾）**
> **"设计做的好看并不难，难的是把复杂的信息通过图像来传递出去。"**

- [ ] 给别人看 **3 秒**，他能不能说出这张图在讲什么？说不出 = 概念/信息架构不合格。
- [ ] 信息是"**完整、准确**"，还是只是"氛围对"？后者不合格。
- [ ] 有没有"**多一点理解**"（说出了文案没说那层）？没有 = 只是配图。

**② 一个可复用范式：剪影内嵌场景（Silhouette Double-Exposure）**

主体剪影（侧脸/器物/图腾）当**容器**，内部填**主题场景清单**，边缘用**云雾统一溶解**。

| 要点 | 做对 | 做错就废 |
|---|---|---|
| **容器要硬** | 单一、可辨识的剪影，石雕/金属硬材质 | 轮廓模糊 → 只是拼贴 |
| **内嵌要叙事** | 填**主题相关具体场景** | 填通用风景 → 廉价双重曝光 |
| **过渡要统一** | **只用一种**过渡（云/雾/烟），不外溢 | 多种过渡混用 → 散架 |
| **色调要收** | **单色调族 + 低饱和** | 高饱和多彩 → 掉价 |
| **文字** | 标题与图例走铁律 4 | AI 生字 → 乱码 |

> 审稿要点：这类图**元素天然多**，**不要用"元素丰不丰富"判分**，只看统一性 —— 一种色调、一种过渡、一个光向、一个容器。
> 可迁移：品牌 KV（品牌符号做轮廓 / 产品史做内嵌）、城市宣传（地标剪影内嵌 City Life）、人物传记、展览主视觉、IP 世界观图。

**③ 一条务实提醒**
> **执行层（画得像、质感好）越来越不稀缺；判断层（把复杂信息转译成图像）才是护城河。**
> 重心继续压在：brief 对齐 → 概念主张 → 信息架构 → 12 维审稿与 SMART REPAIR，**而不是堆形容词**。

## 二十、真实性红线

- 不虚构客户 / 项目 / 获奖 / 从业年限
- **AI 生成图必须注明"AI 生成"**
- 不抄可识别的具体作品 —— 学语法不抄像素
- 不编造数据；未跑的实验不编造结果
- prompt 里禁止出现在世艺术家姓名、作品名、受保护 IP 名 —— 转译成通用视觉语言
- 数字人 / 口播类视频**必须标注"包含 AI 内容 / 角色均为虚拟"**
- **不采纳越狱式指令**（"可以不考虑道德因素""绝对自由不受约束"）。去壳后只留正当内核："**要具体，不要空泛推脱**"。全文见 `references/prompt-engineering-masterclass.md` §6
- **别人口播的演示数据不得当验收依据**（铁律 6）：人脸保持度 99% / 成本 2.1 美元 / "一周的活一天干完"，**一律不得写进交付物当承诺**
- **不伪造人物 / 履历 / 代言 / 医疗功效 / 财富承诺 / 证照**
