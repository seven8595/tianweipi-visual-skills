# Brief 模板库（v2 新增）

不同设计任务的 brief 立基模板。填完再出图，不填空想。

---

## 通用模板（所有任务先填这个）

```
【项目】一句话项目名
【主张】这张图要传达的一句话（不是"做个海报"，是"XX 想让 YY 人群看完 ZZ"）
【受众】谁看？年龄/职业/审美偏好
【场景】在哪看？手机 / 海报墙 / 屏幕 / 印刷？距离多远？
【调性】3 个关键词（如：克制 / 温暖 / 都市）
【参考大师】1–2 位（从 design_masters.md 选）
【禁忌】不能出现什么
【尺寸】16:9 / 3:4 / 1:1 / A3
【输出】本地 ComfyUI / 交付客户 / 内部讨论
【交付时间】今天 / 本周
```

---

## 1. KV / 主视觉

```
【主张】品牌今年的核心情绪
【主视觉元素】一个核心图形 / 一个核心人物 / 一个核心场景
【字体】主标题用什么调性（衬线 / 无衬线 / 手写）
【色彩】主色 HEX、辅助色、点缀色
【留白】占画面比例（高端 ≥ 40%，潮牌可 20%）
【Logo 位置】角落，不抢戏
【参考大师】Saul Bass / 原研哉 / Milton Glaser
```

## 2. 商业建筑 / 商业街效果图

```
【项目类型】高端 / 潮流 / 夜经济 / 文旅 / 社区
【时段】Blue hour / 白天 / 雨夜 / 深夜
【机位】街眼 1.6m / 俯视 / 仰视地标
【透视】中央一点 / 偏轴一点
【建筑高度节奏】2F → 3F → 4F → 远景高层
【必含元素】退台 / 连廊 / 外摆 / 绿植 / 导视
【人流密度】低（高端）/ 中（精品）/ 高（夜经济）
【参考大师】安藤 / 隈研吾 / 槙文彦 / David Chipperfield
```

## 3. 平面海报

```
【信息层级】主标题 > 副标题 > 正文 > 落款（字号差 ≥ 2 倍）
【阅读顺序】Z 字 / F 字 / 中心发散
【网格】几栏？边距多少？
【色彩】主色 70% + 辅助 25% + 点缀 5%
【参考大师】Vignelli（网格）/ Saul Bass（图形）/ 靳埭强（东方）
```

## 4. 产品 / 包装

```
【产品】材质、尺寸、颜色
【场景】桌面 / 户外 / 手持 / 悬浮
【光源】主光方向 / 辅光 / 轮廓光
【背景】纯色 / 场景 / 渐变
【参考大师】Dieter Rams / Jony Ive / 深泽直人
```

## 5. UI / 网页首屏

```
【主操作按钮】第一落点
【信息密度】高端少而精 / 工具型密集
【字体系统】一级 / 二级 / 三级字号 + 字重
【色彩】主色 / 成功 / 警告 / 错误
【留白】8px 栅格
【参考】Apple / Stripe / Linear
```

## Brief 不清晰时的反问模板

1. "你想要的'高级'，是 MUJI 那种空，还是 Apple 那种工业精致？这两个完全不一样。"
2. "客户说'感觉不对'，你具体问他：是颜色不对、构图不对、还是人物不对？'感觉'不是修改意见。"
3. "这张图要贴在 3 米外的公交站，还是 30cm 外的手机屏？阅读距离决定字号和信息密度。"
4. "预算 / 时间只够出一版，还是够迭代 10 版？一版就别让我随便试，直接定方向。"
5. "如果这图只能保留一个元素，你留哪个？那个就是主角。"
