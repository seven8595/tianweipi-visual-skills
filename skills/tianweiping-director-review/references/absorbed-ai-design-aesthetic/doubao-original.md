# AI Design Aesthetic — AI设计审美校准器

解决一个问题：AI生成的东西"好看但廉价"、"像模板"、"没有设计师的手"。

核心逻辑：**风格不是形容词，是参数**。把"高级感"翻译成可执行的色值/字号/圆角/间距规则。

## 使用方法

1. 用户说要某种风格 → 查表取参数 → 写入prompt
2. AI出图后"不够味" → 对照checklist找缺什么
3. 不需要全部67种，记住常用10种就够

## 常用设计风格速查（10种）

### 1. Brutalism 粗野主义
| 参数 | 值 |
|---|---|
| 配色 | 纯黑#000 + 纯白#FFF + 一种强调色（红#FF0000/黄#FFD700） |
| 字体 | 等宽字体/无衬线粗体，字重800+ |
| 圆角 | 0px（直角） |
| 阴影 | 无阴影，硬边 |
| 排版 | 网格严格对齐，大字号，强对比 |
| 禁止 | 渐变、圆角、柔光、玻璃态 |
| 适用 | 品牌海报、艺术展、潮牌 |

### 2. Glassmorphism 玻璃态
| 参数 | 值 |
|---|---|
| 配色 | 半透明白底rgba(255,255,255,0.1-0.2) + 模糊背景 |
| 字体 | 无衬线细体，字重300-400 |
| 圆角 | 16-24px |
| 阴影 | 背景模糊blur(20px) + 细边框rgba(255,255,255,0.3) |
| 排版 | 留白多，居中或偏轴 |
| 禁止 | 高饱和色块、硬阴影、密集排版 |
| 适用 | UI界面、Apple风、科技产品 |

### 3. Claymorphism 黏土态
| 参数 | 值 |
|---|---|
| 配色 | 马卡龙低饱和（粉#FFB6C1/蓝#87CEEB/黄#FFD700） |
| 字体 | 圆润无衬线，字重500-600 |
| 圆角 | 24-40px（超大圆角） |
| 阴影 | 柔和投影offset(0,8px) blur(16px) |
| 排版 | 可爱、友好、元素拟人化 |
| 禁止 | 锐利边角、高对比、暗黑 |
| 适用 | 儿童产品、社交app、可爱IP |

### 4. Bento 便当格
| 参数 | 值 |
|---|---|
| 配色 | 中性灰#F5F5F7 + 白卡片 + 一种强调色 |
| 字体 | SF Pro/Inter，字重400-600 |
| 圆角 | 12-16px统一 |
| 阴影 | 极淡shadow(0,2px,8px,rgba(0,0,0,0.06)) |
| 排版 | 不规则网格，卡片大小不一但对齐基线 |
| 禁止 | 卡片等大、边框粗、颜色杂 |
| 适用 | 数据看板、官网首屏、Apple风 |

### 5. Minimal 极简
| 参数 | 值 |
|---|---|
| 配色 | 米白#FAFAFA + 黑#1A1A1A + 灰#999，最多1个强调色 |
| 字体 | 衬线体（标题）+ 无衬线（正文），大留白 |
| 圆角 | 0-4px |
| 阴影 | 无 |
| 排版 | 大量负空间，一个元素独占画面 |
| 禁止 | 装饰元素、渐变、多色、密集 |
| 适用 | 画廊、高端品牌、原研哉风 |

### 6. Bold 粗体力量
| 参数 | 值 |
|---|---|
| 配色 | 高饱和撞色（红+黑/黄+黑/蓝+橙） |
| 字体 | 超粗无衬线（Anton/Bebas Neue），字号占画面50%+ |
| 圆角 | 0px |
| 阴影 | 硬边投影offset(4px,4px,0px) |
| 排版 | 文字即图形，破格出画 |
| 禁止 | 小字号、柔和、留白过多 |
| 适用 | 音乐海报、活动主视觉、运动品牌 |

### 7. Cafe 咖啡馆/温暖
| 参数 | 值 |
|---|---|
| 配色 | 暖棕#8B4513 + 米白#F5F0E6 + 橄榄绿#6B8E23 |
| 字体 | 手写体/衬线体，温暖感 |
| 圆角 | 8-12px |
| 阴影 | 柔和暖调阴影 |
| 排版 | 自然、手账感、有生活气息 |
| 禁止 | 冷蓝、科技感、硬边 |
| 适用 | 餐饮、生活方式、书店 |

### 8. Clean 干净专业
| 参数 | 值 |
|---|---|
| 配色 | 白#FFFFFF + 深灰#333 + 品牌色一个 |
| 字体 | Inter/思源黑体，字重400为主 |
| 圆角 | 8px统一 |
| 阴影 | 极淡，几乎不可见 |
| 排版 | 严格网格，间距均匀，信息层级清晰 |
| 禁止 | 装饰、渐变、多色、破格 |
| 适用 | B端产品、企业官网、PPT |

### 9. Codex/Developer风
| 参数 | 值 |
|---|---|
| 配色 | 深色背景#0D1117 + 语法高亮色（紫#BC8CFF/绿#7EE787/橙#FFA657） |
| 字体 | 等宽字体（JetBrains Mono/Fira Code） |
| 圆角 | 6-8px |
| 阴影 | 终端光晕glow |
| 排版 | 代码块、命令行风格、等宽对齐 |
| 禁止 | 花哨插画、可爱元素、圆角过大 |
| 适用 | 技术博客、开发者工具、黑客风 |

### 10. Sleek 流线高级
| 参数 | 值 |
|---|---|
| 配色 | 深炭#1A1A1A + 银#C0C0C0 + 暖金#D4AF37 |
| 字体 | 几何无衬线（Montserrat/Poppins），字重300细体 |
| 圆角 | 12-20px |
| 阴影 | 柔和高光+金属反光 |
| 排版 | 不对称、留白奢侈、一个焦点 |
| 禁止 | 粗笨、高饱和、信息密集 |
| 适用 | 汽车、奢侈品、高端科技 |

## 去AI味 Checklist（出图后必查）

AI图的典型"AI味"：
- [ ] 颜色太均匀/太干净——加一点噪点或不对称
- [ ] 所有元素对齐到中线——打破网格，偏轴构图
- [ ] 阴影方向不一致——统一光源
- [ ] 字体用了默认sans-serif——换一个有性格的字体
- [ ] 圆角统一16px——不同元素不同圆角
- [ ] 背景太空——加一个材质/纹理/生活痕迹
- [ ] 颜色超过3种——砍到3种以内
- [ ] 没有视觉焦点——一个元素大，其他小
- [ ] 文字排版居中偏呆板——左对齐/右对齐/破格
- [ ] 像3D渲染太光滑——加胶片颗粒/手绘感/瑕疵

## Prompt模板（按风格组装）

```
[风格名] design,
[配色参数] color palette of [色值描述],
[字体] using [字体描述],
[圆角] with [圆角值] rounded corners,
[阴影] [阴影描述],
[排版] [排版规则],
[气质] [适用场景描述],
no [该风格的禁止项]
```
