## 使用方法

1. 一张图最多对应 1–2 位大师，不堆名字。
2. 翻译成 prompt 关键词，不写"XX 风格"——模型不一定认识，写关键词更稳。
3. 用大师做审核标尺：图贴在 MUJI / 安藤美术馆 / Apple 店里丢人吗？丢人就不交付。
