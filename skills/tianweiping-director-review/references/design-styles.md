# 设计风格参数库（把"高级感"翻译成可执行参数）

> 核心逻辑：**风格不是形容词，是参数**。
> 用户说"高级感/ins风/极简"→ 查表取色值/字号/圆角/间距 → 写入prompt。

---

## 一、海报/KV 类

### 1. Brutalism 粗野主义
| 参数 | 值 |
|---|---|
| 配色 | 纯黑#000 + 纯白#FFF + 一种强调色（红#FF0000/黄#FFD700） |
| 字体 | 等宽/无衬线超粗，字重800+ |

## 六、去AI味 Checklist（出图后必查）

- [ ] 颜色太均匀太干净——加噪点或不对称
- [ ] 所有元素居中对齐——打破网格偏轴构图
- [ ] 阴影方向不一致——统一光源
- [ ] 字体用默认sans-serif——换有性格的字体
- [ ] 圆角统一16px——不同元素不同圆角
- [ ] 背景太空——加材质/纹理/生活痕迹
- [ ] 颜色超过3种——砍到3种以内
- [ ] 没有视觉焦点——一个元素大其他小
- [ ] 文字居中呆板——左对齐/破格
- [ ] 像3D渲染太光滑——加胶片颗粒/手绘感
- [ ] 材质无变化——粗糙度/反射率要有层次
- [ ] 配景"飘"在画面——接地和阴影要对上

## 七、Prompt组装模板

```
[风格名] design,
[配色] color palette of [色值描述],
[字体] using [字体描述],
[圆角] with [圆角值] rounded corners,
[阴影] [阴影描述],
[排版] [排版规则],
[材质] [材质描述],
[气质] [适用场景描述],
no [该风格的禁止项]
```
